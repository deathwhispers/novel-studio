# /novel-studio:outline

设计故事大纲。**不生成线性流水账**——构建多线叙事结构，每条线有独立的起承转合，线之间有设计的交汇点。

## 核心原则

- **总纲即可开写**：做完全书总纲（故事线+分卷）就能开始写，伏笔/弧光/逐卷节拍写作中按需补
- **规划到卷，不规划到章**：伏笔/节拍/弧光/交错只到「第几卷 + 前/中/后段」，不预先钉死章号
- **多线并进**：以角色为单位——主角线为主体 + 各重要配角线，每条线独立完整
- **线要交汇**：角色故事线不能在各自轨道上平行跑——要有设计的交叉、冲突、互相影响
- **节奏设计**：不是匀速前进——高强度后有呼吸，过渡后有高潮
- **每层确认**：每一层设计都和你确认后才进入下一层

## 用法

```
/novel-studio:outline
/novel-studio:outline <操作>      # 操作：创建/调整/查看/检查
```

## 对话流程

### 入口

```
📐 大纲设计。你目前的大纲处于什么状态？

- 完全从零开始（刚初始化项目，还没有大纲）
- 有初步想法但没写下来
- 已有部分大纲，想完善
- 大纲写好了，想检查/调整

或者直接说你想要的操作。
```

---

### 第一层：全书总纲

#### 第 1 轮：核心冲突与主题

```
先不聊章节划分——聊故事的内核。

基于你的项目设定 [已有设定的摘要]，我想确认：

1. 这个故事的核心冲突是什么？
   不是「主角打反派」——是更深层的冲突。
   比如：个人意志 vs 命运安排 / 自由 vs 秩序 / 守护 vs 牺牲

2. 如果这个故事只能让读者记住一件事，你希望是什么？

3. 你脑子里有没有一个「绝对要写」的场景或转折？
   不一定在哪一章——就是你一想到这个故事就兴奋的那个画面。
```

等待用户回答。复述理解。

#### 第 2 轮：拆解故事线

```
好的，基于你说的，我来拆一下故事线。

故事的完整推进，是以「角色」为单位串起来的——主角有自己的线，重要的配角也各有自己的线，这些线交错才形成剧情。

我的初步拆解：

   主角线：[基于核心冲突提炼]
   ───────────
   这条线讲的是：[一句话]
   方向：追求什么 → 会经历什么 → 走向哪里
   赌注是什么：失败了会怎样

   配角X线：[基于已有角色/设定提炼]
   ───────────
   这条线讲的是：[一句话]
   方向：[X 自己的起承转合，不依附主角]
   与主角线的交错点：在哪类事件/冲突上和主角碰撞

   配角Y线：[如果有的话]
   ───────────
   ...

这些线不是各跑各的——它们交汇的点往往是最好的故事节点。
比如 [主角和X交汇的自然方式]。

你觉得这个拆解对吗？有没有要加的线、删的线、改的线？
```

用户可以修改、增减故事线。确认后进入下一轮。

#### 第 3 轮：分卷规划

```
有了故事线，来分卷。

每条角色线都有自己的起承转合，但卷是「所有线共享的时间容器」——

我的建议：

   第一卷（约 X-Y 章）：[卷名]
   ───────────
   功能：[引入/展开/转折/高潮/收束]
   主角线：从 [起始状态] → 到 [卷末状态]
   配角X线：从 [起始状态] → 到 [卷末状态]
   卷末钩子：[读者最想知道的]

   第二卷（约 X-Y 章）：[卷名]
   ───────────
   ...

   总计约 Z 卷，约 XXX 章。

你觉得这个分卷合理吗？章节数、卷的功能、节奏——都可以调整。
```

用户调整确认后，进入逐卷细化。

---

### 第二层：逐卷细化（可选，写作中可渐进补）

选择一卷开始细化（一般从第一卷开始，或者用户指定）：

```
细化第一卷。我们先聊这一卷的故事——

主角线在这一卷里，最重要的 3-5 个节拍是什么？
（不用列每章——只列关键转折，标注在卷内哪一段）

比如：
  - 卷前段：主角第一次 [关键事件]
  - 卷中段：[转折]
  - 卷末：[高潮/揭示]
```

#### 节奏检查

```
在往下细化之前，先看一下这一卷的节奏：

   [用简单的方式展示节奏曲线]
   比如：
   卷前段：中等（世界观建立）
   卷中段：高（第一次冲突）
   卷中后段：低-中（消化、过渡、铺垫）
   卷末：极高（卷高潮）

   ⚠️ 注意：[如果连续高强度或连续过渡，指出风险]

需要调整吗？
```

---

### 第三层：故事线交错（可选，写作中可渐进补）

逐卷节拍确认后，设计各卷内各段的角色线主次分配：

```
基于前面的逐卷节拍，来定各卷内哪些段落主推哪条角色线——

比如第一卷：
  - 卷前段：主推主角线，配角X线暂不在视野
  - 卷中段：主角线为主、配角X线为辅（X线事件影响到主角）
  - 卷末：两线交汇，配角X线反客为主

[此时可以给出 2-3 个交错方案选项]

目的：确保每条角色线不会长时间消失（超过 20 章读者会忘记），各角色线有节奏地交替。
```

---

### 第四层：伏笔布局（可选，写作中可渐进补）

逐卷确认节拍后，系统性考虑伏笔：

```
在大纲阶段先把伏笔框架搭起来——

我梳理了几个可以埋的伏笔方向：

   1. [方向A]：在第 X 卷中段暗示，第 Y 卷末揭示
   2. [方向B]：在第 X 卷前段暗示，第 Y 卷中段揭示
   ...

每个伏笔要回答三个问题：
- 埋的时候读者会注意到吗？（太明显=不是伏笔，太隐蔽=读者忘了）
- 回收的时候读者能想起来吗？（中间要轻碰 1-2 次提醒）
- 回收后有新问题吗？（好伏笔的回收不是结束，是打开新方向）

你觉得哪些方向值得埋？有没有你心里已经想好的伏笔？
```

---

### 第五层：角色弧光映射（可选，写作中可渐进补）

```
最后，把角色弧光叠到大纲上——

[主角] 在这一卷的变化：
  起点状态 → [催化剂位置（卷内哪一段）] → 终点状态

这个变化和剧情节拍对得上吗？
[如果角色弧光和剧情节拍有矛盾，指出]

[其他关键角色同理]
```

---

### 收尾：生成大纲文件

**第一层（全书总纲）确认后即可开写**。第二/三/四/五层为可选，写作中按需补。

```
✅ 全书总纲完成。

生成以下文件：

   outline/全书总纲.yaml      — 故事线/分卷/核心冲突
   outline/volumes/            — 每卷一个文件（卷边界/功能）

🎯 现在可以：
   1. /novel-studio:write 1 — 直接开始写第一章（细节层写作中按需补）
   2. 继续细化 — 逐卷节拍 / 故事线交错 / 伏笔布局 / 角色弧光

大纲有任何想改的随时 /novel-studio:outline 调整
```

---

## 调整已有大纲

如果用户已有大纲想调整：

```
📐 你想调整大纲的哪一层？

- 全书结构（增删故事线、调整分卷）
- 某一卷的节拍
- 故事线交错
- 伏笔布局
- 节奏调整
- 角色弧光
- 或者直接说你觉得哪里不对
```

调整只影响相关层面——改一条故事线的节拍不会重写全书总纲。

## 大纲检查

```
/novel-studio:outline 检查
```

检查项：
- 每条故事线是否有头有尾（不会中途消失）
- 故事线是否有超过 20 章未出现的（读者会忘了这条线）
- 伏笔埋设和回收是否匹配（埋了没收的、收了没埋的）
- 节奏是否有连续 5 章以上同强度
- 每卷结尾是否有钩子（读者为什么继续翻页）
- 角色弧光是否有催化剂事件推动（不是自然渐变）

## 反模式（禁止）

- ❌ 生成「第1章做什么→第2章做什么→...」的流水账大纲
- ❌ 把伏笔/节拍/弧光/交错钉死到具体章号——应到「第几卷+卷内前/中/后段」粒度
- ❌ 只有主角线，没有配角线
- ❌ 所有故事线各跑各的，没有交汇设计
- ❌ 全卷匀速——每章都是「推进」功能
- ❌ 不给用户选择，直接生成完整大纲
- ❌ 强制用户做完全部五层大纲才允许开写——总纲确认后即可写
- ❌ 用户说「主角和配角X的关系不太对」，你只改了一处却没检查所有交汇点
