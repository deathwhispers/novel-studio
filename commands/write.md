# /novel-studio:write

写指定章节。**不动笔直到你完全满意方向**——不限轮次的讨论、纠偏、细化，确认无误后才启动流水线。

## 核心原则

- **不定深度**：讨论可以进行 2 轮也可以进行 10 轮，直到你觉得方向对了
- **逐层纠偏**：每一轮都可以调整——「这个保留，那个换掉，结尾我想要另一种感觉」
- **确认即锁定**：你说「可以了，写吧」，流水线才启动
- **流水线中不打断**：启动后自动流转，中间不问你问题

## 用法

```
/novel-studio:write <章节号>
/novel-studio:write next          # 写下一章（自动计算章节号）
/novel-studio:write               # 等同于 /novel-studio:write next
```

## 对话流程

### 第一阶段：状态回顾

```
📖 当前状态（第 N-1 章结束时）：

   上一章发生了什么：[一句话梗概]
   主角处境：[当前位置/状态/压力]
   活跃伏笔：[列出正在发展的伏笔]
   读者最关心的问题：[列出待解答问题]
   章尾情绪：[上一章给读者留下的感觉]

你要接着写第 N 章吗？还是想先聊一下整体方向？
```

### 第二阶段：方向探索与纠偏（不限轮次）

**首轮**——先问用户想法：

```
在我想方案之前——这一章你有没有特别想写的东西？
某个场景、某段对话、某种感觉？

（模糊的描述也可以，不用是完整方案）
```

如果用户有想法 → 基于用户想法生成选项。
如果用户交给系统 → 基于当前故事状态生成选项。

选项保持简洁：

```
💡 第 N 章发展方向：

   选项 A：[方向名]
   ───────────
   核心：[一句话]
   关键事件：[2-3 个节点]
   章尾感觉：[读完时读者最想知道/最在意的]
   ✅ [一个优势]  ⚠️ [一个风险]

   选项 B：...
   选项 C：...

你可以单选、混合、或者提出自己的方案。
```

**纠偏循环**（关键——这是区别所在）：

用户做出选择后，**不直接启动流水线**，而是进入纠偏循环：

```
✅ 选 [A/B/C/混合方案]。

聊一下细节——比如：

- 场景 [X] 里 [角色] 的反应，你希望是偏 [A风格] 还是 [B风格]？
- [某个关键事件] 的处理，你有偏好吗？
- 章尾你想给读者什么感觉？[当前方案的感觉]，还是更 [另一种感觉]？
```

根据用户回答，给出调整后的细化方案：

```
好的，根据你说的，调整后的方向：

   [细化后的章节方向，标注调整过的部分]

还有什么要调整的吗？
```

用户可以继续纠偏——「这个场景不要」「那个角色多加一点」「结尾换这个」——每轮调整后都重新确认。**循环直到用户说「可以了，写吧」或等价信号。**

```
用户可能说的信号：
- 「可以了，写吧」「就这样」「开始写」「没问题了」「go」
- 如果上次说「可以了」但又补充了新想法 → 纳入后再次确认
```

### 第三阶段：剧情量评估（确认方向后）

```
预估本章：约 XXXX 字（目标 2000 字，范围 1600-2400）
```

如果预估超过 3000 字或关键事件 > 5 个：

```
⚠️ 这一章剧情量比较大，预估约 XXXX 字。

建议拆成两章：

   第 N 章：[前章方向] — 约 XXXX 字
   章尾：[前章落点]

   第 N+1 章：[后章方向] — 约 XXXX 字
   章尾：[后章落点]

你的想法？
- 拆分：先写第 N 章
- 不拆分：压缩剧情到 ~2000 字
- 你自己有别的想法
```

### 第四阶段：启动流水线

用户最终确认后：

```
✅ 方向锁定 → 启动流水线

📋 设计故事契约...
🎬 编排场景...
✍️ 写作中...
🔍 质量检查...
```

流水线中途的返修（Critic 判定）**自动处理**，不中断问用户。只报告最终结果：

```
✅ 第 N 章完成（XXXX 字）
   质量：通过 / 修复后通过（修了X处）
```

## 快速通道

如果你一上来就给出了非常具体完整的本章方案（剧情路径 + 关键事件 + 章尾落点），一句话确认后跳过纠偏循环，直接启动流水线。

## 断点恢复

如果上次 `/novel-studio:write` 中断了，重新执行时自动从断点继续。

## 反模式（禁止）

- ❌ 用户选了一个选项你就启动流水线——要问「还有什么要调整的？」
- ❌ 用户说「结尾不太对」你只改了结尾却不确认其他部分
- ❌ 纠偏了 3 轮就不耐烦了——没有上限
- ❌ 用户说了自己的想法，你却忽略并给出无关选项
- ❌ 发现剧情过载时自行删减事件而不告知用户
