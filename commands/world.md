# /novel-studio:world

打开世界观构建会话。适用于任何需要扩展或修订设定的场景。

## 用法

```
/novel-studio:world
```

## 支持的操作

Orchestrator 会确认你的意图：

| 你说 | 执行 |
|------|------|
| 「添加一个新角色」 | Architect 创建完整角色档案 |
| 「完善力量体系」 | Architect 扩展等级/规则/获取方式 |
| 「补世界观」 | Architect 扩展地理/势力/历史 |
| 「设定有冲突」 | Architect 检测+建议修复方案 |
| 「看看还有什么缺的」 | Architect 全面审视已有 canon |

## 示例

```
/novel-studio:world

[Orchestrator] 你想做什么？
→ 添加一个新角色

[Orchestrator] 角色定位？
→ 主角的对手，同一宗门的师兄，一直怀疑主角的秘密

🌍 Architect 正在创建角色「XX」…

✅ 角色已添加：
   - 姓名：XX
   - 定位：主角的对手/同一宗门师兄
   - 核心特质：观察力极强、心机深沉、有自己的正义逻辑
   - 语言特征：礼貌但疏远、喜欢用反问、从不直接威胁
   - 与主角的关系：怀疑→试探→（待发展）
   - 已写入：setting/characters/XX.md

⚠️  检测到潜在设定冲突：
   - XX的等级（金丹中期）高于主角（筑基后期），但大纲第15章计划让主角战胜他
   → 建议：在战胜前铺垫主角的隐藏优势（系统辅助/环境利用/XX的弱点），或调整XX等级到筑基巅峰

📋 角色已就绪。随时 /novel-studio:write N 继续写作。
```

## 渐进原则

- **只创建当前卷需要的内容**：不要为 500 章后的反派写完整设定
- **可推翻**：未在正文中出现的设定标注为「未锁定」
- **已锁定不可改**：正文中已出现的设定，修改需评估对已写章节的影响
