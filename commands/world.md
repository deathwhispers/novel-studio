# /novel-studio:world

世界观构建会话。**每个设定都是深度对话的产物**——不限轮次、提供选项、允许自定义，直到你对每个细节都满意。

## 核心原则

- **一设定一对话**：每个角色/每条规则/每个势力都是独立的多轮对话产物
- **多选项 + 自定义**：每个决策点提供 2-4 个选项，你也可以自己写
- **不限轮次**：一个角色聊 5 轮还是 20 轮，取决于你，不取决于系统预设
- **确认才写入**：每个设定只有你明确说「可以了」才落盘

## 用法

```
/novel-studio:world
```

## 对话流程

### 入口：你想做什么？

```
🌍 你想做什么？

直接说就行，比如：
- 「加一个角色」
- 「完善力量体系」
- 「世界观还缺一些东西」
- 「检查设定冲突」
- 或者描述你的想法，不用刻意归类
```

---

### 分支 A：添加角色

每个角色是一场独立的多轮对话。不要一次聊完所有问题——**一次只聊一个维度**。

#### 第 1 轮：角色的故事功能

```
先不聊名字和长相——这个人存在的意义是什么？

比如：
- 他/她要推动什么？
- 他/她给主角制造什么麻烦（或提供什么帮助）？
- 没有这个人，故事会少了什么？
```

用户回答后，给出 1-2 句话复述理解，让用户确认。

#### 第 2 轮：核心矛盾

```
这个人的核心矛盾是什么？

比如——
- 想要 [X]，但 [Y] 在阻止他/她
- 表面上是 [A]，实际上是 [B]
- 最相信 [某件事]，但这件事可能是错的

（如果用户说「没想好」，给出 2-3 个选项供选择或启发）
```

#### 第 3 轮：外表与第一印象

```
别人第一次见到他/她，会注意到什么？

提供几个方向你感受一下：
  A. [具体的外表/气质描述 —— 基于前面聊的内核设计]
  B. [另一种可能]
  C. [另一种可能]
  或者你自己描述。

选哪个方向？或者你觉得都不对，说说你自己的想法。
```

#### 第 4 轮：说话方式

```
他/她怎么说话？

  A. [基于角色内核的说话风格 —— 给出具体示例对话]
  B. [另一种风格 + 示例]
  C. [另一种风格 + 示例]
  或者你自己写一段他/她会说的话。

哪种感觉更对？
```

#### 第 5 轮：与已有角色的关系

```
他/她和已有角色的关系？

[列出已有角色名]
- 和主角的关系核心是什么？
- 和其他角色的关系？

  A. [关系设定建议]
  B. [另一种可能]
  或者你自己说。
```

#### 第 6 轮：整体确认

```
好的，整理一下这个角色的完整画像：

   姓名：[用户说的 / 待用户命名]
   故事功能：[提炼]
   核心矛盾：[提炼]
   外表/第一印象：[提炼]
   说话方式：[提炼 + 示例对话]
   与主角关系：[提炼]
   与其他角色关系：[提炼]

   ⚠️ 设定检查：[如果有冲突则指出]

这个画像准确吗？有什么要改的？
```

用户可以调整任何一项。调整完重新确认。循环直到用户满意。

用户确认后写入 `setting/characters/[角色名].yaml`。

---

### 分支 B：完善力量体系

力量体系的每个层级/规则都是独立对话。

#### 第 1 轮：确认范围

```
力量体系目前的状态：[报告已有内容]

你想从哪个方面入手？
- 等级划分（几级、叫什么、怎么升）
- 能力的类型和规则
- 力量的社会影响
- 限制和代价
- 其他
```

#### 第 2 轮：大框架（以「等级划分」为例）

```
先不纠结细节——你脑子里的大框架是怎样的？

比如：
- 一共几个大境界/等级？
- 每级之间怎么跃升？（修炼/任务/系统奖励/奇遇/击杀）
- 有人卡在某个等级一辈子过不去吗？

可以先画大框，不需要每个等级都具体。
```

用户说完后：

```
你的框架我理解是：[复述]

基于这个框架，我补充几个方向你感受一下：

  完整的等级体系方案 A：
  ───────────
  [基于用户框架 + 品类配方设计的体系]

  完整的等级体系方案 B：
  ───────────
  [另一种设计方向]

  完整的等级体系方案 C：
  ───────────
  [另一种设计方向]

选哪个？或者混合？或者你自己有更具体的想法？
```

#### 第 3+ 轮：逐级细化

用户选择大框架后，逐一细化：

```
先聊第一级（[等级名]）：

  这个等级的人——
  - 能做到什么？（给出 2-3 个具体能力描述选项）
  - 做不到什么？（给出 2-3 个限制选项）
  - 在社会中是什么地位？（给出 2-3 个描述选项）

你可以选我的选项，也可以自己写。
```

逐级推进，用户随时可以说「剩下的我自己想」或「先就这样」。剩下的标注「待细化」。

### 分支 C：扩展世界观

每个维度独立对话，每次提供多选项。

#### 示例：扩展「势力」

```
你想设定哪些势力？

当前已有的：[列出已有势力/组织]

先聊第一个势力。它是干嘛的？

  A. [势力类型 + 一句话描述]
  B. [另一种]
  C. [另一种]
  或者你自己说。
```

选定后逐层细化——规模、核心目标、与主角的关系、内部结构——每个都提供选项或让用户自定义。

---

### 分支 D：设定冲突检测

```
好的，我来检查现有设定之间的冲突。

正在梳理...
```

逐条列出冲突，每条附带 2-3 个修复方案选项：

```
⚠️ 冲突 1：[描述]

   修复方案：
     A. [方案A —— 说明谁让步、影响什么]
     B. [方案B —— 说明谁让步、影响什么]
     C. 保持现状（需要在故事中解释）

选哪个？
```

---

### 分支 E：全面审视

```
梳理当前完成度：

   角色：[X/Y 个主要角色已完善]
   力量体系：[完成度评估]
   世界观：[完成度评估]

最需要补充的是 [最薄弱的一环]，建议优先处理。

你觉得呢？或者你有想先补的方向？
```

### 分支 F：系统设计（系统文专属）

系统文除力量体系外，还要设计系统本身。每个维度独立对话 + 多选项。

#### 第 1 轮：系统类型

```
先确定系统的核心机制——

  主线是哪种类型？
    A. 任务流（系统发布任务，完成给奖励）
    B. 签到流（每日签到，地点/时机影响奖励）
    C. 抽奖流（完成任务得抽奖次数，随机奖励）
    D. 商城流（系统内有兑换/购买机制）
    E. 综合型（主线 + 辅线，如任务为主 + 签到为辅）

或者你自己描述。
```

#### 第 2 轮：系统人格

```
系统说话是什么口吻？

  A. 高冷（惜字如金，只在关键时刻出声）
  B. 吐槽（毒舌，爱拆台，和主角斗嘴）
  C. 引导型（温和，像新手教程一样讲解）
  D. 无感情播报（机械、中立，纯信息）

每种给你一句示例台词，你感受一下哪种对味。
```

#### 第 3 轮：核心面板与字段

```
基于系统类型，列出本书剧情会出现的面板：

  个人信息面板（等级/经验/属性）
  任务面板（任务列表/进度/奖励）
  ...（根据剧情补充）

逐面板确认字段。你勾选/增删，锁定后不再随意增改。

（锁定后同步到 setting/系统面板.md，全书统一）
```

## 渐进原则

- **最小可用**：只创建当前卷需要的设定，不为遥远的未来预建
- **主角中心**：世界观从主角的感知范围出发，不写百科全书
- **可推翻**：未在正文中出现的设定标注「未锁定」，可修改
- **已锁定不可改**：正文中已出现的设定，修改需评估影响

## 反模式（禁止）

- ❌ 用户说「加个角色」你就生成完整的姓名/年龄/外貌/等级/背景故事
- ❌ 不给选项、不问意见，直接生成并写入
- ❌ 选项都是一种风格的变体——要有真正的差异化
- ❌ 聊了两轮就觉得够了——用户没确认就继续聊
- ❌ 用户选了一个选项你就把所有细节自己填了——逐项确认
- ❌ 世界观扩展时从宇宙起源开始写
- ❌ 检测到设定冲突后自行修改
