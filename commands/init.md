# /novel-studio:init

初始化新项目。**不直接生成任何内容**——先对话理解你的创作意图，再按需创建。

## 核心原则

- **先问后建**：不理解你要写什么之前，不创建任何文件
- **逐步收敛**：每轮聚焦 1-2 个问题，不搞问卷轰炸
- **复述确认**：每轮对话后复述理解，你确认了再进入下一轮
- **按需生成**：对话结束后只创建你需要的内容，不过度生成

## 用法

```
/novel-studio:init
```

## 对话流程

### 第一轮：创作的起点

先问一个开放问题——你为什么想写这个故事？

```
💬 先聊聊你想写的故事吧。

可以不完整、可以只是一些碎片——
比如某个场景、某个人物、某种感觉。
或者你对市面上某类书不满意，想自己写一本不一样的。

随便说，不用太正式。
```

等待用户回答。根据回答提取关键信息，然后追问最值得深挖的方向。

### 第二轮：故事的核心体验

根据第一轮的回答，追问 1-2 个关键问题：

```
根据你说的，我想再确认一下：

你希望读者读完这本书后，
心里留下什么感觉？

（比如：爽、燃、虐、悬疑感、被治愈、想了很多天）
```

等待用户回答。复述理解：

```
我理解的是：
- 你想写一个[用户描述提炼]的故事
- 读者体验的核心是[用户说的感觉]
- 与众不同的点是[如果用户提到了]

对吗？
```

### 第三轮：品类和基调

根据前两轮的内容，**先给出你的判断和建议**，再让用户确认或修正：

```
从你说的来看，天然适合 [品类建议]——

但基调我想确认一下：
是偏 [严肃/轻松/热血/黑暗/搞笑] 的？
还是想混合？比如 [具体例子]。
```

等待用户确认或修正。

### 第四轮：主角的灵魂

问最关键的几个问题——不是问身份和设定，是问人物的矛盾：

```
聊聊主角吧。不用想名字和设定，就说：

1. 他/她最想要什么？
2. 他/她最怕什么？
3. 这两个之间有什么矛盾？

（比如：最想变强保护所有人，但每次变强都会伤害身边的人）
```

等待用户回答。复述你理解的人物内核，确认。

### 第五轮：篇幅和写作模式

```
最后确认一下：

篇幅：[短篇<50章 / 中篇50-200章 / 长篇200-500章 / 超长篇>500章]
      推荐：[根据前面内容推荐篇幅]

模式：[商业连载 / 类型长篇]
      推荐：[根据前面内容推荐模式]

你觉得呢？
```

### 收尾：基于对话生成项目

用户确认所有内容后，**才**开始创建文件：

```
✅ 聊清楚了。基于我们的对话，我整理一下：

   书名建议：[如果用户提到了]
   品类：[确认的品类]
   核心体验：[确认的读者感受]
   主角内核：想要[X]，害怕[Y]，矛盾是[Z]
   篇幅/模式：[确认的篇幅和模式]

现在创建项目骨架——
只会创建和上面这些直接相关的文件，
不确定的标注「待确认」，后面 /novel-studio:world 再补。
```

然后执行 workflow：Architect 创建骨架 → StateManager 初始化状态。

## 快速通道

如果你一上来就给出了非常完整的信息（故事概念 + 主角 + 品类 + 篇幅），我会用自己的话复述一遍，确认无误后直接创建项目，跳过逐轮对话。

## 反模式（禁止）

- ❌ 用户说了一句你就开始生成角色档案
- ❌ 一次性抛出 5 个问题让用户填表
- ❌ 用户还没确认理解就跳到「创建文件中...」
- ❌ 生成用户没要求的设定内容
