# 番茄系统爽文 — 常见变体

## 一、签到流

**核心设定**：主角通过每日签到获得奖励。签到地点/时机影响奖励品质。

**典型开局**：
> 穿越到修真界成为杂役弟子，觉醒「万界签到系统」——在不同的地点签到获得不同的奖励。
> 在藏经阁签到：获得失传功法。
> 在宗门秘境签到：获得上古丹药。
> 在被追杀时签到：获得保命能力。

**爽点引擎**：
- 签到地点解锁 = 主角探索新地图的动力
- 奖励品质对比 = 读者期待「下一站签什么」
- CD 限制 = 不是无限签到，有冷却/次数/条件

**节奏特点**：每日签到 = 天然日更节奏。签到 + 日常 + 小爽点。

**常见风险**：
- 签到变流水账（每天签到了事） → 签到必须有对应的剧情消耗
- 奖励膨胀（越签越离谱） → 控制奖励梯度

## 二、抽奖流

**核心设定**：主角完成系统任务获得抽奖次数，随机获得不同品质的物品/能力。

**典型开局**：
> 完成新手任务获得一次「青铜抽奖」→ 抽到垃圾技能。
> 完成限时任务获得一次「黄金抽奖」→ 抽到关键道具。
> 读者永远不知道下一次抽到什么——期待感 = 追读动力。

**爽点引擎**：
- 抽奖前的期待积累（读者猜会出什么）
- 抽奖结果的意外感（好东西/搞笑垃圾/隐藏品质）
- 品质分级制造落差（青铜→白银→黄金→钻石→传说）

**节奏特点**：抽奖 = 章节高潮或章尾钩子。不要每一章都抽（频率太高会贬值）。

**常见风险**：
- 全凭运气没有实力（抽到好货就赢，抽不到就等死） → 主角必须有自己的能力基础
- 品质泛滥（三天就抽到传说） → 控制高品质出现频率

## 三、任务流

**核心设定**：系统发布任务，主角完成获得奖励。任务有评分机制（S/A/B/C/D），评分影响奖励。

**典型开局**：
> 「叮！主线任务发布：三天内突破炼气期。奖励：XXX。失败惩罚：系统关闭。」
> 主角必须在时间限制内找到突破的方法——同时还要应付日常冲突。

**爽点引擎**：
- 任务难度 vs 主角手段的反差
- 评分机制的追求（读者想看到 S 级评价）
- 限时任务的紧迫感
- 隐藏任务的意外触发

**节奏特点**：任务 = 剧情引擎。一个大任务可以跨 2-3 章。

**常见风险**：
- 任务套路化（每个任务都是「完成→奖励→下一个任务」） → 增加任务之间的因果关联
- 惩罚无感（失败惩罚从未触发） → 偶尔让主角付出真实代价

## 四、神豪流

**核心设定**：主角获得无限金钱/资源系统，通过消费获得能力或影响力。

**典型开局**：
> 「叮！神豪系统绑定成功。初始资金：1000万。消费返利：每消费1万元获得1积分。」
> 主角必须在规定时间内花完初始资金——花得越多越强。

**爽点引擎**：
- 消费 = 变强（花钱就是修炼）
- 身份逆转（穷小子变富豪）
- 资源碾压（用钱砸死对手）

**节奏特点**：消费场景 = 爽点。积分兑换 = 升级。

**常见风险**：
- 只会花钱不会挣钱（坐吃山空） → 消费必须有产出（投资/购置资产/培养势力）
- 用钱解决一切（没悬念） → 有些问题钱解决不了（人心/规则/时间）

## 五、吞噬流

**核心设定**：主角通过吞噬/吸收/炼化他人的能力或物品来成长。

**典型开局**：
> 「叮！吞噬系统激活。当前等级：F。吞噬 F 级以上目标可获得能力碎片。」
> 主角必须先靠自己战胜目标，再用系统吞噬——不是坐享其成。

**爽点引擎**：
- 获得新能力的快感
- 能力组合的创造性
- 越级吞噬的成就感

**节奏特点**：战斗→吞噬→消化→新能力→下一战。每个循环 3-5 章。

**常见风险**：
- 变种人综合征（太多能力但都用不好） → 限制能力槽位，必须取舍
- 吞噬 = 无敌（没有代价） → 吞噬有副作用（杂质/记忆/人格侵蚀）

## 如何选择变体

| 如果你想要 | 选择 |
|-----------|------|
| 最稳的开局，日更节凑稳定 | 签到流 |
| 最大的随机性和期待感 | 抽奖流 |
| 最强的剧情驱动力 | 任务流 |
| 最直接的爽感（花钱打脸） | 神豪流 |
| 最多样的能力设计空间 | 吞噬流 |

**可以组合**：任务流 + 抽奖流（完成任务获得抽奖次数）= 最稳的组合。
