# 番茄系统爽文 — 章节节奏模板

## 单章节奏基线

```
章首钩子 (500字)
  ├── 方式一：系统通知/任务弹窗/异常数值
  ├── 方式二：上一章章尾问题的直接后果
  └── 方式三：反常细节（不该出现的人/事/物）

主体推进 (1500字)
  ├── 加压/冲突展开 (800字)
  │   主角试图完成任务 → 遭遇阻力 → 第一次尝试失败或受挫
  └── 破局/逆转 (700字)
      主角找到突破点（新能力/隐藏信息/规则漏洞）→ 实施 → 成功

爽点兑现 (300字)
  ├── 系统奖励通知
  ├── 反派/旁观者的震惊反应（见证者视角）
  └── 主角获得可感知的变化（能力/状态/关系/资源）

章尾钩子 (200字)
  ├── 新任务弹出（最常用）
  ├── 隐藏条件触发
  ├── 更大威胁的端倪
  └── 关系变化的余波
```

## 爽点类型轮换

为避免重复感，不同类型的爽点应该轮换出现：

| 爽点类型 | 占比 | 章节示例 |
|---------|------|---------|
| 能力兑现 | 35% | 主角用新技能打败对手 |
| 认知翻转（打脸） | 30% | 旁人从看不起到震惊 |
| 资源获取 | 20% | 获得稀有道具/巨额财富/关键信息 |
| 关系支援 | 10% | 重要角色站队/认可/追随 |
| 公道回收 | 5% | 被夺走的东西收回 |

**轮换规则**：同一种爽点类型不要连续出现 2 章以上。

## 章节功能轮换

```
章节类型轮换建议（10章周期）:

推进 ─→ 推进 ─→ 高潮 ─→ 余震 ─→ 推进
  │                          │
  └── 揭示 ─→ 推进 ─→ 推进 ─→ 高潮 ─┘

统计：
- 推进章：5/10（推动主线或副线前进一步）
- 高潮章：2/10（阶段性的爽点集中释放）
- 余震章：1/10（高潮后果的消化，关系/情绪变化）
- 揭示章：1/10（揭示新信息，改变读者对故事的理解）
- 过渡章：1/10（必要的场景切换或时间跳跃）
```

## 字数节奏

```
短章（1500-2000字）：纯爽点章、过渡章
标准章（2000-3000字）：推进章、揭示章
长章（3000-4000字）：高潮章、卷末章

每章字数波动不超过 ±30%，避免一章1500字下一章4000字。
```

## 系统出现频率

| 章节位置 | 系统出现时机 |
|---------|------------|
| 章首 | 新任务/任务倒计时/系统评价 |
| 章中 | 任务进度更新/隐藏条件提示 |
| 章尾 | 奖励通知/新任务/系统升级提示 |

系统不一定每处都出现，但每章至少出现 1 次。

## 10 章节奏样本

```
第 1 章：系统激活 + 初始任务 + 初次打脸（高潮）
第 2 章：任务完成 + 第一次奖励 + 小爽点（推进）
第 3 章：日常冲突 + 限时任务 + 紧迫感（推进）
第 4 章：第一次受限 + 用智慧破局 + 能力兑现（推进→高潮）
第 5 章：余震 + 关系变化 + 新线索（余震）
第 6 章：探索新线索 + 遭遇新对手（推进）
第 7 章：隐藏任务触发 + 奖励超预期 + 打脸（高潮）
第 8 章：系统隐藏功能揭示 + 世界观扩展（揭示）
第 9 章：消化新信息 + 日常互动 + 关系推进（过渡→推进）
第10章：第一次中升级 + 身份提升 + 卷末钩子（高潮）
```
