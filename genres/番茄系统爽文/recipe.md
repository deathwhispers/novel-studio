# 番茄系统爽文 — 品类配方

## 品类定义

**系统爽文** = 主角获得一个系统（任务/签到/抽奖/商城），通过完成系统任务快速成长，在过程中不断打脸、升级、获取资源的故事。

**番茄平台的爽文特点**：
- 快节奏（每章 2000-3000 字，必须有信息增量）
- 强爽点（每章至少一个「读者想看到的」时刻）
- 低门槛（世界观不需要宏大，主角快速出新手村）
- 追读导向（章尾必须让人想点下一章）

## 核心读者预期

| 读者要的 | 具体含义 | 违反后果 |
|---------|---------|---------|
| 每章至少一个爽点兑现 | 不能让读者读完觉得「这章什么都没发生」 | 弃书 |
| 主角快速成长 | 不能压级超过 10 章 | 读者骂「水」 |
| 打脸要有见证者 | 主角打了反派的脸，必须有人看到并震惊 | 爽感打折 |
| 系统是核心优势 | 系统不能长期失效/被限制/被超越 | 品类承诺破裂 |
| 奖励有代价 | 每次获得必须有付出（努力/风险/选择） | 读者觉得假 |

## 核心循环

```
触发（日常/任务/危机）
  → 任务下达（系统发布任务）
  → 阻力出现（敌人/环境/规则/信息差）
  → 主角破局（能力+智慧+系统奖励的组合）
  → 奖励兑现（能力/物品/信息/权限）
  → 打脸时刻（反派/旁观者的震惊反应）
  → 新任务暗示（系统弹出新任务/更大的挑战露出端倪）
```

单个循环可以跨 1-3 章。不要让循环太快（一章 3 个任务 → 像流水账）或太慢（一个任务写 5 章 → 读者疲惫）。

## 系统设计画布

| 维度 | 选项 | 番茄平台偏好 |
|------|------|-------------|
| 系统类型 | 任务/签到/抽奖/商城/吞噬/神豪 | 任务+签到（最稳） |
| 触发方式 | 每日/随机/被动/主动 | 被动触发+主动查看 |
| 任务类型 | 日常/主线/隐藏/限时/惩罚 | 日常+限时（制造紧迫感） |
| 奖励类型 | 能力/物品/信息/权限/货币 | 能力+物品（最直观） |
| 系统人格 | 机械/调侃/高冷/傲娇/无 | 调侃（番茄平台特色） |
| 系统限制 | 冷却/代价/隐藏规则/等级锁 | 有代价（防止无敌文） |

## 力量等级体系

### 必选项
- 必须有明确的等级名称和数量（通常 5-10 个大等级）
- 每个等级对应：能力范围、社会地位、解锁内容
- 主角当前等级必须低于遇到的挑战（否则没悬念）

### 升级节奏

| 升级级别 | 频率 | 说明 |
|---------|------|------|
| 小升级（技能/资源） | 每 3-5 章 | 新技能、新道具、资源获取 |
| 中升级（段位/身份） | 每 10-15 章 | 突破大境界、身份提升 |
| 大升级（世界观层级） | 每卷 1-2 次 | 进入新世界/新位面/新势力范围 |

## 禁忌清单

以下情况必须避免：

| 禁忌 | 检查方法 |
|------|---------|
| 主角连续 3 章无主动行为（被动挨打/等待救援/纯旁观） | 检查每章主角的选择次数 |
| 系统连续 5 章不出场 | 检查系统通知/任务/界面的出现频率 |
| 反派智商突然下降来成全主角 | 检查反派的计划是否前后一致 |
| 奖励无代价（白给） | 每次获得必须对应付出 |
| 主角突然变强无过程 | 升级必须有门槛和过程 |
| 打脸对象是路人（没有铺垫） | 打脸对象最好是有前文的角色 |
| 同一个爽点模式连续 3 章 | 轮换能力兑现/认知翻转/资源获取 |
