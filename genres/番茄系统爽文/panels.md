# 番茄系统爽文 — 系统面板模板

> 本文件定义系统爽文反复出现的几个固定通用面板。Writer 遇到对应场景时**直接套用模板**，保证全书系统界面格式统一。
> 面板格式规范遵循 `references/web-novel-formatting.md`：系统文字【】包裹、每个字段单独一行、数字/括号/斜杠用半角、冒号用全角。

## 使用规则

1. **字段固定**：模板中的字段顺序和命名不可改。缺少某字段时留空或省略该行，不新增字段。
2. **格式固定**：每行一个字段，【】包裹，不把多个字段挤一行。
3. **命名统一**：面板标题（如「个人信息」「任务发布」）全书一致，同一面板不出现多个叫法。
4. **数值写法**：数字用半角阿拉伯数字，进度用 `x/y`，百分比用 `(67/100)`，时间用 `HH:MM:SS`。

## 面板模板

### 1. 个人信息面板（属性总览）

**触发**：主角查看自身状态、升级后确认、战斗前审视、获得属性加成。

```
【个人信息】
【姓名：林尘】
【等级：炼气三层（35/100）】
【力量：18】
【敏捷：15】
【精神：22】
【剩余积分：320】
```

**字段说明**：属性种类（力量/敏捷/精神等）由作品力量体系决定，init 时在 `setting/系统面板.md` 中锁定。等级格式固定为「境界名 + 进度」。

### 2. 任务面板（任务发布）

**触发**：系统发布新任务。

```
【任务发布】
【任务名：寻找失落的玉佩】
【难度：困难】
【时限：72:00:00】
【奖励：经验 +5000，玄铁剑 ×1】
【失败惩罚：无】
```

**字段说明**：`难度` 取值由作品确定（如 简单/普通/困难/地狱 或 S/A/B/C）。`失败惩罚` 为「无」时也保留该行，保证格式一致。

### 3. 任务进度面板

**触发**：任务进行中，主角查看进度。

```
【任务进度】
【任务名：寻找失落的玉佩】
【当前进度：1/3】
【剩余时限：45:12:08】
```

### 4. 系统提示/通知

**触发**：奖励到账、警告、系统事件、签到、升级。

```
【叮——任务完成，奖励已发放】
【恭喜宿主！获得：筑基丹 ×3，经验 +5000】
【警告：灵力不足，无法使用此技能】
【签到成功！获得：灵石 ×100】
```

**格式规则**：提示语开头用「叮——」或「警告：」「恭喜」等固定前缀，内容紧跟，不换行。多条提示各自成行。

### 5. 技能面板

**触发**：主角查看/学习/升级技能。

```
【技能列表】
【灵目术（初级）：看破伪装，消耗灵力 5】
【剑气诀（中级）：剑气外放，消耗灵力 20】
【御风术（未解锁）：需要等级 筑基期】
```

**字段说明**：每行一个技能，格式为「技能名（品级）：效果描述，消耗/条件」。未解锁技能标注「（未解锁）」。

### 6. 背包/物品面板

**触发**：查看物品、获得物品、使用物品。

```
【背包】
【玄铁剑 ×1（中品）】
【回气丹 ×5】
【灵石 ×300】
【神秘玉佩 ×1（任务物品）】
```

**字段说明**：每行一个物品，格式为「物品名 ×数量（品质/备注）」。无品质或备注时省略括号部分。

## 面板组合示例

写作中一个完整任务循环可能涉及多个面板，按剧情顺序出现：

```
【任务发布】
【任务名：寻找失落的玉佩】
【难度：困难】
【时限：72:00:00】
【奖励：经验 +5000，玄铁剑 ×1】
【失败惩罚：无】

林尘扫了一眼任务面板。玉佩？又是这个地名。

【任务进度】
【任务名：寻找失落的玉佩】
【当前进度：0/1】
【剩余时限：71:58:32】

他合上面板，披上外套出门。

【叮——检测到宿主已到达任务地点】
```

## 反模式（禁止）

- ❌ 把多个字段挤一行：`【姓名：林尘 等级：炼气三层 力量：18】`
- ❌ 改变面板标题叫法：同一面板一会儿叫「个人信息」一会儿叫「属性面板」
- ❌ 系统提示不用【】包裹，直接写成叙述句
- ❌ 任务面板遗漏固定字段（如缺「失败惩罚」行）
- ❌ 数字写法不统一（一会儿 `1/3` 一会儿 `三分之一`）
