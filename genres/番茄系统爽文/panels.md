# 番茄系统爽文 — 系统面板模板

> 定义系统爽文反复出现的固定面板。Writer 遇到对应场景时**直接套用**，保证全书系统界面格式统一。
> 格式规范遵循 `references/web-novel-formatting.md`：系统文字【】包裹、每字段单独一行、数字/括号/斜杠半角、冒号全角、面板顶格不缩进。

## 使用规则

1. **字段固定**：模板字段顺序和命名不可改。缺字段时留空或省略该行，不新增字段。
2. **命名统一**：面板标题全书一致，同一面板不出现多个叫法。
3. **简洁优先**：只写剧情需要的字段，能省则省。字段越少，界面越干净。
4. **数值写法**：数字半角，进度 `x/y`，等级进度 `(35/100)`，时间 `HH:MM:SS`。

## 核心面板（所有系统文通用）

### 1. 个人信息面板（人物面板）

主角查看状态、升级、加点、战斗前。升级或加点后，直接更新此面板展示最新状态。

```
【个人信息】
【姓名：林尘】
【等级：炼气三层（35/100）】
【力量：18】
【敏捷：15】
【精神：22】
【积分：320】
```

升级后（等级跃迁 + 属性变化，同一个面板，无需独立加点面板）：

```
【个人信息】
【姓名：林尘】
【等级：炼气四层（5/100）】
【力量：20】
【敏捷：16】
【精神：22】
【积分：320】
```

> 属性种类（力量/敏捷/精神等）由作品定，init 时锁定。只列剧情需要的属性，不必面面俱到。

### 2. 任务面板

系统发布任务（完整）或任务进行中（精简），同一面板两种状态。

```
【任务：寻找失落的玉佩】
【难度：困难】
【时限：72:00:00】
【奖励：经验 +5000，玄铁剑 ×1】
【失败惩罚：无】
```

进行中只显示进度和剩余时限：

```
【任务：寻找失落的玉佩】
【进度：1/3】
【剩余时限：45:12:08】
```

### 3. 系统提示/通知

奖励到账、警告、事件。一行一条，不换行。

```
【叮——任务完成，奖励已发放】
【警告：灵力不足，无法使用此技能】
【签到成功！获得：灵石 ×100】
```

### 4. 背包面板

查看、获得、使用物品。

```
【背包】
【玄铁剑 ×1】
【回气丹 ×5】
【灵石 ×300】
```

### 5. 技能面板

查看、学习、升级技能。

```
【技能】
【灵目术（初级）：看破伪装】
【剑气诀（中级）：剑气外放】
【御风术（未解锁）：需炼气五层】
```

## 扩展面板（流派/场景专属，按需选用）

### 6. 签到面板（签到流）

每日签到 / 地点签到。

```
【签到成功】
【连续签到：3 天】
【获得：灵石 ×100】
```

```
【签到成功】
【地点：藏经阁】
【获得：失传功法 ×1】
```

### 7. 抽奖面板（抽奖流）

```
【抽奖结果】
【品质：白银】
【获得：玄铁剑 ×1】
```

### 8. 商城面板（神豪流/积分流）

```
【商城】
【筑基丹 ×1：500 积分】
【回气丹 ×10：200 积分】
```

### 9. 绑定面板

系统绑定宿主/物品/目标。

```
【系统绑定】
【目标：林尘】
【进度：100%】
【绑定成功】
```

## 反模式（禁止）

- ❌ 把多个字段挤一行：`【姓名：林尘 等级：炼气三层】`
- ❌ 同一面板多个叫法：一会儿「个人信息」一会儿「属性面板」
- ❌ 系统提示不用【】包裹
- ❌ 堆砌字段：个人信息面板列 10 个属性，只列剧情需要的
- ❌ 数字写法不统一（`1/3` 一会儿 `三分之一`）
