# 迪化流 — 品类配方

## 品类定义

**迪化流** = 都市普通人主角 + 长期目标式系统 + 配角疯狂脑补/自我攻略的核心机制。主角因为系统任务做出的"反常行为"（反复做普通人不该做的事、对到手的好处无欲则刚、状态与他"普通人"的身份拧着来），被身边人一步步解读成"隐藏得很深的豪门大佬在微服做事"；主角澄清反而被当成更深沉的伪装（越描越黑）；换新招自证时，新行为又被误读，把结果推向自己原本目的的反方向——最终阴差阳错地兑现出更大的资源与地位。

> **流派通用，不绑定单本书**：本配方定义的是"迪化机制"这一流派的通用规则。系统任务的具体行为题材（相亲、饭局、签单、出差等）、主线目标、里程碑规则，都由每本书在 init 时按下文画布实例化——文中任何具体任务名都只是示例，不是默认设定。

**三个不可动摇的承诺**：
1. **澄清必然失败**——主角每次解释都会被解读成"更高深的伪装"，误会只升不降。
2. **主角不主动装**——爽感来自旁观者的脑补和敬畏的层层加码，不是主角自吹。
3. **反方向要有结果**——每次换招把事推向原意反方向时，结果要么歪打正着，要么是逗趣的弄巧成拙，但不能空转。

**番茄平台的爽文特点**：
- 快节奏（每章 2000-3000 字，必须有信息增量）
- 强误会（每章至少一个"脑补升级/误会兑现"的可见时刻）
- 低门槛（都市背景，读者零理解成本；系统只是长期目标，不是战力）
- 追读导向（章尾必须让读者想知道"误会还会滚成什么样"）

## 核心读者预期

| 读者要的 | 具体含义 | 违反后果 |
|---------|---------|---------|
| 每章至少一次脑补升级 | 配角的解读必须比上一章更进一步（留意 → 忌惮 → 敬畏 → 传说），不能原地打转 | 误会停滞 = 这章什么都没发生 |
| 澄清必然失败 | 主角一解释就被解读成"更深的伪装"，是品类承诺 | 澄清成功 = 承诺破裂，读者泄气 |
| 反方向要有落点 | 换招后被推向原意反方向的结果，得歪打正着或有喜感代价 | 主角徒劳两章无回报 = 憋屈没爽感 |
| 脑补要自洽 | 旁观者推演必须有读者能接受的证据链，顺着主角的行为细节发疯 | 为脑补而脑补 = 出戏 |
| 爽点靠外界反应 | 主角不主动装，爽感是旁观者越来越怕/敬/跪的过程 | 滑向装逼流，品类走样 |
| 露馅风险永远存在 | 误会随时可能被戳穿的张力要在，不能金身不破 | 无悬念 = 追读动力清零 |

## 核心循环

```
普通举动 / 系统任务行为（外人眼里的"反常"）
  → 旁观者注意到 + 开始脑补（第一层解读）
  → 自我攻略加码（"他一定在考验我 / 这是布局"）
  → 主角澄清原意
  → 澄清被解读成"更高深的伪装"（越描越黑，势能不降反升）
  → 主角换新招自证 / 纠偏
  → 新招行为再度被误读 + 结果被推向原意反方向
  → 阴差阳错 / 歪打正着（虚惊、意外收获、更大的误会）
  → 新任务 / 新小事（循环重启，势能进位）
```

单个循环通常 1-2 章。不要让循环太快（一章三次脑补 → 像流水账）或太慢（一个误会写 5 章 → 读者嫌挤牙膏）。

## 系统设计画布

迪化流的系统是**长期目标式**，不是日常任务流水线。它只提供"主线进度"和少量调味任务，角色吃重的是误会戏，不是面板戏。

| 维度 | 选项 | 迪化流偏好 |
|------|------|-----------|
| 任务形态 | 次数达成型（完成 N 次 X）/ 达标型（攒够 X）/ 里程碑型 | 次数达成型为主（进度条直观、节奏稳定），X 的具体题材按书换皮 |
| 主线目标 | 大奖（千亿 / 实业 / 地位），全程唯一主线 | 大奖要自带一个"表面说得通"的理由，否则像硬给钱 |
| 触发方式 | 被动计数（主角无需主动）/ 主动接取 | 被动计数为主——主角没有额外动作，误会纯来自系统行为 |
| 进度感知 | 面板可见 N/100 | 进度是主角的私密执念，也是外人眼里"他反复做奇怪的事"的证据 |
| 调味任务 | 阶段性小任务：完成 → 给与主线相关的便利/资源 | 调味任务的奖励要被能解读成"豪门手笔"，才能继续喂养误会 |
| 系统人格 | 机械 / 调侃 / 冷漠 | 机械冷处理为主——系统不解释、不背锅，加剧主角"没人信我"的无奈 |

> 关键约束：**系统的"规则解释权"交给系统自己，不给主角**。系统从不出来帮主角澄清，这是误会能成立的前提。

## 系统面板

迪化流的系统面板**极简**——只保留主线进度、里程碑、调味任务三块。参考模板见 [`panels.md`](panels.md)，init 时由 Architect 实例化为每本书的 `setting/系统面板.md`。字段越少越好，面板不是爽点本体。

## 迪化势能体系（代替力量等级）

迪化流没有实力等级，替代品是**误会势能**——旁观者对主角敬畏级别的递进。这是本品的"力量体系"：

| 势能档 | 象征话术 | 见证者范围 | 可兑现的资源/地位 |
|--------|---------|-----------|------------------|
| L1 留意 | "这人有点意思" | 单个人 | 尊重、关注、优先对待 |
| L2 忌惮 | "他绝不是表面这么简单" | 小圈子（介绍人/同事） | 主动配合、行方便 |
| L3 敬畏 | "这是真大佬" | 一个圈层（婚介圈/公司/俱乐部） | 资源倾斜、人脉递投名状 |
| L4 传说 | "那位隐世太子" | 豪门 / 资本圈 | 利益输送、主动投靠、联姻试探 |
| L5 公开化 | "他就是那一位" | 社会公开层面 | 地位、势力、没人敢惹 |

**势能规则**：
- 势能只升不降、升一档少一档的自由度——每升一档都是消耗品，必须卡在阶段兑现点，不能白升。
- 露馅不叫"掉档"，叫"危机"——用阴差阳错的新误会"擦边"补回来，维持只升不降的体感。
- 档位推进要靠"证据链"：每一档都要有一个新的、读者认可的"实锤"（行为、物件、背景），光靠嘴上吹不能升档。

## 升级/推进节奏

**双轴推进**（代替单一升级表）：

| 轴 | 内容 | 频率 |
|----|------|------|
| 系统进度轴 | 主线 N/100 向前 + 每 N 次一个里程碑 | 每 3-5 章推进 1-2 次，里程碑为阶段小高潮 |
| 误会势能轴 | L1 → L5 逐档升 | 每 10-15 章升一档，档位卡在里程碑/败露危机点 |

两条轴**互相咬合**：系统进度制造"新行为→新误会题材"，势能档位决定这批误会被"谁"看见、以多重的分量兑现。进展感 = 进度条在走 + 敬畏的人在变大。

## 禁忌清单

以下情况必须避免：

| 禁忌 | 检查方法 |
|------|---------|
| 主角连续两章不产生新误会（澄清失败不算推进，只是原地） | 检查每章是否有一个"解读升级或换招后果"的节点 |
| 配角脑补不讲证据链（凭空猜"他肯定是大佬"） | 检查脑补是否从主角的具体行为细节出发逐层推演 |
| 澄清成功过一次（某次解释被当场相信） | 全书任何一处都不能出现"说清就信" |
| 主角真怒了/破防骂人（被动破功、情绪失控） | 主角的"无奈"要有克制感和喜剧感，不能真的气急败坏 |
| 误会双方当场和解、把话说开 | 误会只能被"换招/新事件"接走，不能被"谈清楚"了解 |
| 全靠巧合硬凑（每个意外缺"因"） | 阴差阳错也要有因果链：A 的行为 → B 误读 → C 的应对 → 反效果 |
| 脑补者替读者总结（"我懂了，他一定是……"+ 长篇解释） | 脑补用行为证明，不用嘴点破，至少要短促 |
| 势能无代价升档（说升就升） | 每档升位必须配一个可见的"实锤证据"和风险窗口 |
| 系统出来替主角澄清/解释误会 | 系统人格不参与误会解释，规则解释权只在系统自己 |
