# 迪化流 — 章节节奏模板

> 面向番茄平台快节奏。供 ScenePlanner/Writer 按需读取。

## 单章节奏基线

```
章首钩子 (500字)
  ├── 方式一：配角的新解读 / 上一个误会的余波（最有味道）
  ├── 方式二：系统进度推进（N 次达成、里程碑临近、新调味任务）
  └── 方式三：反常细节（主角随手一个举动被某双眼睛注意到）

主体推进 (1500字)
  ├── 误会起势 (600字)
  │   旁观者观察到主角行为 → 脑补初现 → 自我攻略开始（证据链第一层）
  ├── 澄清失败 (500字)
  │   主角解释原意 → 被动解读成"更高深的伪装" → 势能升档
  └── 换招后果 (400字)
  │   主角换新招自证 → 新行为又被误读 → 结果偏离原意（反方向伏笔）
  └── 爽点/节点 (300字)
      阴差阳错的落点（歪打正着 / 意外收获 / 误会落槌）
  └── 见证者反应的递进（留意 → 忌惮 → 敬畏）

章尾钩子 (200字)
  ├── 误会下一层解读预告（配角自言自语"那位一定是……"）
  ├── 系统里程碑逼近
  ├── 露馅危机端倪（有个知情者要来/有份资料要被翻出来）
  └── 更大舞台的入场券（新圈层的请柬/大人物的"拜访"）
```

## 爽点类型轮换

为避免重复感，不同类型的爽点应该轮换出现：

| 爽点类型 | 占比 | 章节示例 |
|---------|------|---------|
| 误会升级 | 30% | 旁观者对主角的解读再上一档（从忌惮到敬畏） |
| 歪打正着 | 25% | 主角想办成 A，阴差阳错拿到更大的 B |
| 务实小兑现 | 20% | 系统里程碑奖励 / 明确的资源进账 |
| 意外受益 | 15% | 被误会白捡的好处（人情、便利、挡箭牌） |
| 危机化解 | 10% | 露馅边缘的惊险过关，因祸得福 |

**轮换规则**：误会升级不要连续出现 2 章以上（全程升级会麻木）；升级章后面紧跟"歪打正着/务实兑现"，让势能落袋。

## 章节功能轮换

**章节类型轮换建议（10章周期）**：

```mermaid
flowchart LR
    起势1["推进"] --> 起势2["推进"] --> 兑现1["高潮"] --> 余震["余震"] --> 扩展["扩展"]
    扩展 --> 起势3["推进"] --> 危机["高潮"] --> 过渡["过渡"] --> 起势4["推进"] --> 入场["卷末"]
```

统计：
- 推进章：4/10（误会复诵一层 + 换招落点）
- 高潮章：2/10（阶段爽点集中释放：里程碑兑现 / 危机惊险化解）
- 扩展章：1/10（误会扩散到新圈层/新配角进场）
- 余震章：1/10（上一波误会的后果消化，关系变化）
- 过渡章：1/10（日常轻喜感，调味任务，节奏缓冲）
- 卷末章：1/10（势能升档 + 新阶段钩子）

## 字数节奏

```
短章（1500-2000字）：纯爽点章、过渡章
标准章（2000-3000字）：推进章、扩展章
长章（3000-4000字）：高潮章、卷末章

每章字数波动不超过 ±30%，避免一章1500字下一章4000字。
```

## 系统出现频率

| 章节位置 | 系统出现时机 |
|---------|------------|
| 章首 | 主线进度推进（当前值/总目标）、新调味任务、里程碑临近提示 |
| 章中 | 主角瞄一眼进度（私密执念）、调味任务完成确认 |
| 章尾 | 里程碑达成通知、下一阶段解锁 |

系统每章至少露一次面，但**只给进度和规则，从不解释误会**——系统出面越少，误会的戏份越足。

## 10 章节奏样本

```
第 1 章：系统激活 + 主线任务亮出（0/N）+ 第一次被误会（高潮·开书钩子）
第 2 章：主线第一次推进 + 见证者脑补初现 + 主角澄清失败（推进）
第 3 章：误会扩散进小圈 + 调味任务 + 歪打正着小收益（推进）
第 4 章：主角换招自证 → 越描越黑 → 势能升档 L2（推进→上升）
第 5 章：里程碑达成 + 阶段奖励 + 更上层见证者注意到主角（高潮）
第 6 章：奖励被误读成"大佬手笔" + 引发更大圈层关注（余震）
第 7 章：日常线误会 + 轻喜感 + 缓冲（过渡）
第 8 章：误会扩散至新圈层/公司 + 有人开始查主角底（扩展）
第 9 章：露馅危机 → 主角急救纠偏 → 阴差阳错化解 + 因祸得福（高潮）
第10章：更大圈层入场券 + 大人物"拜访" + 下一阶段钩子（卷末）
```
