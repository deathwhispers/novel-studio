# 迪化流 — 常见变体

> 供 Architect 初始化与 Writer 写作时参考。

## 一、次数达成型（长期目标，最常见）

**核心设定**：主角必须完成 N 次特定行为才能获得大奖。**行为题材可自由替换**——相亲、饭局、签单、出差、打卡都行。下面以"相亲"为例展开（婚配题材误会信息量高、见证者天然在场，便于讲清机制），但每本书完全可以换皮成自己的任务。

**典型开局**（示例，以相亲题材为例）：
> 「叮！主线任务发布：完成 100 次相亲，任务完成奖励：1000 亿。」主角为了大奖开始频繁相亲，对女方条件出奇地较真，却一次次婉拒——这一连串"反常行为"被介绍人、女方、圈内人一步步解读成"隐世豪门太子在微服挑选婚配对象"。

> 换成其他题材同理：把"相亲"替换成别的行为，脑补方向从"豪门选婚配"换成对应圈层的"深藏不露"。

**爽点引擎**：
- 行为频率 = 误会燃料（"正常人哪会反复做这种事？"）
- 行为极值 = 解读升级（反常到出格的举动最容易被脑补成深意）
- 进度条 = 主线悬念（凑满 N 次那天到底会发生什么）

**节奏特点**：每 1-2 次"行为" = 一个误会小循环；里程碑（进度走到 20%/50%/80%）= 阶段小高潮。天然适配番茄日更。

**常见风险**：
- 行为重复 → 每次必须换一种误会角度（豪门派/考验派/挑刺派/神秘派），不能同款解读复制
- 次数推进全靠单一行为场景 → 插日常线、职场线、家族线稀释

## 二、里程碑递进型（阶段化）

**核心设定**：主线大口径目标被拆成阶段里程碑，每过一个阶段升一档误会势能。阶段题材无关紧要（以相亲为例：100 次 → 见家长 → 订婚 → 完婚；换成饭局/签单/出差等同样成立），关键是"阶段更替 = 势能跃迁 + 见证者范围扩大"。

**典型开局**（示例，以相亲题材为例）：
> 同样是"结缘百次"主线，但系统把 100 次分成四阶段：前 20 次"初识期"→ 40 次"择偶期"→ 60 次"摊牌期"→ 100 次"终局"。每到一阶段，误会的见证者范围就扩大一圈，势能从"介绍人"一路升到"豪门层面"。

**爽点引擎**：
- 阶段更替 = 势能跃迁的仪式感
- 每阶段一个"实锤证据"（新车/新岗位/新背景），把脑补钉实
- 阶段边界 = 必写的"露馅危机卡点"，制造换季张力

**节奏特点**：节奏比次数型缓一档（每阶段 5-8 章），适合想写长线、把误会做成"传说"的书。

**常见风险**：
- 阶段切换生硬 → 用"败露危机 + 阴差阳错化解"当阶段间的卡点，别直接宣布"进入下一阶段"
- 阶段重复（每阶段同一行为题材 + 误会 + 兑现）→ 每一阶段的误会题材、见证者、施压方式必须不同

## 三、封闭场景型（高密度）

**核心设定**：主角困在单一场景里（一场相亲局 / 一场晚宴 / 一个俱乐部 / 一栋办公楼），误会全发生在有限几个人之间反复博弈。

**典型开局**：
> 主角被系统要求参加一场"顶级私人晚宴"，就此困在宴会厅：一桌人从看他不起，到疯狂脑补他是"那位隐世太子"，几小时里误会层层叠加、互相印证、彼此攀比谁先巴结上他。

**爽点引擎**：
- 密度极高（一场景里十几处脑补连发）
- 同场景人物互相"交叉印证"，误会在群体中自我强化（A说他是大佬，B想起细节更确信）
- 封闭 = 张力（真相出不去，也进不来，误会只能内部滚雪球）

**节奏特点**：天然适合短篇/单卷；若写长篇，封闭场景作为卷段，之后放闸扩散。

**常见风险**：
- 场景单调 → 限制篇幅，或用"宴会散场/俱乐部换馆"自然换景
- 配角脸谱化（都是巴结者） → 区分巴结/试探/冷眼/打工人四类反应

## 四、真相危机型（事故局）

**核心设定**：主线中埋着一条"真相可能被戳穿"的线——有个知情人、有份资料、有一次对质，随时可能把误会掀底。全书张力来自"危机推演 + 阴差阳错擦边"。

**典型开局**：
> 主角的误会已经传到豪门圈，但当年认识他的老同学、能翻到他真实底细的猎头、以及被他"拒绝"过的一个当事人，都随时可能出来拆台。系统 80/100 的进度条，和"真相爆炸倒计时"并行。

**爽点引擎**：
- 持续性紧张（每章都有踩雷的可能）
- 化解不靠硬解释，靠"换招 → 被误读成新布局 → 阴差阳错盖过真相"
- 真相被反复"差一点暴露"又"擦边过去"，读者的心悬着

**节奏特点**：节奏偏紧，适合中期（误会已经成型）以后启用，不适合开书就用。

**常见风险**：
- 露馅了就崩 → 每次危机必须有一个"比真相更可信的误会"来接住，不能真戳穿
- 反复擦边麻木 → 危机要一档比一档险，真有一次落到"就差一行字"的程度

## 如何选择变体

| 如果你想要 | 选择 |
|-----------|------|
| 最稳的番茄节奏、主线清晰、开书就有钩子 | 次数达成型 |
| 误会做成"传说"的长线史诗感 | 里程碑递进型 |
| 短篇高密度误会快感 | 封闭场景型 |
| 强悬念、中期持续紧张 | 真相危机型 |

**可以组合**：次数达成型 + 里程碑递进型 = 最稳的组合（主线完整拆阶段，行为题材自由换皮）；中期再叠真相危机型制造持续张力（有"随时查穿主角底细"的知情人）。
