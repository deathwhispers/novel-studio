# 迪化流 — 范例分析

> 示例为迪化流典型桥段的配方化拆解（范例虚构，仅提取可迁移的技法模式），供 Writer 参考，非强制模板。

## 示例 1：封闭场合误会（以一场相亲局为例）

**场景**：主角被系统要求完成第 N 次相亲（"相亲"只是任务行为题材的示例，换成饭局/签单/出差等同类封闭场合同样成立），他照常赴约、照常较真看条件、照常礼貌婉拒。

**处理方式**：
1. **反常行为先行**：主角的真实动因是系统进度（拒绝 = 在完成任务），但在外人眼里，他"条件登记超认真、来者不拒又谁也不娶"，这种行为本身就反常。
2. **第一层脑补**：介绍人先嘀咕"这人条件这么好，怎么还来相亲"——脑补从"主角身上的矛盾"出发，不凭空。
3. **自我攻略加码**：女方/介绍人开始给反常行为找回解释："他这么挑，肯定不是一般人""你看他刚才婉拒的样子，跟见过大场面似的"。
4. **澄清失败**：主角解释"我就是按流程来"——被解读成"这种场合见多了，懒得解释"。越描越黑，势能原地+1。
5. **歪打正着小落点**：婚介所把他设为 VIP、女方家庭反而主动贴上来——主角想完成"次数"的原本目的没变，但外溢出了一圈"被高看"的好处。

**可迁移技法**：
- 误会的第一颗火苗必须从"主角行为的真实反常"烧起，不是天上掉下来的传闻
- 脑补要给"逻辑钩子"：每次加码都顺着上一个细节推演（较真 → 见过世面 → 不是普通人）
- 澄清是导演让你怎么写都会反噬的台词——专给能误读的点，不给能澄清的点
- 小落点不要踩主角原意（他还是要完成任务），外溢的好处是"惊喜"，不是主线替代

## 示例 2：日常线误会（一个普通举动 → 隐世豪门）

**场景**：主角在职场/生活里随手做了一件小事（把一笔不该拿的钱退了、对一个势利的人面不改色、收到一笔"天价"赔偿金不惊讶），被同事/邻里脑补成"家里有矿"。

**处理方式**：
1. **选行为**：挑那种"正常人会心动/会慌、主角却波澜不惊"的举动——主角波澜不惊的原因要立住（系统给了更大的盼头，所以他看不上眼前的钱）。
2. **见证者分层**：起先是单个人留意（L1），然后传到小圈子（L2），每个传播者都加一层自己的脑补。
3. **越描越黑的第二拍**：主角想纠正"我真没那么多钱"，结果他"对钱不接话"这个姿态本身，成了新的证据——"有钱人从不聊钱"。
4. **反方向落点**：主角本想让人知道"我其实没钱，别找我借"，结果传成了"那人是真豪门，找他借不如找他帮忙"——他的澄清反而把他钉牢在大佬位子上。

**可迁移技法**：
- 主角"看不上小钱"要有合理动因（系统的长期大奖 = 心理锚点），否则读者觉得他装
- 脑补的传播要在配角之间"交叉印证"：A 说主角飒，B 想起另一件小事就更确信——群体自我强化比单人自嗨更有说服力
- 反方向结果 = 主角想澄清的事，成为误会最硬的证据（"他说自己没钱" = "有钱人惯用的低调"）

## 示例 3：里程碑"歪打正着"兑现（想办成 A → 拿到更大的 B）

**场景**：主角逼近系统里程碑（主线推进到 80/N，或阶段奖励解锁），原本目的是"凑完次数拿大奖"，却在这个节点阴差阳错被豪门/资本圈递出橄榄枝。

**处理方式**：
1. **危机先行**：里程碑前先埋一个"露馅危机"——有人要来查他真实底细，或者有个当事人要出来对质。
2. **主角换招纠偏**：主角为躲危机做了一件事（比如紧急参与一个项目、救场一个场合、亮出一张资源牌）。
3. **新招被误读成布局**：他避祸的动作被大人物看到，误读成"随手一子，已布好局"——危机反而把势能推到新档位。
4. **反方向兑现**：主角本来只是想"别被拆穿、把任务做完"，结果被当成值得投资的"那位"——金主递上比"完成任务"更大的东西（资本/势力/联姻机会）。
5. **留钩子**：到手的更大 B 附赠一个新疑难（这笔利益是谁牵线搭桥的？背后有真正的豪门在试探他？）——把误会推向下一层。

**可迁移技法**：
- 里程碑=阶段高潮，前面必须垫一个"真危机"，让兑现发生在"查穿 vs 阴差阳错"的刀刃上，才有张力
- 主角的换招要"合理且紧急"，不是随随便便的新误会
- 反方向兑现的落点要比主角原意"意外地更大"，让读者爽在"他以为要坏事，结果赚大了"
- 每一兑现都要带出一个新的"未知来源/更大试探"，把钩子递向下一阶段
