# AI 味检测清单

> Critic Style Checker 专用。完整版见 `references/ai-flavor-catalog.md`。

## 关键词扫描（逐项搜索正文）

| # | 搜索关键词 | 类别 | 修复方向 |
|---|-----------|------|---------|
| 1 | `感到` `觉得` `认为` `意识到` `明白` `知道` | 解释腔 | 删词，换成动作或感知 |
| 2 | `由于` `因为` `所以` `随着` `与此同时` | 解释腔/过渡 | 删连词，拆短句 |
| 3 | `仿佛` `似乎` `好像` `犹如` `某种` `某种程度` | 偷懒模糊 | 删词，写确定的具体表现 |
| 4 | `不禁` `不由` `忍不住` `不由得` | 解释腔 | 换成具体动作 |
| 5 | `在这一刻` `在那一瞬间` `此时此刻` | 机械修辞 | 删掉，直接写事件 |
| 6 | `xxx而xxx` `xxx却xxx` | 机械修辞 | 只保留真正的矛盾关系 |
| 7 | `xxx地说`（副词+对话标记） | 修饰过度 | 删副词，让对话传达语气 |
| 8 | `微微` `轻轻` `缓缓` `慢慢` | 修饰过度 | 同动作最多保留一个 |
| 9 | `目光` `眼神` `视线` | 修饰过度 | 超5次/章 → 用其他感官替代 |
| 10 | `不知过了多久` | 偷懒模糊 | 用具体感知替代（茶凉了、天黑了） |
| 11 | `说明` `意味着` `代表` `这就是` | 过度总结 | 删掉，让读者判断 |
| 12 | `不是害怕，不是后悔，而是`（否定铺垫） | 模板化句式 | 直接写肯定句 |
| 13 | `没有表情。没有`（否定清单） | 模板化句式 | 写有什么，不写没有什么 |
| 14 | `点了点头` `深吸一口气` `眼中闪过` `沉默了片刻` | 模板化句式 | 换成具体、独特的动作 |
| 15 | `空气仿佛凝固` `时间仿佛停止` `心像被揪了一下` `脑海一片空白` `一股暖流` | 陈旧意象 | 换角色认知世界里的比喻 |
| 16 | `第一` `第二` `第三` `首先` `其次` `最后` `一方面` `另一方面` | 机械罗列 | 拆掉编号，顺序藏进因果或叙事 |
| 17 | `综上所述` `总而言之` `由此可见` `总之` `当然` `显然` `很明显` | 机械罗列 | 删掉，让情节自己收束 |
| 18 | 连续 300 字无触觉、听觉、嗅觉描写 | 活人感缺失 | 注入 1 个非视觉感官（温度/声音/气味） |
| 19 | 连续 3 段无角色身体反应（心跳/出汗/胃紧/手抖/脸热等） | 活人感缺失 | 加身体反应来传递情绪 |
| 20 | 独立「不是……。是……」两句否定 | 模板化句式 | 删否定部分，直接写肯定句 |
| 21 | 独立「没有……」做段落过渡 | 模板化句式 | 替换为肯定动作或直接推进 |

## 结构扫描（逐段阅读，不搜索关键词）

| # | 检查项 | 判定标准 |
|---|-------|---------|
| 16 | 段落均匀 | 连续 5 段以上同样长度 → 标记 |
| 17 | 对话后紧跟解释 | 对话段落后立即出现「这意味着/他意识到」→ 标记 |
| 18 | 叙事后紧跟心理 | 动作描写后立即出现「他想/他感到」→ 标记 |
| 19 | 先景后人模式 | 每场景开头都是环境描写 → 标记 |
| 20 | 连续 300 字无触觉/听觉/嗅觉 | 全视觉描写 → 标记活人感缺失 |
| 21 | 连续 3 段无角色身体反应 | 无心跳/出汗/胃紧/手抖/脸热等 → 标记活人感缺失 |
| 22 | 连续 3 段无闲笔 | 无无用动作/环境杂音/角色走神 → 标记活人感缺失 |

## 句式风险速查

| 模式 | 处理 |
|------|------|
| `由于……所以……` | 删连词 |
| `在……的带领下/帮助下` | 换成具体互动 |
| `只见/就看到` | 删掉，直接写画面 |
| `不是……而是……` | 删否定前缀 |
| `不是……。是……` | 删否定句，只留肯定 |
| `不是……——是……` | 删否定部分，直接肯定 |
| `没有……（独立过渡）` | 替换为肯定动作 |
| `没有……没有……就是……` | 只写肯定 |
| `第一/第二/第三` `首先/其次` `一方面/另一方面` | 拆掉序号，因果链重写 |
| `综上所述/总而言之/当然/显然` | 删掉 |
| `原来……是因为` `原来……是` | 写成发现过程，不写事后解释 |
| `xxx而xxx` / `xxx却xxx` | 只用于真矛盾 |
| `众所周知` / `毫无疑问` | 删掉 |

## 检测阈值

**AI 味关键词**：
- ≤2 处：标注但自行修复
- 3-5 处：`局部修复` → 回 Writer
- >5 处：标记为文风问题，`局部修复` → 回 Writer 逐项处理

**机械罗列（第一/首先/综上所述等）**：
- ≥1 处：硬伤，`局部修复` → 回 Writer

**活人感缺失（感官单一/无身体反应/无闲笔）**：
- 连续 300 字不达标：软问题，标注修复建议
- 连续 3 段以上不达标：`局部修复` → 回 Writer

**否定句式（不是…是…/没有…独立过渡）**：
- ≥3 处：`局部修复` → 回 Writer
