# 网文排版规范

> Writer 硬约束。正文排版不合格 = 硬伤，Critic 退回。

---

## 一、短句式

### 核心规则

**每句不超过 30 字。超过即拆。**

网文阅读场景是手机竖屏滚动——长句 = 读者跳读 = 体验崩塌。

| 句长 | 适用场景 | 占比要求 |
|------|---------|---------|
| 2-8 字（极短） | 打斗、紧张、对话交锋 | 至少占 20% |
| 10-20 字（标准） | 叙述、描写、推进 | 主体，占 60%+ |
| 20-30 字（上限） | 复杂描写、心理活动 | 不超过 15% |
| 30+ 字 | **禁止** | 0% |

### 长句拆分示例

```
❌ 他走进那间昏暗的房间，目光扫过墙角那张落满灰尘的木桌和上面摆放着的早已干涸的茶杯以及旁边那封已经泛黄的信封。

✅ 他走进房间。灯没开。
墙角一张木桌。落满灰。
桌上有个茶杯——早就干了。
旁边一封信。信封泛黄。
```

### 逗号限制

**一句话最多两个逗号。** 三个逗号以上的句子必定要拆。

```
❌ 他看了一眼系统面板，确认任务目标在城西废弃工厂后，转身披上外套，推门走进了夜色里。

✅ 他看了一眼系统面板。
任务目标：城西废弃工厂。
他披上外套。推门。走进夜色。
```

## 二、段落节奏

### 核心规则

**一段不超过 3 句。** 超过即拆。

网文不是传统文学——段落之间的空白是读者喘息的空间。大段文字 = 读者跳过。

```
❌ （连续 6 句挤在一段）
他走进房间，窗帘拉着，屋里很暗。桌上放着一杯没喝完的茶，旁边是一封信。信上的字迹很潦草，像是匆忙中写下的。他拿起信看了两遍，脸色越来越难看。窗外有人在唱歌，唱的是他小时候听过的那首。他把信折好放进兜里，转身离开。

✅ （按节奏拆段）
他走进房间。窗帘拉着。屋里很暗。

桌上放着一杯没喝完的茶。旁边有一封信。字迹潦草——像是匆忙中写下的。

他看了两遍。脸色越来越难看。

窗外。有人在唱歌。他小时候听过的那首。

他把信折好。放进兜里。转身离开。
```

### 段落功能表

| 段落类型 | 句数 | 用途 |
|---------|------|------|
| 冲击段 | 1 句 | 关键信息、反转、震撼 |
| 标准段 | 2-3 句 | 正常叙述和描写 |
| 呼吸段 | 1 句 + 空行 | 场景/情绪切换 |
| 禁止 | >3 句 | 大段文字是网文毒药 |

### 空行规则

**句与句之间不空行。段与段之间空一行。**

短句不等于每句一行——同一个段落内的句子用标点（句号、逗号）自然连接，不要每写一句就换一行。空行只用在段落之间，用于划分语义块。

```
❌ （每个短句都单独换行，全文像诗不像小说）
他走进房间。
灯没开。
墙角一张木桌。
落满灰。

✅ （同一段内短句自然连接，段与段之间才空行）
他走进房间。灯没开。墙角一张木桌，落满灰。

桌上有个茶杯。早就干了。
```

以下情况必须插入空行（空一行，不是空多行）：
- 场景切换（时间/地点变化）
- 视角切换（A 角色 → B 角色）
- 情绪切换（紧张 → 舒缓）
- 对话回合之间（大段对话用空行分组）
- 两个独立的人物/事件单元之间

空行只用**一行**，禁止连续空两行以上。

### 缩进规则

**段落首行缩进 2 个字符（两个全角空格）。**

每个自然段的首行统一缩进两个汉字的宽度，保持段落起始整齐。

```
✅ （首行缩进两个全角空格）
　　他走进房间。灯没开。墙角一张木桌，落满灰。

　　桌上有个茶杯。早就干了。

❌ （顶格写，无缩进）
他走进房间。灯没开。
桌上有个茶杯。早就干了。
```

## 三、系统/面板文字

### 核心规则

**所有系统提示、面板内容、任务描述、数值变化，统一使用【】包裹。**

```
✅ 【叮——检测到宿主完成隐藏任务】
✅ 【任务奖励：力量 +10，敏捷 +5】
✅ 【警告：灵力不足，无法使用此技能】
✅ 【签到成功！获得：筑基丹 ×3】
```

### 系统面板格式

**每个属性单独一行，一行一个字段。** 禁止把多个属性挤在一行。

> 每本书的面板定义锁定在 `setting/系统面板.md`（init 时由 Architect 从品类模板 `genres/番茄系统爽文/panels.md` 实例化并个性化）。Writer 写作时以 `setting/系统面板.md` 为准，不自行发明字段或格式。

```
【个人信息】
【姓名：XXX】
【等级：筑基中期（67/100）】
【技能：灵目术（初级）、剑气诀（中级）】
【剩余积分：320】
```

任务、属性面板同样一行一个字段：

```
✅
【任务：寻找失落的玉佩】
【难度：困难】
【时限：72 小时】
【奖励：经验 +5000，玄铁剑 ×1】
【当前进度：0/1】

❌
【任务：寻找失落的玉佩，难度困难，时限72小时，奖励经验5000玄铁剑】
```

### 禁止的写法

```
❌ 系统提示：检测到异常。
❌ “系统：任务完成”
❌ 【系统】任务已发布
❌ 叮！恭喜宿主获得新技能（缺少【】包裹）
```

## 四、对话排版

### 核心规则

**每句对话单独一行，用中文弯引号 `“”` 包裹。一人一句一段。** 不同人的对话不能挤在同一行。

```
✅
“你来了。”他说。
她没回头。“我不该来吗？”
“你知道我不是这个意思。”
“那你是什么意思？”她转过身。

❌
“你来了。”他说。她没回头。“我不该来吗？”“你知道我不是这个意思。”“那你是什么意思？”她转过身。
```

### 对话标签

- 对话前/后加简短的动作或神态，不超过 15 字
- 大段对话只保留关键的肢体语言，其他标签删掉
- 读者能看出谁在说话时，删掉“XX说”

```
✅
“你确定？”
他没说话。把烟掐了。
“好。当我没问。”
```

### 对话中的省略和打断

- 省略号：`……`（两个全角省略号，共 6 个点）
- 打断：`——`
- 停顿：`。`（用句号代替省略号，更干脆）

```
✅
“我不是那个意思，我是说——”
“够了。”
他张了张嘴。没再说。
```

## 五、内心独白与心理活动

### 核心规则

不需要特殊标点。直接用短句穿插在叙事中。

```
✅
他看了一眼任务面板。
开什么玩笑。这个任务是人做的？
算了。接都接了。
```

### 禁止

```
❌ 他心里想：“这任务太难了。”
❌ （内心os：这任务太难了）
❌ “我该怎么办？”他心想。
```

内心独白不需要“他想”“心里想”“内心os”——读者知道是角色在想。

## 六、章节结构

### 章节标题

```
## 第X章 标题
```

### 正文开头

章节开始不需要回顾上一章。“上一章说到……”禁止。

直接从场景切入：

```
✅
系统面板上弹出一条新消息。
红色的。不是平时的蓝色。
苏晨愣了一下。

❌
上一章说到苏晨完成了系统的试炼任务，获得了新能力。这一章我们接着讲他如何使用这个能力。
```

### 章节结尾

不写“且听下回分解”“预知后事如何”等评书式收尾。钩子本身够吸引人就行。

```
✅
他把信翻过来。
背面还有一行字。
很小的字。像是用指甲刻的——
“别相信系统。”

❌
苏晨的命运将会如何？系统的真相又是什么？请听下回分解。
```

## 七、数字与数值

### 核心规则

网文中涉及系统的数字，使用阿拉伯数字。

```
✅ 力量 +10
✅ 等级提升至 15 级
✅ 剩余时间：00:03:42
```

非系统的普通叙述中，小数字用中文：

```
✅ 他等了三秒。
✅ 两个人对视了一眼。
✅ 这是他第三次失败了。
```

## 八、标点规范

### 总则

**正文叙述和对话的标点，统一使用中文全角标点**（，。！？；：、“”《》、——……、（））。唯一例外是系统文字【】内部的标点（见下方“特殊”）。

| 场景 | 正确用法 | 禁止 |
|------|---------|------|
| 省略 | `……`（两个全角省略号） | `...` `…` 单省略号 |
| 破折号 | `——`（两个全角破折号） | `--` `—` 英文破折号 |
| 书名号 | `《》` | 用引号代替书名号 |
| 对话引号 | `“”`（中文弯引号） | `「」` `''` `""` 英文直引号 |
| 顿号 | `、` | 用逗号代替顿号 |
| 感叹号 | `！` | 连用 `！！` `！！！` |
| 问号 | `？` | 连用 `？？` `？？？` |
| 逗号 | `，` | `,` 英文逗号 |
| 句号 | `。` | `.` 英文句号 |

### 特殊：系统文字中的标点

系统文字内的标点使用半角（模拟程序界面）：

```
✅ 【任务：击杀 10 只妖兽（0/10）】
✅ 【获得称号：幸运儿（唯一）】
```

## 九、强调与特殊格式

- 不使用粗体/斜体——网文不是技术文档
- 需要强调的词，用短句独立成段来实现：

```
✅
这个任务。
不可能完成。

❌
这个任务**不可能**完成。
```

- 不使用分割线 `---` `***`——场景切换用空行即可

## 十、常见排版错误

| 错误 | 说明 |
|------|------|
| 大段环境描写 | 超过 4 句的纯环境描写 → 打散，穿插角色感知 |
| 连续长对话 | 连续 6 句以上对话无穿插动作 → 加肢体动作/环境反应 |
| 信息堆砌 | 一段里塞 3 个以上新信息 → 拆开，给读者消化时间 |
| 过于工整 | 每段都是 2-3 句，从头到尾不变 → 插入 1 句冲击段打破节奏 |
| 长句塞爆 | 超过 30 字的句子 → 必定要拆 |
| 段落墙 | 超过 4 句的段落 → 必定要拆 |
| 每句一行 | 把每个短句都单独换行，全文像诗不像小说 → 同一段内句子用标点连接 |
| 引号用错 | 对话用「」或英文直引号 `""` → 统一用中文弯引号 `“”` |
| 面板挤一行 | 系统面板多个字段挤在一行 → 每个字段单独一行 |
| 标点混用 | 正文出现英文逗号/句号/引号 → 统一中文全角标点 |
| 多行空行 | 连续空两行以上 → 空行只用一行 |

## 十一、手机阅读测试

写完一章后，用手机屏幕视角自检：

1. 在 6 英寸屏幕上，每段不超过 5 行
2. 任何一段在屏幕上超过半屏 → 必拆
3. 一屏里至少看到 2-3 个段落空白
4. 对话在屏幕上是错落的，不是整齐的方块

如果一段文字在手机上看起来像一面墙——拆掉它。
