# AI 味目录

“AI 味”不是禁用词表，而是语言选择与人物、场景和叙事目的脱节。先用本文定位风险，再用 `去味手法.md` 判断是否修改。

## 常见模式与示例

### 解释腔

AI 倾向把角色的行为和动机解释得太清楚。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他握紧拳头，心中充满了愤怒，因为他意识到自己被背叛了。 | 他握紧拳头，指节发白。 |
| 她感到一阵恐惧，她知道接下来会发生什么可怕的事情。 | 她的脸色刷地白了。 |
| 他明白这是唯一的办法，只能硬着头皮上了。 | 他深吸一口气，推开了门。 |

### 均匀感

AI 倾向让段落长度、节奏和信息密度均匀分布。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 这是一个普通的早晨。阳光透过窗户洒进来。他起床洗漱，然后吃了早餐。 | 阳光刺眼。他翻了个身，把被子蒙在头上。 |
| 他们相视一笑，然后转身离开了房间。走廊里很安静，只有脚步声回荡。 | 她笑了笑。他没笑。 |

### 模板化句式

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他深吸一口气，缓缓说道…… | 「好，我去。」 |
| 她抬起头，眼中闪过一丝复杂的情绪。 | 她看着他，没说话。 |
| 空气中弥漫着一种诡异的寂静。 | 安静得不正常。 |
| 不是害怕，不是后悔，而是一种说不清的悸动。 | 他心跳很快。不知道为什么。 |
| 没有表情。没有「哦」。没有「管得真宽」。就是一句陈述。 | 他听完，把烟掐了。 |

### 过度总结

AI 倾向在叙事中插入评论式总结句。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 这就是命运的安排，谁也无法改变。 | 他没再说什么。 |
| 也许这就是成长的代价吧。 | 她揉了揉眼睛，继续往前走。 |

### 角色同声腔

AI 倾向让所有角色用相似的方式说话。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 「我认为这样做可能不太妥当。」 | 「不行。」 |
| 「我对此感到非常抱歉。」 | 「怪我。」 |
| 「根据我的分析，情况不容乐观。」 | 「完了。」 |

### 安全表达

AI 倾向避免强烈、有风险的表达。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他似乎对她有些好感。 | 他喜欢她。 |
| 这件事可能带来一些不好的影响。 | 这事要命。 |
| 他感到一种难以言说的情绪。 | 他笑不出来。 |

### 偷懒式模糊表达

AI 用模糊词逃避精确描述——读者读到的不是画面，是作者的不确定。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他仿佛看到了希望。 | 他看到了希望。 |
| 一种说不清的情绪涌上心头。 | 他想哭，又不知道为什么。 |
| 不知过了多久，她终于开口。 | 茶凉了。她开口。 |
| 似乎有什么东西变了。 | 他没说再见。 |

核心原则：这些词存在的唯一理由是「作者不确定」。要么确定（删词），要么写清楚不确定的具体表现（写动作/感知），不要用模糊词糊弄过去。

### 机械修辞

AI 强制使用对比、比喻制造「文学感」——每句都要转折，每个情绪都要配比喻。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他的声音很轻，却很有力。 | 他声音很轻，每个字都砸在地上。 |
| 在这一刻，他终于明白了。 | 他终于明白了。 |
| 她的笑容温暖而明亮。 | 她笑得让人想哭。 |
| 在这一瞬间，所有回忆涌上心头。 | 他把照片翻过来，背面有字。 |
| 他沉默了片刻，随后缓缓开口。 | 「我想了一下。」他开口。 |

核心原则：「而/却」只用于真正的矛盾（又爱又恨），不用于普通形容。「在这一刻」删掉后句子如果仍然成立——就删掉。

### 陈旧意象

AI 反复使用已被千万篇网文用烂的比喻和描写。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 空气仿佛凝固了。 | 没人动。 |
| 时间仿佛停止了。 | 她就站在那里。 |
| 他的心像被什么东西狠狠揪了一下。 | 他胃里一紧。 |
| 脑海中一片空白。 | 他张了张嘴。 |
| 一股暖流涌上心头。 | 他没说话，把杯子往她那边推了推。 |
| 像断了线的风筝 / 像脱缰的野马 | 换成这个角色会用的比喻——或者不用比喻 |

核心原则：如果这个比喻你已经在三本以上的网文里见过——换掉。好比喻来自角色的认知世界，不来自通用比喻库。

### 修饰过度

AI 倾向给每个动作加副词、给每个场景加视觉描写——结果是没有重点，句句都像润色过度的范文。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他平静地说：「我知道。」 | 「我知道。」 |
| 她微微点了点头。 | 她点了下头。 |
| 他的目光落在她身上，久久不曾移开。 | 他一直看着她。 |
| 她轻轻叹了口气，缓缓转过身。 | 她叹了口气，转身。 |
| 他的视线扫过房间的每一个角落。 | 他扫了一眼。 |

核心原则：删除副词后对话仍然成立 → 副词是废的。同一个动作不需要两个修饰词（「轻轻」「缓缓」择一）。「目光」「视线」「眼神」每章出现超过 5 次 → 审视是否可以用其他感官替代。

### 机械罗列

AI 倾向用论文式序号结构组织叙事——但小说不是说明文，读者不需要看到"第一点"。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他有两个选择：第一，接受系统的任务；第二，拒绝然后等死。 | 系统给了任务。接了，可能会死——不接，一定会死。 |
| 首先，他需要搞清楚系统到底是什么。其次，得找到其他持有者。最后，活下去。 | 先搞清楚系统是什么。能找到其他持有者就更好了——前提是活到那一天。 |
| 一方面他渴望力量，另一方面他又害怕被系统控制。 | 力量谁都想要。但万一系统在操控他呢？他不敢往下想。 |
| 综上所述，这次任务的风险远大于收益。 | 他看了眼任务面板。这一趟，能活着回来就算赚。 |
| 当然，他也可以选择放弃。但那样的话，系统不会放过他。 | 放弃？系统不会放过他。 |

核心原则：列举的逻辑应该藏在叙事里——角色先遇到什么、再遇到什么——而不是用序号标签告诉读者"这是第一点"。「当然/显然/很明显」是 AI 最爱用的填充过渡词，删掉后句子更紧凑。

### 活人感缺失

这不是一个具体的句式错误，而是一种**整体的叙事温度过低**。特征是：所有描写都"有用"、所有句子都工整、叙事者像监控摄像头一样客观中立、角色不会走神不会吐槽不会说废话。

| 症状（AI 味） | 诊断 | 修复 |
|---|---|---|
| 连续 300 字全是视觉描写（看到/看到/看到） | 五感只用了一种 | 注入触觉（温度/材质）、听觉（环境音/人声）、嗅觉（气味触发回忆） |
| 叙事者像上帝一样客观中立 | 没有偏见、没有盲点、没有私人判断 | 明确叙事者=角色视角，允许偏见：「那个女人穿得很贵——贵得让人不舒服」 |
| 所有细节都"有用"，没有闲笔 | 没有生活质感 | 加一个无用动作：喝水、看窗外、哼歌、挠头、衣服上的线头 |
| 段落句句工整，无中断无冗余 | 真实的人写作有节奏不规则性 | 让角色走神、吐槽、说半句话、改口 |
| 情绪只用"感到/觉得"或脸部特写表达 | 没有身体反应 | 手心出汗 > 感到紧张；胃里一紧 > 感到恐惧；后背发凉 > 感到害怕 |

**活人感自检（写完后抽一段读）**：
1. 这一段里角色有"多余"的动作吗？（喝水、看窗外、挠头）没有 → 加一个
2. 用了几种感官？只有视觉 → 加一个触觉或听觉
3. 角色有没有吐槽/骂人/自言自语/走神？没有 → 考虑加一句
4. 叙事者客观得像监控吗？换成角色自己讲会用什么词？
5. 有没有「第一/第二/首先/其次/不是…是…」？有 → 拆掉

核心原则：活人感不是技法堆出来的，是角色用有缺陷的、有偏见的、会走神的眼睛看世界。完美是机器的特征，不完美是人的特征。

## 句式风险索引

| AI 腔 | 自然替代 |
|---|---|
| 由于……所以…… | 直接写原因或结果，不用连词 |
| 他/她感到/觉得/认为 | 删掉，换成动作或对话 |
| 随着…… | 拆成两句，不要用「随着」开头 |
| 不禁/不由地/忍不住 | 换成具体动作 |
| 说明/意味着/代表 | 留给读者判断，不要说穿 |
| 在……的带领下/帮助下 | 换成具体互动 |
| 只见/就看到 | 删掉，直接写画面 |
| 不是……不是……而是…… | 删掉否定铺垫，直接写「而是」后面的东西；如果不是真的需要澄清误解，不要用这个结构 |
| 不是……。是…… | 两句否定比三句更隐蔽但同样机械——删掉「不是 X」，直接写「是 Y」 |
| 不是……——是…… | 破折号否定变体，同两句否定处理——直接写肯定句 |
| 没有……（独立否定句做过渡） | 「没有预兆。」「没有人说话。」——独立否定句不创造画面，删掉或替换为肯定动作 |
| 没有……没有……就是…… | 否定清单不创造画面——写有什么，不写没有什么 |
| 仿佛/似乎/好像/犹如 | 删掉；如果不确定就写不确定的具体表现 |
| xxx而xxx / xxx却xxx | 只用于真正矛盾，普通形容拆成两句 |
| xxx地说（副词+对话） | 删副词，让对话本身传达语气 |
| 在这一刻/在那一瞬间 | 删掉，直接写事件 |

## 结构风险索引

| AI 腔 | 自然替代 |
|---|---|
| 每个段落 3-5 句均衡 | 长短段交替，关键段落可只有一句 |
| 先景后人 | 先人后景，或人和景同时出现 |
| 对话后紧跟解释 | 删掉解释，信任读者能看懂 |
| 叙事后紧跟心理 | 把心理化成行动或对话潜台词 |
| 每章开头重述前文 | 直接推进，不要回顾 |

## 词汇风险索引

| AI 腔 | 自然替代 |
|---|---|
| 点了点头 | 点了下头 / 没说话 |
| 与此同时 | 删掉，或者用「这时」 |
| 然而/但是 | 一半的情况可以删掉，用短句转折 |
| 众所周知 | 不要用，直接写世界普遍认知 |
| 毫无疑问 | 删掉，用事实说话 |
| 某种/某种程度 | 换成具体描述或直接删 |
| 目光/眼神/视线 | 每章检查出现次数；超过 5 次用其他感官替代 |
| 微微/轻轻/缓缓/慢慢 | 检查是否必要；同一动作最多用一个 |
| 不知过了多久 | 用具体感知替代（茶凉了、天黑了、腿麻了） |

## 常见 AI 味组合

| 组合 | 表现 | 修复 |
|---|---|---|
| 解释 + 概括 | “他感到愤怒，因为对方背叛了他” | 删掉“感到”和“因为”，写动作 |
| 过渡 + 过渡 | “随着天色渐暗，与此同时……” | 拆成两句，删掉过渡词 |
| 安全 + 安全 | “某种程度上的某种变化” | 改成精确描述 |
| 均匀 + 均匀 | 连续 5 句都是“他做了什么，然后做了什么” | 长短交替，加中断 |
| 先景 + 解释 | “夕阳很美。这说明一天结束了。” | 删解释，让夕阳自己说话 |

## AI 味检测流程

1. **扫描标记**：搜索“感到/觉得/认为/意识到”“由于/随着/与此同时”“不禁/不由/忍不住”“可能/大概/似乎/某种”。
2. **分类处理**：解释腔和概括情绪优先删除；过渡词按 P1 处理；安全表达和均匀句式按 P2 处理，不机械替换。
3. **通读验证**：读改后的段落，确认仍像这个人物、这个叙述者、这本书；删了反而不通就回退。

## 快速检查（1 分钟）

随机抽 3 段：

1. 有“感到/觉得”吗？→ 有则检查是否解释或概括。
2. 有连续 3 句同样开头吗？→ 有则改写节奏。
3. 有“由于/随着”吗？→ 有则考虑删掉。

任一题“有”→ 进入 AI 味检测流程，并用 `去味手法.md` 判断受损效果。
