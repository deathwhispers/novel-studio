# 老司机词汇总表

网文写作中的双关/隐晦词汇库。适用于都市、玄幻、仙侠等品类中需要含蓄表达的场景。Writer 按需加载，Critic 的 StyleChecker 用于判断是否为有意使用的修辞还是误用。

## 使用原则

- 这些词汇的核心特征是**字面正经、别有深意**——单独使用时读者各有理解，组合使用时指向明确
- 用于角色对话中制造笑点、塑造老司机人设、或营造暧昧氛围
- 不当使用会显得低俗——应与人物性格和场景功能匹配
- 一章不超过 2 处，避免堆砌

## 成语类（字面正经型）

| 词汇 | 字面意思 | 深层含义 | 适用场景 |
|------|---------|---------|---------|
| 古道热肠 | 古道上的热心肠 | 古道=旧路/老路 | 角色感叹老友重逢 |
| 曲径通幽 | 弯曲小路通向幽静处 | 曲折路径通往幽处 | 环境描写、双关调侃 |
| 羊肠小道 | 羊肠般狭窄的小路 | 狭窄通道 | 地形描写 |
| 管鲍之交 | 管仲与鲍叔牙的深厚友谊 | 谐音双关 | 兄弟情描写 |
| 日久生情 | 时间久了产生感情 | 日久=长时间 | 感情线发展 |
| 扶摇直上 | 乘风直上青云 | 扶摇=乘风而上 | 修炼突破描写 |
| 人多势众 | 人多势力大 | 势众=势力众多 | 描述势力/人数优势 |
| 势大力沉 | 势头大力量沉 | 势大=势头猛烈 | 战斗描写 |
| 腹背受敌 | 前后都受到攻击 | 腹背=前后 | 战斗困境描写 |
| 双管齐下 | 两根管子同时下去 | 两根管子同时运作 | 同时进行两件事 |
| 深入敌后 | 深入到敌人后方 | 深入=到深处 | 战斗策略描写 |

## 成语类（字面可双解型）

| 词汇 | 表面用法 | 隐性含义 | 警示 |
|------|---------|---------|------|
| 进退两男 | 两个男人，进退两难 | 进=进入，退=退出，男=男人 | 同人/耽美场景慎用 |
| 左右为男 | 左右都是男人 | 被男人包围 | 同人/耽美场景慎用 |
| 男上加男 | 男人上面还有男人 | 难上加难的变体 | 调侃困境 |

## 短句/对白类

| 词汇 | 用法 | 示例对白 |
|------|------|---------|
| 货从口出 | 货物从嘴里出来 → 祸从口出的变体 | 「我这人做生意，货从口出。」 |
| 同道中人 | 同一条道路上的人 | 「原来你也是同道中人。」 |
| 进进出出 | 反复进入和离开 | 「他在阵法中进进出出，找不到规律。」 |
| 口吐白沫 | 嘴里吐出白色泡沫 | 「中招后口吐白沫，倒在地上。」 |
| 莞尔一笑 | 微微一笑 | 常规用法，单独使用无歧义 |

## 招式/动作类

以下词汇可用于功法名、招式名或打斗动作描写，但需注意上下文的歧义风险：

| 词汇 | 正常用法 | 歧义触发条件 |
|------|---------|-------------|
| 老汉推车 | 老车夫推独轮车 | 单独出现时指向明确，打斗场景中慎用 |
| 观音坐莲 | 观音菩萨坐于莲台之上 | 功法名/招式名常见，单独出现有误解风险 |
| 进进出出 | 反复进出 | 与身体部位、人物位置搭配时触发 |
| 曲径通幽 | 秘境入口描写 | 与身体比喻搭配时触发 |
| 日后再说 | 以后再说 | 「日」字触发——「日后再议」同理 |

## 品类适配

| 品类 | 推荐用法 | 避免 |
|------|---------|------|
| 都市（都市暧昧/都市生活） | 用于角色对白制造幽默，一章 1-2 处 | 连续使用 |
| 仙侠/玄幻 | 用于老不正经型角色，或年轻弟子之间的调侃 | 正道宗师型角色 |
| 系统爽文 | 系统吐槽/评价中使用，增加趣味 | 严肃剧情节点 |
| 言情/女频 | 暧昧场景含蓄表达 | 过于直白的组合使用 |
| 悬疑/正剧 | 不使用 | 任何使用都会破坏氛围 |

## Critic 检测规则

StyleChecker 在检测这些词汇时，需判断：

1. **是否在允许的品类中** — 悬疑/正剧中出现 → Flag 为软问题
2. **密度是否过高** — 一章超过 2 处 → Flag 为软问题  
3. **是否与角色人设一致** — 清冷仙尊说「古道热肠」→ Flag 为硬伤
4. **组合使用** — 单用「古道热肠」无问题，但连续出现三个以上此类词 → Flag 为 AI 味的「刻意堆梗」
