# 老司机词汇总表

网文中的含蓄性暗示词汇库。以下所有词汇均具备**字面正经、暗含性暗示**的双重语义特征。适用于都市暧昧、玄幻后宫、仙侠双修等需要含蓄开车场景的品类。Writer 按需加载，Critic 的 StyleChecker 负责密度和人设合规检查。

> 核心特征：字面可过审、懂的自然懂。单用是修辞，组合是开车。

## 使用原则

- 这些词汇的本质是**一语双关**——字面意思完全正常，读者各有理解
- 用于角色对白制造笑点、塑造老司机人设、或需要「过审」的暧昧场景
- 如果品类/角色不需要这种效果，宁可直白描述也不要强行堆梗
- 一章不超过 2 处，避免从暧昧滑向猥琐
- 网络梗/俗语类自带「出戏」效果，适合制造意外笑点，不适合正剧

## tag 说明

每个词汇标注了 `tag`，用于检索命中。tag 含义如下：

| tag | 含义 | 典型用法 |
|-----|------|---------|
| `#谐音` | 靠谐音双关（鸡=阴茎、日=性交） | 对白笑点、老司机人设 |
| `#双关` | 字面正经、暗含性暗示 | 暧昧场景、过审开车 |
| `#意象` | 借景/物喻性（云雨、桃源、落红） | 含蓄描写、只可意会 |
| `#招式` | 具体姿势/动作（老汉推车、观音坐莲） | 直接开车、招式梗 |
| `#网络梗` | 网络流行语/出戏笑点 | 制造意外笑点、破次元 |
| `#对白` | 用于人物台词 | 角色对话、调情 |
| `#变体` | 成语/词的改造变体 | 谐音歪解、生造梗 |
