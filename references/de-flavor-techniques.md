# 去味手法

正面修复技法。目录（`ai-flavor-catalog.md`）告诉你「哪里有问题」，清单（`ai-flavor-checklist.md`）帮你检测，本文告诉你「怎么改成对的」。

> 原则：不只是删除 AI 味，而是用正确的写法替换。删掉坏句子留下空白不是修复——要用活人的写法填回去。

## 一、否定句修复

### 问题识别

AI 倾向通过否定来逼近描述——「不是 A，是 B」——但否定 A 没有创造任何画面，只是消耗读者的注意力。

三种变体：
- `不是……不是……而是……`（经典三句否定）
- `不是……。是……`（跨句否定）
- `不是……——是……`（破折号否定）

### 修复三步法

**第一步：删掉否定部分。** 把「不是 X」「没有 Y」全部砍掉。

**第二步：保留肯定部分。** 只留下「是 B」或「B」。

**第三步：补充具体细节。** 直接写 B 还不够，要把 B 写具体——读者不知道的事物，用一个可感知的细节代替。

### 示例

| 原文 | 第一步：删否定 | 第二步：留肯定 | 第三步：补细节 |
|------|-------------|-------------|-------------|
| 不是害怕，不是后悔，而是一种说不清的悸动。 | 一种说不清的悸动。 | 他心跳很快。 | 他心跳很快。不知道为什么。 |
| 不是闹钟。是系统。 | 是系统。 | 系统。 | 屏幕上的字在闪。系统的通知。 |
| 不是脏——是洗的次数太多，纤维已经开始变形了。 | 是洗的次数太多，纤维已经开始变形了。 | 洗的次数太多，纤维已经开始变形了。 | 领口泛黄。洗太多次了，纤维变了形。 |
| 没有预兆。她像想起什么事，干脆地转头往回走。 | 她像想起什么事，干脆地转头往回走。 | 她忽然转头往回走，像想起了什么事。 | 苏晴走到一半停住了。然后转身，沿着来的路走回去。 |

### 何时保留否定

只有一种情况保留否定：**角色内心真正的自我纠错**。

```
✅ 「我以为我会怕。」他顿了顿。「没有。」
   ——这是角色在纠正自己的预期，有心理内容

❌ 不是闹钟。是系统。
   ——这是叙事者在替读者做排除法，机械
```

## 二、罗列句修复

### 问题识别

AI 在需要表达因果关系或递进关系时，默认用序号——「第一……第二……第三……」或「首先……其次……最后……」。在叙事中，序号标签破坏沉浸感，让读者意识到「有人在组织信息」。

### 修复：顺序藏进因果

不告诉读者「有三点」，而是让事件本身按因果链展开：

| 原文 | 改后 |
|------|------|
| 他有两个选择：第一，接受系统任务；第二，拒绝然后等死。 | 系统给了任务。接了，可能会死。不接，一定会死。 |
| 首先搞清楚系统是什么，其次找到其他持有者，最后活下去。 | 先搞清楚系统是什么。能找到其他持有者就更好了——前提是活到那一天。 |
| 一方面他渴望力量，另一方面他又害怕被控制。 | 力量谁都想要。但万一系统在操控他呢？ |

核心技巧：
1. **用句号代替序号**——每一点独立成段，序号自然消失
2. **用因果代替枚举**——「因为 A，所以 B」优于「第一 A，第二 B」
3. **用角色内心的犹豫代替分析**——角色不会对自己说「第一第二」，他会反复权衡

## 三、解释腔修复

### 问题识别

AI 倾向写「情绪 + 原因解释」的完整句子——「他感到愤怒，因为他意识到自己被背叛了」。读者不需要你解释为什么愤怒，他们需要看到愤怒的样子。

### 修复：拆成两个动作

```
原文：他感到愤怒，因为他意识到自己被背叛了。
修复：他把杯子摔在地上。碎片溅到那个人脚边。
```

核心技巧：
1. 「感到 X」→ 换成 X 的身体反应
2. 「因为 Y」→ 换成 Y 的具体画面（如果是过去的事件）或角色此刻的微动作

## 四、机械修辞修复

### 问题识别

「xxx而xxx」「在这一刻」「随着……」——AI 强制使用转折、时间标记和连接词制造伪文学感。

### 修复：断句

```
原文：他的声音很轻，却很有力。
修复：他声音很轻。每个字都砸在地上。

原文：在这一刻，他终于明白了。
修复：他明白了。
```

核心技巧：「而/却」只用于真正的矛盾关系（又爱又恨）。普通的递进、对比、转折——拆成两句。

## 五、活人感注入

AI 味检测只能发现「缺了什么」——缺感官轮换、缺闲笔、缺身体反应、缺内心声音。以下 5 种手法用于**主动注入**活人感。

### 手法 1：闲笔

加一个与主线无关的、角色独有的无用动作或环境细节。

```
❌ 他拿起杯子喝水。
✅ 他拿起杯子，发现杯沿上有一个裂口。不知道什么时候磕的。继续喝。
```

闲笔不是水字数——它让读者感觉这个人物**生活在世界上**，而不是在执行剧情任务。

### 手法 2：感官轮换

读完一段，数一下用了几种感官。全是视觉 → 加一个触觉、听觉或嗅觉。

```
❌ 他走进房间。窗帘拉着。桌上有一杯没喝完的茶。旁边放着一封信。
✅ 他走进房间。空气里有烟味。窗帘拉着，桌上的茶已经凉透了。旁边放着一封信——纸是热的。
```

### 手法 3：身体反应优先

情绪不是被"感到"的，是被身体感知的。

| 情绪 | ❌ AI 写法 | ✅ 活人写法 |
|------|----------|----------|
| 紧张 | 他感到一阵紧张。 | 手心出汗。 |
| 恐惧 | 她感到恐惧。 | 胃里一紧，腿发软。 |
| 愤怒 | 他愤怒了。 | 脸上一阵热，手指掐进掌心。 |
| 放松 | 她感到放松。 | 肩膀终于塌下来。 |
| 尴尬 | 他尴尬极了。 | 耳朵发烫。不敢看对面的人。 |

### 手法 4：内心声音

叙事者不是上帝——是角色在感知世界。允许角色在心里吐槽、骂人、自言自语、说半句话。

```
❌ 这个任务显然超出了他的能力范围。
✅ 开什么玩笑。这任务是人做的？
```

### 手法 5：不完美保留

真实的人写作有怪癖——不对称、重复、半截句子、改口。AI 打磨过的文字把这些全删了，结果像润色过度的范文。

```
❌ 她看着窗外的雨，思绪万千。（太光滑了）
✅ 雨。她看了很久。不知道在看什么。
```

```
❌ 苏晴忽然回头。她像想起了什么事，干脆地转头往回走，差点跟后面的同学撞上。
✅ 苏晴忽然回头。后面的同学差点撞上她。她没道歉——像是根本没注意到有人——径直往回走。
```

保留原则：如果一个句子在读的时候让你停顿了 0.5 秒——但停顿是因为它有意思，不因为它写错了——那就留着。

## 六、对话去壳

### 问题识别

AI 写的对话像两个 AI 在互发消息——每句话都完整、礼貌、有信息量。真实的人说话会抢话、会跑题、会用语气词、会说一半咽回去、会用沉默代替回答。

### 修复：给对话加"毛边"

| 症状 | ❌ AI 对话 | ✅ 活人对话 |
|------|----------|----------|
| 太完整 | 「我认为这个方案可能存在一些问题。」 | 「不太对。」 |
| 太礼貌 | 「非常抱歉，是我考虑不周。」 | 「……怪我。」 |
| 太配合 | 「好的，我明白你的意思了。」 | 「行。」 |
| 太顺畅 | A：「你来了。」B：「是的，我来了。」 | A：「来了？」B：嗯。A：东西呢？B：先给我看钱。 |
| 太讲理 | 「既然你不同意，那我们可以协商。」 | 「你不同意？」他愣了一下。「那你来。」 |

### 对话检查清单

写完一段对话后问自己：
1. **能不能删掉一半？** 删掉后意思变了吗？没变 → 删
2. **有没有人没把话说完？** 整段对话没有一句被打断 → 加一次打断
3. **有没有人没有回答？** 每个问题都被正面回答了 → 把其中一个回答改成沉默或岔开话题
4. **有没有语气词/脏话/口头禅？** 整段对话像书面语 → 加一个"操""靠""啧"或口头禅
5. **有没有人说了废话？** 每句话都在推进剧情 → 加一句真正的废话（"这天真热""你吃了吗"）

### 对话节奏

```
❌ 均匀节奏：
A：「你确定要这么做？」
B：「我别无选择。」
A：「那你小心。」
B：「我会的。」

✅ 有节奏：
A：「你确定？」
B 没回答。把烟掐了。
A 等了三秒。「行。」他站起来。「死了别怪我。」
B 笑了一下。「不怪你。」
```

核心原则：对话不是传球——是拳击。不是每句话都要有来有回，可以有躲闪、有重击、有沉默。

## 七、细节选择

### 问题识别

AI 写细节是"尽职调查"式——把场景里的物品一个一个列出来。活人写细节是"偏见选择"式——只写角色此刻会注意的东西。区别在于：细节不是越多越好，是越对越好。

### 对的细节 vs 多的细节

```
❌ 细节堆砌（AI 尽职调查）：
房间不大。靠墙有一张木桌，桌上摆着杯子、一本书、一盏台灯。窗边是一张床，床单是蓝色的。地上铺着灰色的地毯。墙上挂着两幅画。

✅ 偏见细节（角色视角）：
房间里有股泡面味。桌上那本书翻开扣着，页角都卷了——看了不止一遍。
```

角色注意到的细节**暴露角色自己**：
- 一个警察进门会注意：出口位置、在场人的手、窗户开没开
- 一个小偷进门会注意：值钱的东西在哪、有没有人、逃跑路线
- 一个失恋的人进门会注意：和前任来过的地方、情侣座、那首歌

### 细节选择技巧

| 类型 | ❌ 随便一个细节 | ✅ 角色会注意的细节 |
|------|-------------|-----------------|
| 环境 | 桌子上有一杯水。 | 桌子上那杯水是满的。人刚走。 |
| 人物 | 她穿着一件红色连衣裙。 | 她那条红裙子，他见过——上周四，医院门口。 |
| 物品 | 墙上挂着一把剑。 | 剑柄上的缠绳已经磨断了。没用过的剑不会这样。 |
| 动作 | 他点了一根烟。 | 他点烟的时候打火机响了三次才着。手在抖。 |

核心原则：细节的功能不是描述世界——是暴露看世界的人。选那个有故事的，不选那个好看的。

## 八、节奏控制

### 问题识别

AI 写出的文字如同节拍器——每句差不多长、每段差不多密。活人写作像呼吸——有时急促、有时舒缓、有时憋一口气。

### 节奏类型与用法

| 节奏 | 句长特点 | 适用场景 | 示例 |
|------|---------|---------|------|
| 快（断奏） | 2-5 字短句，连续 | 打斗、紧急、紧张 | 门开了。他转身。刀光。 |
| 中（叙述） | 15-25 字中等句 | 日常推进、对话、过渡 | 正常叙述 |
| 慢（延展） | 30-50 字长句连用 | 沉思、抒情、氛围 | 细节铺陈 |
| 破（中断） | 长句后突然极短句 | 转折、揭示、震撼 | 啰嗦了半天然后 → 然后他死了。 |

### 实操：用句长画出情绪曲线

```
❌ 节拍器（每句差不多长）：
他走进房间。窗帘拉着。桌上放着一杯茶。旁边有一封信。他走过去。拿起信。拆开。看了一遍。

✅ 有呼吸（长短交替）：
他走进房间。空气里有股说不出的味道——烟味、茶味、还有一点血腥气。窗帘紧紧拉着，但外面在下雨，水从窗缝里渗进来，在地板上积了一小摊。
桌上有一杯茶。
凉的。
旁边放着一封信。他的手伸过去，在信封上方停了两秒。拿起来。
拆开。
看了一遍。又看了一遍。
```

### 节奏规则

1. 一场戏的节奏不能从头到尾一样——至少变两次
2. 打斗用短句，但打完后必须有一句中长句让读者喘气
3. 关键信息前面停顿——用短段、空白、或一个无用动作
4. 最重的话用最短的句子

## 九、留白与暗示

### 问题识别

AI 有一种焦虑——怕读者看不懂，于是把每一层意思都写出来。结果读者什么都看到了，什么也没有自己发现的快感。

好的小说是读者和作者的合作——读者需要自己拼出一些东西，拼出来的比被告知的印象深十倍。

### 三类留白

**1. 情绪留白：不写角色感受，写角色做的事**

```
❌ 他很难过。这么多年，她还是走了。
✅ 他把她的杯子收进柜子里。收完又拿出来。放回原处。
```

读者会自己感受到"难过"——而且比你直接告诉他更强烈。

**2. 因果留白：不解释为什么，只展示先后**

```
❌ 苏晴忽然回头，因为她想起了什么事。
✅ 苏晴忽然回头。后面的同学差点撞上她。她没道歉，径直往回走。
```

读者会自己推导"想起了什么事"——读者自己推导出来的因果关系，印象最深刻。

**3. 关系留白：不说"他们的关系是这样"，让互动展示关系**

```
❌ 他和父亲的关系一直不好。
✅ 「回来了？」父亲没抬头。他把书包扔在沙发上。上楼。关门的力气比平时重了一点。
```

### 留白尺度

| 留太多 | 刚好 | 留太少 |
|--------|------|--------|
| 读者完全不明白发生了什么 | 读者通过自己的推测理解了深层含义 | 读者被按着头喂每一层意思 |

核心原则：写七分，留三分。这三分是给读者的座位——让读者坐进来，参与这个故事。

## 十、人物反应链

### 问题识别

AI 写角色反应是单层的：事件 → 一个情绪 → 一个动作。真实的人反应是多层的、矛盾的、有延迟的——听到坏消息先是没反应，然后强装镇定，然后某个瞬间才崩。

### 三层反应法

```
❌ 单层反应（AI）：
他听到这个消息，感到非常震惊。

✅ 三层反应（活人）：
「你爸走了。」
他点了点头。手里还在削苹果。
削完。放下刀。把苹果放在桌上。站起来。
走到洗手间。
把门锁上。
```

反应链分析：
- **第一层（表面）**：点了点头，继续削苹果——大脑还没处理完
- **第二层（延迟）**：削完、放下、站起——身体开始执行"离开现场"
- **第三层（私下）**：锁门——崩溃发生在没人看到的地方

### 情绪的物理锚点

情绪不能漂浮在空中——必须有一个物理锚点让读者触摸到。

```
❌ 漂浮情绪：
他感到一种深深的无力感。

✅ 物理锚点：
他盯着天花板上的那道裂缝看了很久。裂缝从灯座延伸到墙角，像一条干涸的河。
```

| 情绪 | 找什么物理锚点 |
|------|-------------|
| 无力感 | 一件坏了很久没修的东西、一条打不通的电话 |
| 失去 | 一件留下来的物品、一个空了的座位 |
| 等待 | 一凉再凉的茶、反复看了又不回的屏幕 |
| 后悔 | 一条没走的路、一个没按的号码 |
| 疏离 | 隔着一层玻璃看世界、周围的人声像水下的声音 |

## 十一、口语化叙事

### 问题识别

AI 叙事永远用标准书面语——主语谓语宾语齐全，连词从不省略。真实的人讲故事不是这样的——会省略、会倒装、会用口语词、会用"就""才""都"这些虚词制造语气。

### 口语化改造

```
❌ 书面语叙事：
他等待了三个小时，对方仍未出现。他开始怀疑自己是否被欺骗了。

✅ 口语化叙事：
等了三个小时。人影都没有。靠，该不会是被耍了吧。
```

### 口语化技巧

| 书面语特征 | 口语化替代 |
|-----------|----------|
| 主语齐全 | 省略主语（"等了三个小时"） |
| 连接词完整 | 省略连词（"来了。没带钱。"） |
| 副词正式 | 用口语副词（"很/挺/有点/超"） |
| 语气中立 | 用感叹词（"操/靠/啧/哎"） |
| 句式完整 | 允许碎片句（"三个小时。人影都没有。"） |
| 被动语态 | 永远用主动语态 |

### 什么时候用口语化叙事

- 角色内心独白 → 强制口语化
- 贴近角色的第三人称叙事 → 半口语化（句法灵活，但不过分）
- 客观叙事（时间跨度大、上帝视角）→ 可以用书面语
- 抒情/氛围段落 → 看文风定位

核心原则：叙事的声音离角色越近，口语化程度越高。叙事的声音离角色越远，越可以用书面语。但除非在刻意制造史诗感——永远不要完全消除口语痕迹。

## 十二、反差与意外

### 问题识别

AI 写作的致命问题是**可预测性**——读者读到第二句就知道第五句要说什么。因为 AI 总是选择"最合理的"那个下一步。活人写作会在合理的基础上制造微小的意外——不是反转剧情，而是反转读者的期待。

### 三类微意外

**1. 行为意外：角色做了一件读者没猜到的事，但做完后又觉得合情合理**

```
❌ 可预测：
他打开系统面板，查看新任务。任务难度很高。

✅ 有意外：
他打开系统面板。
然后关掉了。
靠在椅子上，盯着天花板。三分钟。再打开。还是那个任务。
```

**2. 语言意外：用一个读者没想到的词**

```
❌ 可预测：
她笑得很开心。

✅ 有意外：
她笑得像个刚抢到糖的小孩——得意，还有一点心虚。
```

**3. 情绪意外：在一个该悲伤的场合写一个不该悲伤的细节**

```
❌ 可预测：
葬礼上，所有人都很悲伤。

✅ 有意外：
葬礼那天，他记得最清楚的是殡仪馆的空调太冷了。冷得他一直搓手。搓完左手搓右手。搓了一整个仪式。
```

### 意外的尺度

不是每句话都要意外——那就变成刻意了。一章有一两处微意外就够了。功能是让读者在流畅的阅读中偶尔要停一下，重新调整预期，然后被满足。

## 十三、快速修复流程（完整版）

写完一章后，按以下顺序处理：

### 第一遍：砍 — 删除 AI 味

按 `ai-flavor-checklist.md` 的关键词扫描逐项搜索，命中后按本文对应章修复：
1. 搜索「不是」「没有」→ 判定是否角色自我纠错，否则三步法修复（见「一、否定句修复」）
2. 搜索「第一」「首先」「一方面」「其次」「最后」→ 出现即拆（见「二、罗列句修复」）
3. 搜索「感到」「因为」「意识到」→ 解释腔修复（见「三、解释腔修复」）
4. 搜索「综上所述」「总而言之」「当然」「显然」→ 删掉
5. 搜索「而」「却」「随着」「在这一刻」→ 机械修辞修复（见「四、机械修辞修复」）

### 第二遍：加 — 注入活人感

6. 抽 3 段，检查感官轮换 — 连续 300 字只有视觉 → 加触觉/听觉
7. 抽 3 段，检查闲笔密度 — 无无用动作/环境杂音 → 加一个
8. 抽 3 段，检查身体反应 — 情绪只用脸部描写 → 加身体反应
9. 抽 3 段，检查内心声音 — 无吐槽/自言自语/走神 → 加一句

### 第三遍：调 — 优化质感

10. 对话检查：有没有打断/沉默/废话/语气词？没有 → 加
11. 细节检查：每个细节是这个角色会注意的吗？不是 → 换成角色偏见细节
12. 节奏检查：这段戏的句子节奏变了几次？一次没变 → 调整
13. 留白检查：有没有地方写得太满？是 → 砍掉解读部分，留给读者
14. 意外检查：有没有地方让读者猜到下一步了？有 → 在不破坏逻辑的前提下制造一个微意外

### 第四遍：读

15. 读出声。不是默读——读出声音。哪里卡了就改哪里。舌头是最诚实的编辑器。
