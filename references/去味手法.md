# 去味手法

与 `ai-flavor-catalog.md` 配套的正面修复技法。目录告诉你「哪里有问题」，本文告诉你「怎么改成对的」。

> 原则：不只是删除 AI 味，而是用正确的写法替换。删掉坏句子留下空白不是修复——要用活人的写法填回去。

## 一、否定句修复

### 问题识别

AI 倾向通过否定来逼近描述——「不是 A，是 B」——但否定 A 没有创造任何画面，只是消耗读者的注意力。

三种变体：
- `不是……不是……而是……`（经典三句否定）
- `不是……。是……`（跨句否定）
- `不是……——是……`（破折号否定）

### 修复三步法

**第一步：删掉否定部分。** 把「不是 X」「没有 Y」全部砍掉。

**第二步：保留肯定部分。** 只留下「是 B」或「B」。

**第三步：补充具体细节。** 直接写 B 还不够，要把 B 写具体——读者不知道的事物，用一个可感知的细节代替。

### 示例

| 原文 | 第一步：删否定 | 第二步：留肯定 | 第三步：补细节 |
|------|-------------|-------------|-------------|
| 不是害怕，不是后悔，而是一种说不清的悸动。 | 一种说不清的悸动。 | 他心跳很快。 | 他心跳很快。不知道为什么。 |
| 不是闹钟。是系统。 | 是系统。 | 系统。 | 屏幕上的字在闪。系统的通知。 |
| 不是脏——是洗的次数太多，纤维已经开始变形了。 | 是洗的次数太多，纤维已经开始变形了。 | 洗的次数太多，纤维已经开始变形了。 | 领口泛黄。洗太多次了，纤维变了形。 |
| 没有预兆。她像想起什么事，干脆地转头往回走。 | 她像想起什么事，干脆地转头往回走。 | 她忽然转头往回走，像想起了什么事。 | 苏晴走到一半停住了。然后转身，沿着来的路走回去。 |

### 何时保留否定

只有一种情况保留否定：**角色内心真正的自我纠错**。

```
✅ 「我以为我会怕。」他顿了顿。「没有。」
   ——这是角色在纠正自己的预期，有心理内容

❌ 不是闹钟。是系统。
   ——这是叙事者在替读者做排除法，机械
```

## 二、罗列句修复

### 问题识别

AI 在需要表达因果关系或递进关系时，默认用序号——「第一……第二……第三……」或「首先……其次……最后……」。在叙事中，序号标签破坏沉浸感，让读者意识到「有人在组织信息」。

### 修复：顺序藏进因果

不告诉读者「有三点」，而是让事件本身按因果链展开：

| 原文 | 改后 |
|------|------|
| 他有两个选择：第一，接受系统任务；第二，拒绝然后等死。 | 系统给了任务。接了，可能会死。不接，一定会死。 |
| 首先搞清楚系统是什么，其次找到其他持有者，最后活下去。 | 先搞清楚系统是什么。能找到其他持有者就更好了——前提是活到那一天。 |
| 一方面他渴望力量，另一方面他又害怕被控制。 | 力量谁都想要。但万一系统在操控他呢？ |

核心技巧：
1. **用句号代替序号**——每一点独立成段，序号自然消失
2. **用因果代替枚举**——「因为 A，所以 B」优于「第一 A，第二 B」
3. **用角色内心的犹豫代替分析**——角色不会对自己说「第一第二」，他会反复权衡

## 三、解释腔修复

### 问题识别

AI 倾向写「情绪 + 原因解释」的完整句子——「他感到愤怒，因为他意识到自己被背叛了」。读者不需要你解释为什么愤怒，他们需要看到愤怒的样子。

### 修复：拆成两个动作

```
原文：他感到愤怒，因为他意识到自己被背叛了。
修复：他把杯子摔在地上。碎片溅到那个人脚边。
```

核心技巧：
1. 「感到 X」→ 换成 X 的身体反应
2. 「因为 Y」→ 换成 Y 的具体画面（如果是过去的事件）或角色此刻的微动作

## 四、机械修辞修复

### 问题识别

「xxx而xxx」「在这一刻」「随着……」——AI 强制使用转折、时间标记和连接词制造伪文学感。

### 修复：断句

```
原文：他的声音很轻，却很有力。
修复：他声音很轻。每个字都砸在地上。

原文：在这一刻，他终于明白了。
修复：他明白了。
```

核心技巧：「而/却」只用于真正的矛盾关系（又爱又恨）。普通的递进、对比、转折——拆成两句。

## 五、活人感注入

AI 味检测只能发现「缺了什么」——缺感官轮换、缺闲笔、缺身体反应、缺内心声音。以下 5 种手法用于**主动注入**活人感。

### 手法 1：闲笔

加一个与主线无关的、角色独有的无用动作或环境细节。

```
❌ 他拿起杯子喝水。
✅ 他拿起杯子，发现杯沿上有一个裂口。不知道什么时候磕的。继续喝。
```

闲笔不是水字数——它让读者感觉这个人物**生活在世界上**，而不是在执行剧情任务。

### 手法 2：感官轮换

读完一段，数一下用了几种感官。全是视觉 → 加一个触觉、听觉或嗅觉。

```
❌ 他走进房间。窗帘拉着。桌上有一杯没喝完的茶。旁边放着一封信。
✅ 他走进房间。空气里有烟味。窗帘拉着，桌上的茶已经凉透了。旁边放着一封信——纸是热的。
```

### 手法 3：身体反应优先

情绪不是被"感到"的，是被身体感知的。

| 情绪 | ❌ AI 写法 | ✅ 活人写法 |
|------|----------|----------|
| 紧张 | 他感到一阵紧张。 | 手心出汗。 |
| 恐惧 | 她感到恐惧。 | 胃里一紧，腿发软。 |
| 愤怒 | 他愤怒了。 | 脸上一阵热，手指掐进掌心。 |
| 放松 | 她感到放松。 | 肩膀终于塌下来。 |
| 尴尬 | 他尴尬极了。 | 耳朵发烫。不敢看对面的人。 |

### 手法 4：内心声音

叙事者不是上帝——是角色在感知世界。允许角色在心里吐槽、骂人、自言自语、说半句话。

```
❌ 这个任务显然超出了他的能力范围。
✅ 开什么玩笑。这任务是人做的？
```

### 手法 5：不完美保留

真实的人写作有怪癖——不对称、重复、半截句子、改口。AI 打磨过的文字把这些全删了，结果像润色过度的范文。

```
❌ 她看着窗外的雨，思绪万千。（太光滑了）
✅ 雨。她看了很久。不知道在看什么。
```

```
❌ 苏晴忽然回头。她像想起了什么事，干脆地转头往回走，差点跟后面的同学撞上。
✅ 苏晴忽然回头。后面的同学差点撞上她。她没道歉——像是根本没注意到有人——径直往回走。
```

保留原则：如果一个句子在读的时候让你停顿了 0.5 秒——但停顿是因为它有意思，不因为它写错了——那就留着。

## 六、快速修复流程

写完一章后，按以下顺序处理：

1. **否定句扫描**：搜索「不是」「没有」→ 每个都要问：这是角色在自我纠错，还是叙事者在替读者做排除法？后者 → 三步法修复
2. **罗列句扫描**：搜索「第一」「首先」「一方面」→ 出现即拆，用因果链重写
3. **解释腔扫描**：搜索「感到」「因为」「意识到」→ 拆成身体反应 + 画面
4. **活人感注入**：抽 3 段，对照 5 种手法，缺什么补什么
5. **通读**：改完后读一遍，确认改过的地方仍然像这个人物、这个场景
