# 描写素材检索索引

> 轻量检索入口。Writer 描写女性外貌/气质/身材、穿搭造型，或需要含蓄性暗示词汇时，**先加载本索引**，按 `tag` 定位，用 `Read` 工具从目标行号读起，读到下一个 `###` 或 `---` 之前为止，**不要加载整个素材库**。

## 使用方式

1. 确定当前场景需要的 `tag`（如 `#都市` `#职场`，或 `#意象` `#对白`）
2. 在下方表格定位到「段落标题 + 行号」
3. `Read` 目标素材库，`offset` = 行号，只读到下一个 `###` / `---` 前
4. 读完即弃，不保留整个素材库

> 维护说明：素材库新增 / 删除 / 重命名类型会**改变行号**，须同步更新本索引的对应行，避免索引与素材库脱节。
