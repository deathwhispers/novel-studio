# 描写素材检索索引

> 轻量检索入口。Writer 描写人物（外貌/气质/身材/性格）、穿搭、资产（豪车/名表/房产/奢侈服饰/神豪消费符号）、环境场景、美食，或需要含蓄性暗示词汇时，**先加载本索引**，按 `tag` 定位，用 `Read` 工具从目标行号读起，读到下一个 `###` 或 `---` 之前为止，**不要加载整个素材库**。

## 使用方式

1. 确定当前场景需要的 `tag`（如 `#都市` `#职场`，或 `#意象` `#对白`）
2. 在下方表格定位到「段落标题 + 行号」
3. `Read` 目标素材库（位于 `references/lib/`），`offset` = 行号，只读到下一个 `###` / `---` 前
4. 读完即弃，不保留整个素材库

## tag 规范

- tag 用 `#中文词` 表达属性/题材/氛围/身份（`#都市` `#职场` `#气质` `#性格`），专有名词缩写用 `#英文`（`#BBA`）
- 每库有主类目 tag 作为第一项（`#性格` `#神豪` `#美食` `#豪车` `#名表` `#房产` `#奢侈服饰`），检索时先定库、再按属性组合命中
- 跨库可复用的通用维度：档次（`#超豪华`/`#顶级`/`#高奢`/`#高端`）、圈层（`#老钱`/`#身份`/`#新贵`）、题材（`#都市`/`#校园`/`#职场`）

> 维护说明：素材库新增 / 删除 / 重命名类型会**改变行号**，须同步更新本索引的对应行，避免索引与素材库脱节。
