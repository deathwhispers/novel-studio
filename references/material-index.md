# 描写素材检索索引

> 轻量检索入口。Writer 描写人物（外貌/气质/身材/性格）、穿搭、资产（豪车/名表/房产/奢侈服饰/神豪消费符号）、环境场景、美食，或需要含蓄性暗示词汇时，**先加载本索引**按 `tag` 定位条目标题，再用 `grep -n` 在目标素材库中动态定位该标题的行号，`Read` 读到下一个 `###` 或 `---` 之前为止，**不要加载整个素材库**。

## 使用方式

1. 确定当前场景需要的 `tag`（如 `#都市` `#职场`，或 `#意象` `#对白`）
2. 在下方表格定位到「段落标题」（记住标题即可，无需行号）
3. `grep -n "^### .*标题" 目标素材库` 得到该段落的当前行号（`^### .*` 锚定标题行，兼容「1.」与「一、」两种序号）
4. `Read` 目标素材库（位于 `references/lib/`），`offset` = 上一步行号，只读到下一个 `###` / `---` 前
5. 读完即弃，不保留整个素材库

## tag 规范

- tag 用 `#中文词` 表达属性/题材/氛围/身份（`#都市` `#职场` `#气质` `#性格`），专有名词缩写用 `#英文`（`#BBA`）
- 每库有主类目 tag 作为第一项（`#性格` `#神豪` `#美食` `#豪车` `#名表` `#房产` `#奢侈服饰`），检索时先定库、再按属性组合命中
- 跨库可复用的通用维度：档次（`#超豪华`/`#顶级`/`#高奢`/`#高端`）、圈层（`#老钱`/`#身份`/`#新贵`）、题材（`#都市`/`#校园`/`#职场`）

> 维护说明：行号不再硬编码——检索时用 `grep -n` 动态定位，素材库增删条目不会导致索引错位。仅当条目标题（`### 标题`）重命名或增删时，需同步更新本索引表格的「段落标题」与 `tag`。

### tag 说明

| tag | 含义 |
|-----|------|
| `#谐音` | 靠谐音双关（鸡=阴茎、日=性交） |
| `#双关` | 字面正经、暗含性暗示 |
| `#意象` | 借景/物喻性（云雨、桃源、落红） |
| `#招式` | 具体姿势/动作（老汉推车、观音坐莲） |
| `#网络梗` | 网络流行语/出戏笑点 |
| `#对白` | 用于人物台词 |
| `#变体` | 成语/词的改造变体 |

### 词汇类别

| 类别 | 主要 tag | 典型词 |
|------|---------|--------|
| 成语/四字词 | `#双关` `#意象` `#谐音` | 古道热肠、曲径通幽、翻云覆雨、巫山云雨、红杏出墙 |
| 变体成语 | `#谐音` `#变体` `#双关` | 日理万鸡、见鸡行事、大鸡大利、埋头苦干 |
| 短句/对白 | `#对白` `#双关` `#谐音` | 日后再说、深入交流、进去坐坐、你懂的 |
| 招式/动作 | `#招式` `#双关` | 老汉推车、观音坐莲、老树盘根、毒龙钻 |
