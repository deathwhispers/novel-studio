# 穿搭描写素材库

> 使用说明：按时代/题材打 tag 的穿搭描写素材库，与 [`beauty-description-library.md`](beauty-description-library.md) 配套——那个写「人」，这个写「衣」。穿搭描写同样是 AI 味重灾区（「她穿着一件 X 色的 XX 裙」），须贯彻去味原则：写单品的质感、剪裁、搭配效果，写衣服衬出的人，不写「她很会穿」「气质出众」这种空泛词。

## 穿搭描写去味原则

1. **不写模板句** —— 「她穿着一件白色连衣裙」是档案，不是描写。
2. **写质感与剪裁** —— 面料、垂坠、收腰、开衩，比「漂亮」「时尚」更有画面。
3. **写衣服衬出了什么** —— 腰、腿、锁骨、气场，不写「她很会穿」。
4. **写穿搭与人物的关系** —— 这套衣服暴露了她的身份/性格/处境。
5. **用细节代替概括** —— 一条裙子的开衩高度、一颗扣子的解与不解，比「性感」更具体。
