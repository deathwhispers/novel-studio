# 男性角色描写素材库

> 使用说明：这是「男性角色描写」的专项素材库，与 [`ai-flavor-catalog.md`](../ai-flavor-catalog.md)、[`de-flavor-techniques.md`](../de-flavor-techniques.md) 配套，服务都市文、神豪文、豪门文、系统文。写男主或其他主要男性角色的外貌、气场、身材、神态时按需加载，先查「高频 AI 味速查表」排雷，再按 `tag` 命中对应类型。
>
> 与 [`beauty-description-library.md`](beauty-description-library.md) 分工：美女库写女性角色的外貌气质，本库写男性——重点是男主的气场、身材、神态。写男主的核心不是「他多帅」，是「他是谁」：靠细节、靠反应、靠记忆点，让读者隔着文字感受到这个人压得住场。
>
> 组织方式按四个维度分层，对应「立人设 → 定气场 → 截面描写 → 神态记忆点」的写作顺序：
> 1. **男主类型**（他在故事里是谁）→ 决定叙事功能
> 2. **气质气场**（他给人的感觉）→ 决定人设能否立住
> 3. **身材体型 / 局部焦点**（他具体长什么样）→ 决定细节描写爽不爽
> 4. **神态表情 / 身段姿态 / 声音**（他身上最抓人的一个点）→ 决定读者记不记得住他
>
> 每个类型给「`tag` + 一句话核心 + ❌ AI 味反例 + ✅ 完整描写（200–300 字）+ ✅ 短句速写（一句话抓人）+ ✅ 侧面反应（旁人视角）」。三种写法按场景取用：完整描写用于重点人物铺陈，短句速写用于一笔带过，侧面反应用于借他人眼睛侧面写人。其中「身材体型」「局部焦点」「神态表情」「身段姿态」「声音」五个专题例外，用要点式：`tag` + 要点 + 传情角度（写X→）+ 示范短句，便于写作时引用要点自己造句。`tag` 用于检索命中：按品类（都市/校园/军旅/豪门）、身份（男主/霸总/赘婿/兵王）、属性（气场/身材/气质/神态）快速定位。示范段落可直接套用，替换掉具体的人名、场景、动作即可，不要整段照抄。

## 核心原则（写男主专项去味）

### 五大 AI 味陷阱

| 陷阱 | 表现 | 例子 |
|------|------|------|
| 面瘫高冷 | 全程一个表情，读者 get 不到性格 | 「他面无表情，周身散发着冷气」 |
| 帅而无物 | 只堆形容词，没有记忆点 | 「他高大英俊、剑眉星目、气宇轩昂」 |
| 出场即巅峰 | 一上来把身份家世全交代 | 「他是龙国第一豪门唯一继承人……」 |
| 替读者惊叹 | 写完外貌让配角喊帅 | 「众人倒吸一口凉气：好帅的男人！」 |
| 现成模板 | 「邪魅一笑」「气场全开」随手就用 | 「他邪魅一笑，气场全开」 |

### 五条写男主方法

1. **写气场不写标签** —— 「压得人喘不过气」是结果，要靠细节堆：一句话没人敢接、有人自动让路、空气安静了几秒。
2. **一个记忆点足够** —— 出场记住一个点（那双手、那道疤、那双眼），比五官全描一遍强十倍。
3. **通过别人写** —— 用配角/环境对他的反应侧面烘托：他进门，喧闹停了；他开口，有人坐直了。
4. **神态比外貌有用** —— 同一个人，笑着和冷着脸是两种气场。写神态就是写权力关系。
5. **气场靠留白** —— 不一次交代完，让读者自己感受到。宣布「他很强」最廉价，让人「猜他很强」才高级。

## 一、男主类型维度

### 1. 冷面霸总

**tag**：`#男主` `#霸总` `#都市` `#上位者` `#克制`

**核心**：话少、命令式、习惯掌控全场。冷不是没温度，是身份带出来的距离感——他不跟你熟，也不需要跟你熟。

**❌ AI 味**：他是冷面无情的商业帝王，高冷矜贵，生人勿近。

**✅ 完整描写**：
他把签好的文件往桌上一放，没抬头。「下一份。」声音不大，会议室里却没人敢动。他抬眼，视线落在那个僵住的人身上，两秒，那人慌忙去翻文件。他就是这种人——不说话的时候，整间屋子都替他屏着呼吸。开会他从不让废话落地，谁讲得长了，他指节敲两下桌面，那人就自动收声。可就是这样的一个人，下班路过前台，会停下来把那盆快枯的绿萝挪到窗边有光的地方，一言不发，像做一件很自然的事。后来那前台才想明白，他那冷，是对事不对人的——他没空跟谁热络，但该他照拂的，一件没落下。

**✅ 短句速写**：他把签好的文件往桌上一放：「下一份。」会议室里没人敢动。

**✅ 侧面反应**：他开口之前，整间屋子都替他屏着呼吸；下班路过前台，却会顺手把那盆快枯的绿萝挪到窗边。

### 2. 清冷校草

**tag**：`#男主` `#校草` `#校园` `#清冷`

**核心**：干净、疏离、成绩好。像隔着一层玻璃，谁都够不着，却又谁都忍不住多看两眼。

**❌ AI 味**：他是全校公认的校草，清冷孤傲，气质出众。

**✅ 完整描写**：
他在人群里很好认——不是最闹的那个，是人群里最静的那个。课间走廊挤成一锅粥，他靠在窗边，白衬衫袖口卷到小臂，低头翻着一本没人看得懂的原文书，周围的热闹到了他那儿，像隔了层玻璃，进不去。有人故意从他跟前路过，想引他抬头，他眼皮都不撩一下。可他也不是冷——同学去问他题，他把书一合，讲得很耐心，讲完又把书摊开，像方才那一幕没发生过。他这种人，好是好，就是太远了。你跟他坐同桌三年，可能都叫不出他半句闲话，只在某个下午，看见他趴桌上睡着了，阳光照着他侧脸，你忽然觉得，他其实也没那么远。

**✅ 短句速写**：人群里最好认的那个不是最闹的，是最静的——他靠窗翻书，周围的热闹到他那儿像隔了层玻璃。

**✅ 侧面反应**：有人故意从他跟前过，想引他抬头，他眼皮都不撩；可同桌来问题，他把书一合，讲得很耐心。

### 3. 痞气少年

**tag**：`#男主` `#痞` `#少年` `#不羁` `#野`

**核心**：不守规矩、嬉皮笑脸、天不怕地不怕。看着不着调，骨子里重义气，真遇上事第一个站前面。

**❌ AI 味**：他吊儿郎当，痞里痞气，玩世不恭。

**✅ 完整描写**：
他倚在门框上，斜挎着书包，嚼着口香糖，见谁都是一副「欠揍」的笑。老师点他名，他慢悠悠站起来，把问题驴唇不对马嘴地答一遍，逗得全班哄笑，他再一脸无辜：「啊？不对吗？」就这样的人，你指望不上他什么。可那天巷子里有人被堵，他正叼着烟路过，眼睛都没眨，书包一甩就进去了。事后他咧着嘴，拍拍被堵那人的肩：「行了，多大点事。」脸上还是那副没正经的笑，拳头上却破着皮。你才明白，他那身痞，是他给自己罩的壳——底下是什么样，得等他真出事才看得见。

**✅ 短句速写**：老师点他名，他慢悠悠站起来，一本正经答了个错的，逗笑全班：「啊？不对吗？」

**✅ 侧面反应**：巷子里有人被堵，他叼着烟路过，书包一甩就进去了——脸上还是那副笑，拳头上破着皮。

### 4. 兵王

**tag**：`#男主` `#兵王` `#铁血` `#军旅` `#硬汉`

**核心**：从部队出来的，身上带着规矩和杀气。沉默、精准、不废话，动起手来干净利落。

**❌ AI 味**：他是退役兵王，身手了得，浑身散发着铁血气息。

**✅ 完整描写**：
他坐着也像在站岗——背挺得笔直，手放在桌上，两腿平齐。聊天的时候他不怎么插话，偶尔应一声「嗯」，声音短促有力。服务员上菜，他接盘子的手很稳，稳到你能看出那不是练出来的，是刻进去的。有人喝多了找事，摔了杯子，他眉头都没皱一下，只是抬了下眼皮。那人隔着桌子还要骂，他忽然动了——也没见多快，就是起身、伸手、扣腕，三下，那人被他反剪着手按在桌上，全程没说一句话。等警察来了，他早松了手，坐回位子上，给对面那位续了杯茶，像什么都没发生。那杯茶，他倒得一滴都没洒。

**✅ 短句速写**：他坐着也像在站岗——背挺得笔直，接盘子那双手，稳得像是刻进去的。

**✅ 侧面反应**：那人隔着桌还要骂，他起身、伸手、扣腕，三下把人按桌上，全程没说一句话，倒茶一滴没洒。

### 5. 赘婿（扮猪吃虎）

**tag**：`#男主` `#赘婿` `#扮猪吃虎` `#隐忍` `#反杀`

**核心**：明明深藏不露，偏要装成窝囊废。吃过的亏、咽下的气，都是账，迟早连本带利讨回来。

**❌ AI 味**：他看似窝囊，实则深藏不露的顶级强者。

**✅ 完整描写**：
酒桌上，谁都能指使他两句。「林总」叫的是别人，他给自己倒酒，递烟，赔笑，话都说得很轻。大舅哥把烟头往他面前的烟灰缸里一按：「去，把车开过来。」他应一声「好」，起身就往外走，脸上看不出一点不情愿。没人正眼瞧他——赘婿嘛，吃软饭的，能有什么出息。直到那天，酒桌上有位真大佬，隔着几个人，忽然认出了他，端着酒杯绕过来，恭恭敬敬叫了声「林先生」。一桌人都愣住，他这才慢慢抬起头，脸上还是那副笑，只是那笑底下，冷得让人脊背发凉。他端起杯，跟大佬碰了一下，轻声说：「低调惯了，见笑。」

**✅ 短句速写**：大舅哥把烟头往他面前一按：「去，把车开过来。」他应声「好」，起身就走，脸上看不出一点不情愿。

**✅ 侧面反应**：真大佬隔着几个人认出他，端着杯绕过来，恭恭敬敬叫了声「林先生」——他抬起头，脸上还是那副笑，底下冷得让人发凉。

他总穿得随意，坐在哪儿都不显眼。饭局上他话不多，偶尔接一句，轻飘飘的，别人没在意。可每次那话落下去，总会有人暗自点头，心里想：这人，不简单。有人问他做什么的，他笑笑：「做点小生意。」谁都知道他在敷衍，可没人敢追问——因为上一个追问的人，后来再没在这桌上出现过。他不争、不抢、不解释，就那么坐着，像一潭深水，你扔多少石头进去，都听不见响。直到某天有人无意中翻出一份名单，赫然看见他的名字排在最上面，才后知后觉：原来整张桌子，都是围着他转的。他自己呢，还是那句「做点小生意」。

**✅ 短句速写**：他签单不看价签，笔一划，服务员眼睛都直了：「钱这东西，花出去才叫钱，攒着叫纸。」

**✅ 侧面反应**：他请全公司吃饭，专挑那个刚被欺负过的实习生的位子坐——从那以后，没人敢再欺负那孩子。

**✅ 短句速写**：再急的事，到他这儿都被熨平了——他先起身，递杯温水：「慢慢说。」

**❌ AI 味**：他是个偏执疯狂的病娇。

**✅ 完整描写**：

**✅ 短句速写**：他笑得很好看，眼睛弯弯的，像个无害的少年——可你看他盯着你的眼神，就知道那笑底下有东西。

**✅ 侧面反应**：你碰了他的人，他笑着说「没事」，一周后你的客户全没了、房退了租、连常走的路都在修。

## 五、神态表情维度

### 1. 抬眼（睥睨）

**tag**：`#神态` `#抬眼` `#睥睨` `#俯视`

**要点**：从忙碌/沉思中缓缓抬眼，是最经典的「气场开关」——抬眼的瞬间，气场全开。

**传情角度**：
- 写威慑 → 他慢悠悠抬起头，那一眼扫过来，满屋的喧闹都哑了
- 写轻蔑 → 他抬起眼，居高临下看过来，像看蝼蚁
- 写转折 → 他原本漫不经心，抬眼的那一瞬，眼神变了

**示范短句**：
- 他慢悠悠抬起眼，那一眼扫过来，满屋子的喧闹都哑了火。
- 他抬眼看了对方一眼，不咸不淡，可那一瞬间，气场全变了。

### 2. 眯眼（危险）

**tag**：`#神态` `#眯眼` `#危险`

**要点**：眯眼是「动念」的信号——往往在他察觉到不对、要出手或算计的瞬间。眯眼越慢，事越大。

**传情角度**：
- 写警觉 → 他眯了眯眼，目光钉在对面那人身上，像鹰盯上猎物
- 写怒 → 他眯着眼，眼里那点温度一点点冷下去
- 写盘算 → 他眯起眼，不知道在给谁下套

**示范短句**：
- 他眯了眯眼，目光钉过去，像鹰锁住了猎物。
- 他慢悠悠眯起眼，眼里的温度一点点降下去，冷得渗人。

### 3. 勾唇（邪笑）

**tag**：`#神态` `#勾唇` `#邪笑`

**要点**：只牵动一边嘴角的「半笑」——带戏谑、带挑衅、带危险，是男主的标志性表情。别每章都勾，用滥了就廉价。

**传情角度**：
- 写挑衅 → 他勾了勾嘴角，那笑里带着点挑衅的味儿
- 写笃定 → 他唇角一勾，像早把对方看透了
- 写危险 → 他笑得越深，对方越危险

**示范短句**：
- 他勾了勾嘴角，那点笑带着挑衅，像在说「你试试看」。
- 他唇角一勾，明明在笑，却笑得人心头发毛。

### 4. 挑眉（戏谑）

**tag**：`#神态` `#挑眉` `#戏谑`

**要点**：单边眉毛一挑，表达「哦？有意思」。带玩味、带审视、带一点居高临下的好奇。

**传情角度**：
- 写玩味 → 他挑了挑眉：「就这？」
- 写兴趣 → 他眉峰微挑，忽然来了兴致
- 写不信 → 他挑眉看着对方，那眼神明明白白写着「你继续编」

**示范短句**：
- 他挑了挑眉：「就这？」两个字，轻飘飘的，却刺得对方脸一红。
- 他眉峰微挑，慢悠悠看着对方，那眼神写着「你继续编」。

### 5. 冷笑

**tag**：`#神态` `#冷笑` `#嘲讽`

**要点**：从鼻腔里哼出来的一声笑——比任何话都伤人。写嘲讽、写居高临下、写忍到极点都用它。

**传情角度**：
- 写嘲讽 → 他冷笑一声，那点冷意直接扎进人骨头里
- 写不屑 → 他哼笑，连看都懒得多看对方一眼
- 写怒极 → 他冷笑出声，笑得越轻，怒气越重

**示范短句**：
- 他冷笑一声，那点凉意顺着耳根扎进骨头里。
- 他哼笑了一下，连正眼都懒得多给，比骂人还伤人。

### 6. 抽烟（动作神态）

**tag**：`#神态` `#抽烟` `#烟`

**要点**：抽烟是写男人气场的经典动作——点烟、夹烟、吐烟各有讲究。别滥用，写到情节点上才够劲。

**传情角度**：
- 写疲惫 → 他瘫进沙发里，点了一支烟，火光明明灭灭
- 写沉思 → 他夹着烟，半晌没抽一口，烟灰积了一截
- 写压迫 → 他吐出一口烟，烟雾里那张脸看不太真切

**示范短句**：
- 他点了一支烟，没急着抽，夹着，烟灰积了长长一截，才抬手吸了一口。
- 烟雾缭绕里，他那张脸看不太真切，只有烟头的火光明明灭灭。

### 7. 垂眸（克制）

**tag**：`#神态` `#垂眸` `#克制`

**要点**：垂下眼睑——收住情绪、盘算对策、隐藏心思。垂眸比抬眼更耐看，写内敛与城府用它。

**传情角度**：
- 写克制 → 他垂下眼，把到嘴边的火气压了回去
- 写盘算 → 他垂着眸，谁也看不见他眼里的算计
- 写收敛 → 他敛下眼底那点光，又变回那副无害的样子

**示范短句**：
- 他垂下眼，那点没出口的火气，被他硬生生压了下去。
- 他敛下眼眸，眼底那点锋芒一闪，又藏得干干净净。

### 8. 绷紧下颌（隐忍）

**tag**：`#神态` `#下颌` `#隐忍`

**要点**：情绪压到极点时，下颌线绷出一条硬线——比摔东西更见分量。写「忍」的高光时刻。

**传情角度**：
- 写忍怒 → 他下颌绷紧，青筋隐隐，却一个字没漏
- 写忍辱 → 对方骂得难听，他下颌咬得咯咯响，还是没动手
- 写隐忍 → 他喉结滚了滚，下颌紧了一下，把话咽了回去

**示范短句**：
- 他下颌绷成一条硬线，青筋隐隐，却一个字都没漏。
- 那人骂得难听，他下颌咬得咯咯响，到底还是忍住了。

### 9. 克制地笑

**tag**：`#神态` `#笑` `#克制`

**要点**：不是大笑，是唇角压不住的那一点弧度——真高兴、真被取悦、真动心时，冰山才有裂缝。写「破防」的高光。

**传情角度**：
- 写破防 → 他唇角压了压，没压住，还是弯了起来
- 写被取悦 → 他难得笑了一下，那点笑意让整张脸都亮了几分
- 写真心 → 他笑起来，眉眼间的冷意化开，像冰面裂开一道缝

**示范短句**：
- 他唇角压了压，没压住，还是弯了起来——冰山裂了一道缝。
- 他难得笑了一下，那点笑意把满眼的冷都化开几分。

### 10. 怒（暴怒前兆）

**tag**：`#神态` `#怒` `#暴怒`

**要点**：真怒不是咆哮，是「静得反常」。眼神、动作、语气层层收紧，等那个临界点爆开。写男主动真怒，要压着写。

**传情角度**：
- 写静怒 → 他越生气越安静，眼神冷得像结了霜
- 写临界 → 他捏着杯子的手收紧，指节泛白，杯壁裂开细纹
- 写爆发 → 他忽然笑了，笑得和煦，下一秒整张桌都被掀了

**示范短句**：
- 他越生气越安静，只那双眼睛，冷得像结了霜。
- 他手里那杯水，被他捏得指节泛白，杯壁裂开细细的纹路。

## 六、身段姿态维度

### 1. 坐姿（翘二郎腿/瘫坐/端坐）

**tag**：`#姿态` `#坐姿` `#姿态暗示身份`

**要点**：坐姿是一个人最不设防时的姿态。翘二郎腿是松弛，端坐是规矩，瘫坐是疲惫——三种坐姿，三种身份与心境。

**传情角度**：
- 写松弛 → 他翘起二郎腿，往沙发上一靠，那点气定神闲的姿态，比谁都写意
- 写紧张 → 他腿抖得桌子都在晃，压都压不住
- 写端坐 → 哪怕坐着，他背脊也挺得笔直，跟坐着也像站着似的

**示范短句**：
- 他往沙发里一瘫，翘起二郎腿，手肘搁在扶手上，那副姿态写意得像在自己家。
- 他哪怕坐着，背脊也挺得笔直，端坐得跟坐着也像站着似的。

### 2. 站姿（倚墙/叉腰/挺立）

**tag**：`#姿态` `#站姿` `#体态`

**要点**：站姿透气场。靠墙是随意，叉腰是挑衅，挺立是军人气质——别只写「他站了起来」。

**传情角度**：
- 写随意 → 他靠墙站着，一条腿微微曲着，看热闹都看得漫不经心
- 写挑衅 → 他双手抱胸，下巴一抬，对面那人就矮了下去
- 写挺立 → 他站得笔直，双手贴着裤缝，像钉在地板上

**示范短句**：
- 他靠墙站着，一条腿微微曲着，那副姿态闲散得好像全世界都跟他无关。
- 他双手抱胸，下巴微微一抬，对面那人就矮了半截气势。

### 3. 走姿（带风/沉稳/痞步）

**tag**：`#姿态` `#走姿` `#步伐`

**要点**：步态是男主气场的延伸。军警稳、霸总慢、痞子松——不同步态暗示不同身份与情绪。

**传情角度**：
- 写霸气 → 他两步走过来，每一步都踩得稳，像踩在对方心口上
- 写痞 → 他晃晃悠悠走过来，步子带点晃荡，一副天塌不下来的样子
- 写急 → 他几乎是一步三米地冲过来，那点急连装都装不住

**示范短句**：
- 他朝这边走过来，每一步都踩得稳，像一步一步踩在人心口上。
- 他晃晃悠悠走过来，步子带点晃，那副天塌都不慌的姿态，让人又爱又恨。

### 4. 倚门（懒）

**tag**：`#姿态` `#倚门` `#懒`

**要点**：倚门是男主经典出场姿势——单肩一靠，长腿一伸。出场一秒立住人设。

**传情角度**：
- 写出场 → 他倚在门框上，单肩一靠，看你从那头过来
- 写懒 → 他倚着门，那副姿态闲散得好像天塌下来也跟他无关
- 写心思 → 他倚着门，眼睛看着别处，不知道在想什么

**示范短句**：
- 他倚在门框上，单肩一靠，那副姿态像是在等人，又像是在等戏。
- 他靠着门，长腿往前伸，看着漫不经心，眼里却暗暗在数人头。

### 5. 俯身（压迫/温柔）

**tag**：`#姿态` `#俯身` `#逼近`

**要点**：俯身是制造距离感的动作——压下来时，气势瞬间贴近。写气场也写暧昧。

**传情角度**：
- 写压迫 → 他俯下身，那张脸直直逼过来，对方话都说不出来了
- 写暧昧 → 他俯下来，声音压得很低，气息都喷到她耳边
- 写交代 → 他俯下身，在你耳边低声交代了两句，那神情跟谈公事似的

**示范短句**：
- 他俯下身，那张脸直直逼过来，对方往后一缩，话全卡在嗓子眼里。
- 他俯过来，声音压得极低，气息喷在她耳边，让人起了一身鸡皮疙瘩。

### 6. 双手插袋（松弛/冷）

**tag**：`#姿态` `#插袋` `#松弛`

**要点**：双手插袋是男主最松弛的站姿——越松弛，气场越足。写不设防时的高位感。

**传情角度**：
- 写松弛 → 他双手插袋，看戏似的站着，连眼皮都懒得抬
- 写冷 → 他双手插袋，斜睨过来，那眼神凉得渗人
- 写思考 → 他双手插进裤袋，微微仰头，看着天

**示范短句**：
- 他双手插在裤袋里，看戏似的站着，连眼皮都懒得多抬一下。
- 他双手插袋，斜睨过来，那眼神凉得让人腿都软了半截。

### 7. 转身（背对/决绝）

**tag**：`#姿态` `#转身` `#背对`

**要点**：转身是态度——背对是一种「不跟你多讲」的姿态，写决绝、写权势压制都靠它。

**传情角度**：
- 写决绝 → 他没多说，转身就走，背影决绝得像一句封死的判决
- 写权势 → 他说完话，转身就走，根本不回头看对方反应
- 写傲 → 他懒得听完，转身的一瞬，给对方留了个不屑的侧脸

**示范短句**：
- 他没再多说一个字，转身就走，背影决绝得像一道无法上诉的判决。
- 话说完了，他转身就走，根本不回头看对方反应。

### 8. 递手（绅士/援助）

**tag**：`#姿态` `#递手` `#绅士`

**要点**：伸出手是一种姿态——对女主是绅士，对盟友是表态，对敌人是邀请入瓮的陷阱。

**传情角度**：
- 写绅士 → 他伸出手：「请。」一个字，礼数全到位
- 写援助 → 他伸出手，没说话，但那姿态比任何承诺都稳
- 写陷阱 → 他笑着伸出手，像请人入瓮

**示范短句**：
- 他伸出一只手，没说话，只是稳稳地托在那里——那姿态比任何承诺都让人安心。
- 他微微欠身，伸出一只手：「请。」一个字，礼数全到位。

## 七、声音维度

### 1. 低沉（磁性）

**tag**：`#声音` `#低沉` `#磁性` `#性感`

**要点**：嗓音压低、带着共鸣——磁性嗓是男频男主标配，写声音质感、写暧昧都用它。

**传情角度**：
- 写质感 → 他的声音压得很低，听着像大提琴的低音区
- 写暧昧 → 他压低声说话，气息带着热意，让人耳根发软
- 写气场 → 他开口，声音不重，整间屋子却听得清清楚楚

**示范短句**：
- 他压低嗓音，那句话带着点磁性的震感，让人耳根都软了。
- 他开口声音不重，可那把低沉的嗓音，让人听得清清楚楚。

### 2. 沙哑（磨过）

**tag**：`#声音` `#沙哑` `#磨过`

**要点**：嗓子磨过沙——是疲惫、是抽烟、是熬夜、是吼过。沙哑里带着故事感，写沧桑、写经历用它。

**传情角度**：
- 写沧桑 → 他声音沙哑，像是熬了一整夜
- 写故事 → 那嗓子像被风沙磨过，话里都带着颗粒感
- 写暧昧 → 他声音压得很低，略带沙哑，听得人心口发紧

**示范短句**：
- 那嗓子像被风沙磨过，话里都带着颗粒感，一听就知道熬过不少夜。
- 他压低嗓音，沙哑里带着点气声，听得人耳根都烧了起来。

### 3. 清冷（疏远）

**tag**：`#声音` `#清冷` `#疏远`

**要点**：音色清亮但冷——不带感情色彩，像冬天的井水。写疏离、写克制都靠它。

**传情角度**：
- 写疏远 → 他声音清冷得像冬天的井水，听不出一点温度
- 写克制 → 他嗓音清冽，话少，每个字都咬得很干净
- 写霸气 → 那把清冷的嗓压下来，比吼叫还管用

**示范短句**：
- 他嗓音清冷得像井水，听不出一点温度，字字都带着距离。
- 他开口声音不大，可那把清冽的嗓子压下来，比吼叫还让人发慌。

### 4. 浑厚（压场）

**tag**：`#声音` `#浑厚` `#压场`

**要点**：音色浑厚、底气足——天生的男中音。开口就稳气场，不用吼就能镇住场。

**传情角度**：
- 写压场 → 他开口，嗓子浑厚，一句话就把整个场子压了下来
- 写稳重 → 他说话中气足，字字落地有声
- 写可靠 → 那嗓音听着就让人心里踏实

**示范短句**：
- 他开口，嗓音浑厚，一句话就把整间喧闹压得静了下来。
- 他说话中气足，字字落地有声，听着就让人心里踏实。

### 5. 玩世不恭（散漫腔）

**tag**：`#声音` `#玩世不恭` `#散漫`

**要点**：语尾上扬、节奏散漫——痞男主、玩世不恭的人常用。写不羁、写戏谑都用它。

**传情角度**：
- 写玩世 → 他说话尾音上扬，像什么都无所谓似的
- 写戏谑 → 他那把嗓音调子拖得长，听着像在逗你玩
- 写调侃 → 他拖长调子说话，每个字都带着笑

**示范短句**：
- 他那把嗓音尾音拖得长，调子带笑，听着像在逗人玩。
- 他说话尾音上扬，慢悠悠的，每个字都带着股什么都不在乎的劲儿。

### 6. 哼笑

**tag**：`#声音` `#笑声` `#哼笑`

**要点**：从鼻腔里哼出来的笑声——「哼」一声带过，比开口骂人更冷。写嘲讽、写狠用它。

**传情角度**：
- 写嘲讽 → 他从鼻腔里哼了一声，那点冷意比骂人还狠
- 写不屑 → 他冷笑出声，懒得接你话茬
- 写危险 → 他笑得越轻，嗓子越冷，听得人后背发凉

**示范短句**：
- 他从鼻腔里哼出一声笑，那点冷意直往人骨头里钻。
- 他冷笑一声，懒得接话茬，那声音轻飘飘的，比骂人还伤人。
