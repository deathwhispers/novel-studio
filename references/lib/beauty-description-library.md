>
> 组织方式按四个维度分层，对应「定位 → 立人设 → 细节爽点 → 记忆点」的写作顺序：
> 1. **身份关系**（她在故事里是谁）→ 决定叙事功能
> 2. **气质类型**（她给人的感觉）→ 决定人设能否立住
> 3. **身材外貌**（她具体长什么样）→ 决定细节描写爽不爽
> 4. **局部焦点**（她身上最抓人的一个点）→ 决定读者记不记得住她
>
> 每个类型给「`tag` + 一句话核心 + ❌ AI 味反例 + ✅ 完整描写示范（200–300 字）+ ✅ 短句速写（一句话抓人）+ ✅ 侧面反应（旁人视角）」。三种写法按场景取用：完整示范用于重点人物铺陈，短句速写用于一笔带过，侧面反应用于借他人眼睛侧面写人。其中「眼睛」「五官部位」「身段姿态」「发型」「声音」五个专题例外，用要点式：`tag` + 形状/神态要点 + 传情角度 + 示范短句，便于写作时引用要点自己造句。`tag` 用于检索命中：按品类（都市/校园/职场/豪门/娱乐圈等）、功能（女主/女配/白月光）、属性（气质/身材/外貌）快速定位。示范段落可直接套用，替换掉具体的人名、场景、动作即可，不要整段照抄。

## 核心原则（美女描写专项去味）

### 八大 AI 味陷阱

| 陷阱 | 表现 | 例子 |
|------|------|------|
| 全景扫描式 | 眼睛→鼻子→嘴→身材机械罗列 | 「她有一双大眼睛，高鼻梁，樱桃小嘴，身材纤细」 |
| 成语堆砌 | 用成语代替画面 | 「倾国倾城、闭月羞花、沉鱼落雁」 |
| 陈旧意象 | 用烂了几千遍的比喻 | 「肌肤胜雪、眉目如画、杨柳细腰」 |
| 模板句式 | 万能句式套所有人 | 「她穿着一身 X 色连衣裙」「她微微一笑」 |
| 机械修辞 | 强行「X 而不失 Y」 | 「冷艳而不失温柔」「清纯中带着妩媚」 |
| 模糊偷懒 | 用模糊词逃避精确 | 「一种说不出的美」「美得让人窒息」 |
| 目光/眼神滥用 | 只会写「目光落在她身上」 | 「他的目光落在她身上，久久不愿移开」 |
| 无旁观者反应 | 只写「她美」，不写「别人怎么反应」 | 「她走进来，所有人都被她的美貌震惊了」 |

### 五条去味方法

1. **写「他注意到什么」，不写「她长什么样」** —— 从主角视角出发，写偏见、写反应，不写客观档案。
2. **写一个记忆点，不写十句堆砌** —— 一个有故事的特征，胜过十句漂亮但空洞的形容词。
3. **用动作神态写气质** —— 写她怎么坐、怎么笑、怎么说话，让气质自己浮出来。
4. **写反应链** —— 主角看到她 → 身体反应 → 心理 → 行为，一层层推进。
5. **感官轮换** —— 别只用视觉。她经过时带起的风、她的声音、她身上的味道，都比「漂亮」更有画面。

## 一、身份关系维度

### 1. 女主（官配）

**tag**：`#女主` `#核心女角` `#都市`

**核心**：故事的锚点，不需要最漂亮，但要有「就是她了」的唯一性。

**❌ AI 味**：她长得很美，是那种让人一眼就忘不掉的类型。

**✅ 完整描写**：
她不是那种第一眼就能在人群里被挑出来的长相。五官挑不出毛病，也挑不出惊艳，属于那种越看越耐看的类型。真正让他记住她的，是她笑起来的那个瞬间——眼睛先弯，然后嘴角才慢慢扬上去，像是一池水被风吹开。那天她穿一件洗得发白的蓝裙子，袖口磨出了毛边，可她抬手把头发别到耳后的时候，腕上那根红绳露出来，衬得手腕很细。他没由来地想起小时候老家屋檐下挂着的那串风铃，也是这样，安安静静的，风一过就响一下。

**✅ 短句速写**：她不是第一眼惊艳的那种，是越看越挪不开眼——尤其笑的时候，眼睛先弯。

**✅ 侧面反应**：一屋子人在说话，他总能在嘈杂里第一个听见她的声音。她一开口，别的声音就都淡了。

### 2. 白月光

**tag**：`#白月光` `#校园` `#都市` `#回忆`

**核心**：可望不可即的「神」，活在回忆滤镜里，主打距离感和「够不到」。

**❌ AI 味**：她穿着一身白裙，气质清冷，像不食人间烟火的仙子。

**✅ 完整描写**：
她永远站在离他三步远的地方。三年了，这三步他从没走完过。其实她长得并不算惊艳，甚至有点普通——皮肤白，眼睛不大，鼻梁也不算挺。可她站在那里的时候，自有一种让人不敢大声说话的气场，像隔着一层擦不干净的玻璃看他。她总是把校服的拉链拉到最上面，领子立起来，遮住半截下巴。风大的时候，她会眯一下眼睛，然后很快恢复那种波澜不惊的样子。他一直记得她低头写字时，发梢扫过纸面，像羽毛一下一下扫在他心上。够不着，也忘不掉。

**✅ 短句速写**：她永远站在离他三步远的地方，三年了，这三步他从没走完过。

**✅ 侧面反应**：她一进教室，喧闹声就莫名低了一截，连最皮的那几个男生都下意识坐直了身子。

### 3. 青梅竹马

**tag**：`#青梅竹马` `#校园` `#都市`

**核心**：熟悉感、安全感，被忽略的真心，主打「太熟了才突然看见」。

**❌ AI 味**：她其实长得很漂亮，只是主角一直没发现。

**✅ 完整描写**：

**✅ 短句速写**：她扎马尾的样子他闭着眼都能画出来，可那天她散着头发跑过来，他忽然就不敢认了。

**✅ 侧面反应**：旁人早就看在眼里，只有他还蒙在鼓里——明眼人都看得出，这姑娘对他和对别人不一样。

### 4. 女总裁

**tag**：`#女强人` `#职场` `#都市` `#豪门`

**核心**：权力、气场、距离感，写「贵」和「不敢直视」，不写「美」。

**✅ 侧面反应**：她环视一圈，没人敢迎她的目光，连端茶进来的秘书都屏着气。

**tag**：`#主播` `#娱乐圈` `#直播` `#双重人设`

**✅ 短句速写**：镜头里她笑得标准，镜头一关，那笑像面具一样，一秒就摘了。

**✅ 侧面反应**：弹幕刷得飞起，谁也不知道镜头后那个瘫在椅子上的疲惫女人，才是真的她。

**✅ 短句速写**：她道歉的样子楚楚可怜，眼泪在眼眶里打转，就是不落下来。

**✅ 侧面反应**：在场的人都在心疼她，唯独他注意到，她低头的瞬间，嘴角有一丝不易察觉的弧度。

### 16. 气质细节（动态呈现）

**tag**：`#气质` `#细节` `#动态`

**核心**：气质不是贴标签，是「用细节把气质演出来」。报「她很清冷」是 AI 味；写「她端起茶杯，指尖在杯沿轻轻一划，不抬眼」才是清冷。五种写法如下，可叠用。

**五种写法**：

**1. 小动作写气质**——捋发、托腮、转笔、咬唇、摩挲杯沿。气质藏在这些不经意的动作里。
- 写清冷 → 她转着笔，眼睛盯着别处，把一屋子人都晾在一边。
- 写妩媚 → 她咬着下唇，似笑非笑地睨你一眼。

**2. 微表情写气质**——眼波、嘴角、眉梢的细微变化，比语言更传神。
- 写高冷 → 她眉梢都没动一下，只从鼻子里哼出一个音。
- 写温柔 → 她眼睛弯了弯，没说话，笑意先到了。

**3. 习惯写气质**——端杯子的姿势、坐的姿态、笑的习惯，是气质的指纹。
- 写贵气 → 她端茶的动作极慢，杯盖轻扣，一点声响都没有。
- 写洒脱 → 她往椅子上一靠，一条腿随意搭着，半点不端着。

**4. 说话写气质**——语速、用词、停顿、口头禅，都是气质。
- 写知性 → 她说话不疾不徐，每句留半拍，让人不自觉地听。
- 写甜 → 她说话爱带「呀」「啦」，尾音上扬，像撒了糖。

**5. 反差写气质**——在压力、诱惑、突发状况下，气质才显真。冷峻的人为某人破功，最动人。
- 写破功 → 平时冷着一张脸的人，看见他受伤，手都抖了。
- 写反差 → 御姐式的人，私底下却会抱着玩偶睡觉。

**示范短句**：
- 她不看人，只低头把玩着杯子，指尖在杯沿上慢慢划着——那股子清冷，比说一百句「离我远点」都管用。
- 他伸手去接文件，她递过来时，手指在他掌心多停了半秒，然后若无其事地抽走。

## 四、局部焦点维度

> 局部焦点 = **记忆点**。全景扫描（眼睛→鼻子→嘴→身材）是 AI 味第一重灾区，局部焦点反其道而行：只写一个部位，写到让读者记住这个人。它和「身材外貌维度」的区别——身材外貌是「整体体型」（高挑/娇小/丰满），局部焦点是「某一个具体部位的极致特写」（一颗痣、一截锁骨、一处腰窝）。

## 五、身段姿态维度

> 身段姿态 = 动态的体态与动作。写「她怎么动」比写「她长什么样」更鲜活——一个回眸、一次撩发、一个伸懒腰，比三句外貌描写更抓人。与「身材外貌维度」（静态体型）的区别：身材外貌是「长什么样」，身段姿态是「怎么动」。
>
> 要点式：每类给 `tag` + 动作要点 + 神态要点 + 传情角度 + 示范短句，写作时引用要点自己造句。

### 1. 走姿（摇曳生姿）

**tag**：`#身段` `#走姿` `#摇曳` `#媚`

**动作要点**：腰肢轻摆，步态摇曳，走一步腰臀跟着动，步步生姿。

**神态要点**：妩媚、自信、从容——走起路来像自带 BGM，全场目光都跟着她走。

**传情角度**：
- 写媚 → 腰肢一扭一扭，走一步就晃一下人的眼
- 写自信 → 步子不紧不慢，背挺得笔直，目不斜视
- 写从容 → 她走得从容，高跟鞋一下一下，像踩在节拍上

**示范短句**：
- 她踩着高跟鞋走过，腰肢轻摆，一屋子人的目光都追着她的背影。
- 那步子不疾不徐，每一步都带着股说不出的风情。

- 写端庄 → 双手交叠身前，站姿端正，一看就是家教极好
- 写气场 → 她往那儿一站，周围人都不自觉地矮了三分

**示范短句**：
- 她站得笔直，肩背挺拔，像一根绷紧的弦，优雅又有力量。
- 往那一站，什么话都不用说，气场就压了满场。

**音色要点**：笑声爽朗洪亮，毫不掩饰，中气十足。

**神态要点**：豪爽、坦荡、有活力——一笑就透着股真性情。

**传情角度**：
- 写豪爽 → 笑得前仰后合，一点都不端着
- 写坦荡 → 那爽朗的笑，坦坦荡荡，毫无遮掩
- 写活力 → 笑声洪亮，像把阳光都笑进来了

**示范短句**：
- 她笑得前仰后合，声音洪亮，半点不端着。
- 那爽朗的笑声，像把一屋子的阴霾都冲散了。
