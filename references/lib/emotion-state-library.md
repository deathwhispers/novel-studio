# 情绪状态描写素材库

> 使用说明：这是「情绪状态描写」的专项素材库，与 [`../ai-flavor-catalog.md`](../ai-flavor-catalog.md)、[`../de-flavor-techniques.md`](../de-flavor-techniques.md) 配套，服务都市文、爽文、虐文、纯爱文。Writer 写到角色陷入某个情绪状态时按需加载，按 `tag` 命中对应类型。
>
> 与其他描写库的分工：美女/男性/性格库写"人长什么样/怎么待人"，爽点场景库写"情节怎么推得爽"，本库写"人在某个情绪里是什么样子"——**情绪状态**是内在驱动，神态动作是外在可见，两者互补，本库专注于前者。神态动作（如抬眼/冷笑/勾唇）已在 [male-description-library](male-description-library.md) 神态表情维度覆盖；本库聚焦**情绪**——震惊/愤怒/得意/冷冽/心碎/委屈/尴尬/绝望/慌张/羞愧/余悸/期待，十二类最常见情绪状态的"如何写"。
>
> 与现有 skill 的分工：情绪怎么写得动人，写得不出戏，已由 `skills/emotion-payoff/SKILL.md`（情绪兑现）、`skills/description/SKILL.md`（描写技法）、`skills/voice-check/SKILL.md`（同声腔检测）覆盖。本库给"哪些情绪要写出来"——具体到每一个情绪状态，给「`tag` + 核心 + 身体反应 + 思维特征 + 反 AI 味 + 完整示范段（200-300 字）+ 短句速写 + 侧面反应」，让 Writer 写到对应情绪时能立刻拿到"那一刻人是什么样"的范本。
>
> 组织方式按情绪的强度与极性分三个维度：
> 1. **强烈反应**（重头戏用）—— 震惊 / 愤怒 / 心碎 / 绝望
> 2. **温反应**（日常/过场用）—— 委屈 / 尴尬 / 余悸 / 羞愧
> 3. **隐性/特殊状态** —— 冷冽 / 得意 / 慌张 / 期待
>
> 每个情绪给「`tag` + 一句话核心 + 身体反应（那个情绪里人会怎样）+ 思维特征（那一刻会想什么）+ ❌ AI 味反例 + ✅ 完整示范段（200-300 字，多含神态/动作/内心/旁人反应）+ ✅ 短句速写（一句话抓人）+ ✅ 侧面反应」。**身体反应与思维特征**是本库的特色——把抽象的情绪拆成"身体看得见的部分"和"脑子里的部分"，写作时既可以二选一，也可以同时用，避免重复造句。`tag` 用于检索命中：按情绪名（`#震惊` `#愤怒`）、极性（`#正面` `#负面` `#中性`）、强度（`#强烈` `#温和` `#隐性`）快速定位。
>
> **节奏提醒**：情绪状态描写是"调料"，不是"主菜"。一章之内大情绪不要超过 2-3 个，否则读者会"麻"——情绪写多了，读者反而不感动。

## 核心原则（情绪描写专项去味）

### 六大 AI 味陷阱

| 陷阱 | 表现 | 例子 |
|------|------|------|
| 报情绪名 | 直接说"他很震惊" | 「他震惊得说不出话来」 |
| 模板反应 | 用"心如刀绞""瞳孔骤缩"代替具体反应 | 「他心如刀绞，瞳孔骤缩」 |
| 解释腔 | 写完反应再解释一遍 | 「他呆呆地站着，显然无法接受这个事实」 |
| 处处到位 | 每个角色反应都拉满 | 「全场所有人都震惊了」 |
| 替读者感 | 把角色的内心直白写出来 | 「他心里既震惊又愤怒」 |
| 静态描述 | 情绪只停留在一个画面 | 没有前后变化、没有过程 |

### 五条写情绪方法

1. **拆身体反应** —— 一个情绪要拆成几个身体部分：手、脸、呼吸、动作，每个部分各一句，比"震惊"两个字强十倍。
2. **拆思维特征** —— 人在那个情绪里，脑子会跑什么念头：是空白、是反复回放、是只想到一件事。把它写出来。
3. **写过程不写结果** —— 震惊不是一秒钟，是三秒、五秒、十秒；这中间他的反应在变。写过程才动人。
4. **不解释，让旁人反应收尾** —— 「他脸上血色刷地退了」比「他很震惊」更动人；围观者的议论比主角内心独白更可信。
5. **克制情绪的表达** —— 越是重头情绪，越不要堆砌字。给个动作、给个眼神、给个停顿，读者自己脑补。

## 一、强烈反应维度

### 1. 震惊

**tag**：`#情绪` `#震惊` `#负面` `#强烈`

**核心**：预料之外的事砸下来，脑子比身体慢半拍，先僵住、再回神、再反应。

**身体反应**：身体先定住 → 呼吸停一拍 → 瞳孔放大/失焦 → 嘴微张但说不出话 → 慢慢回神时手开始抖。

**思维特征**：先一片空白 → 反复回想"是不是听错了"→ 开始抓住一个细节死磕 → 慢慢承认是真的。

**❌ AI 味**：他震惊得说不出话来，瞳孔骤缩，整个人僵在原地。

**✅ 完整描写**：
"什么？"他手里那杯咖啡顿了一下，没放下，也没端起来，就那么端着。眼前那张单子还在桌上，他眼睛盯着同一行字，看了大概有半分钟。同事喊了他两声，他没听见。等同事凑过来推他一下，他才回过神，慢慢把咖啡放下来——放得不太稳，杯子磕在桌上，咖啡溅出来一点。他"哦"了一声，伸手去擦，擦的时候手是抖的。他没再问第二遍，也没再确认，只是把那杯咖啡端起来，喝了一口，喝完才发现，咖啡凉了。

**✅ 短句速写**：他手里那杯咖啡顿了一下，没放下也没端起来，就那么端着——看了那张单子半分钟。

**✅ 侧面反应**：同事喊他两声没听见，推他一下才回过神。

### 2. 愤怒

**tag**：`#情绪` `#愤怒` `#负面` `#强烈`

**核心**：真怒不是吼叫，是克制到极致后的爆发，或者压都压不住。越安静，越可怕。

**身体反应**：下颌咬紧 → 眼睛眯起来 → 呼吸变重变慢 → 拳头攥紧 / 物品被捏变形 → 颈上青筋隐现。

**思维特征**：脑子里只有一件事反复刷 → 控制自己想别冲动 → 真的忍不住 → 决定动手。

**❌ AI 味**：他勃然大怒，眼中燃起熊熊怒火。

**✅ 完整描写**：
他没说一句话。把那张报告慢慢放下，手掌压在上面，五指收拢——纸被他攥得起了褶。"再说一遍。"声音低得旁边人都没听见。对面那位又重复了一遍，听完，他点了点头，抬手，把桌上的笔筒抓起来，掼了出去。笔筒撞在墙上，零件和笔散了一地。他没看，下颌绷成一条硬线，眼里的温度一点点冷下去。他开口，每个字都压得很低："你刚才那句话，再说一遍试试。"

**✅ 短句速写**：他没说一句话，把那张报告攥得起了褶，抬手掼了笔筒——下颌绷紧，眼里那点温度冷下去。

**✅ 侧面反应**：他那一眼扫过去，对面那位后半句话生生咽了回去。

### 3. 心碎

**tag**：`#情绪` `#心碎` `#负面` `#强烈`

**核心**：不是嚎啕大哭，是一种更深的、更静的东西——是某样一直撑着的东西，被轻轻抽走了。

**身体反应**：呼吸变浅 → 整个人轻飘飘的，像丢了重量 → 眼眶发酸但不一定流泪 → 手指发凉 → 说话声音突然变得很轻。

**思维特征**：脑子里反复回放过去的某个片段 → "是不是我哪里做错了"→ 不想再想了，但停不下来 → 慢慢承认"是这样了"。

**❌ AI 味**：他心如刀绞，泪水夺眶而出，整个人仿佛被抽空了一般。

**✅ 完整描写**：
他站在那儿，看着她把行李箱推到门口。没说话，也没挡。屋里很安静，安静到能听见楼下小孩在哭。她拉开门，回头看了他一眼，嘴动了一下，又闭上，走了。门"咔哒"一声关上。他这才动了，不是追，是走到沙发边，坐下来。沙发上还有她刚才坐过的地方，还有点温度。他看着那个位置，看了很久。茶几上有两只杯子，一只满的，一只空的——满的那只是她的，空的那只是他的。他把那只满的端起来，没喝，又放下了。后来他不知道坐了多久，窗外的光一点一点暗下去，他没开灯。手机亮了一下，是她的消息，他没点开。

**✅ 短句速写**：门关上之后他没追，走到沙发边坐下来——茶几上那两只杯子，一只满的，一只空的。

**✅ 侧面反应**：手机亮了一下，是她的消息，他没点开。

### 4. 绝望

**tag**：`#情绪` `#绝望` `#负面` `#强烈`

**核心**：不是"还能搏一搏"那种，是"已经知道结局了"那种。平静得像水面，反而最让人心里发沉。

**身体反应**：身体像被抽空了力气 → 眼神放空 → 呼吸很浅很慢 → 说话声很轻，不带任何起伏 → 整个人向内塌陷。

**思维特征**：脑子反而很清醒 → 不再挣扎 → 一件一件回顾过去 → 开始想"接下来怎么收场"。

**❌ AI 味**：他陷入深深的绝望，感到整个世界都崩塌了。

**✅ 完整描写**：
他把手机放下，靠在椅背上，没动。屋子里很安静，那种没开灯的安静。桌上那堆文件他没再看，反正看了也没用。他抬手，把桌上的水杯端起来，杯子里是空的，他看了一眼，又放下了。他想站，站不起来；想喊，没力气喊；想哭，眼泪也干得差不多了。他就那么坐着，看着窗外。天早就黑了，对面楼的灯一盏一盏亮起来，跟他没关系。他知道没人会来，电话不会响，门不会开。他想的是另一件事——明天要不要去把那张卡里的钱取出来，给她转过去，剩下的留给她。这些事他脑子里已经过了一遍，过得很平静，像在交代后事。

**✅ 短句速写**：他靠在椅背上没动，杯子是空的，手机不会再响——他脑子里过得很平静，像在交代后事。

**✅ 侧面反应**：对面楼的灯一盏一盏亮起来，跟他没关系。

## 二、温反应维度

### 5. 委屈

**tag**：`#情绪` `#委屈` `#负面` `#温和`

**核心**：不是真大委屈，是"我做了这么多，你怎么能这样"的累积感。带着一点不甘，带着一点赌气。

**身体反应**：眼眶发红但不流泪 → 鼻尖发酸 → 下唇被咬住 → 手指抠衣角 / 攥紧袖口 → 喉咙发紧。

**思维特征**：反复回想自己之前做了什么 → 试图找"是不是我哪里没做好"→ 想开口又咽回去 → 决定"算了"。

**❌ AI 味**：他委屈得红了眼眶，眼泪在眼眶里打转。

**✅ 完整描写**：
他端着杯子走过去，把她要的那份资料递过去。她没抬头，扫了一眼："放这儿吧。"语气比跟别人还淡。他顿了一下，没走，把杯子轻轻搁在她手边，没说话。她终于抬头，看了他一眼："还有事？"他摇头，转身回工位。坐下之后，他盯着屏幕看了很久，一个字没打。同事过来问"你不舒服？"他摇头说"没事"，说完才发现声音有点哑。他用手背蹭了一下眼角，那儿没湿，只是发酸。他把键盘敲了两下，又停了，抬手把那张资料的发件记录翻出来看了一眼——昨晚十一点半改的，三处红色批注，七次保存。她看过一眼吗？他把记录关了，没再看。

**✅ 短句速写**：她扫了一眼："放这儿吧。"他转身回工位，翻出昨晚十一点半的修改记录——她看过一眼吗？

**✅ 侧面反应**：同事过来问"你不舒服？"他摇头说"没事"，说完才发现声音有点哑。

### 6. 尴尬

**tag**：`#情绪` `#尴尬` `#负面` `#温和`

**核心**：被当众戳破，或者自己搞砸了——那一瞬间希望地球裂开，自己能钻进去。

**身体反应**：脸先红 → 耳朵尖发烫 → 视线飘忽不知道看哪儿 → 手不知道放哪儿 → 强装镇定但身体出卖自己。

**思维特征**：脑子里飞快想"刚才说了什么"→ 想解释 → 解释不清 → 想立刻结束这一秒。

**❌ AI 味**：他尴尬得恨不得找个地缝钻进去。

**✅ 完整描写**：
话一出口，他就知道自己说错了。会议室里有两秒钟的安静，那两秒比两年还长。他咳了一声，端起杯子想喝口水压一压，杯子是空的。他放下，想接一句圆回来，又不知道从哪儿接。旁边那位同事低头假装看文件，肩膀抖了一下——他看见了，知道人家在憋笑。他抬眼看了看主持，那位也在看他，眼神很微妙。他硬着头皮把话往下讲，声音比刚才低了半档，讲完之后自己都没听见讲了什么。会散了，他走得最快，到工位上才松了一口气。打开电脑，先把刚才说的那句话打在搜索栏里查了一下——果然，是错的。他把搜索记录清掉，又清不掉。

**✅ 短句速写**：话一出口他就知道自己说错了——会议室里那两秒，比两年还长。

**✅ 侧面反应**：同事低头假装看文件，肩膀抖了一下。

### 7. 余悸（后怕）

**tag**：`#情绪` `#余悸` `#负面` `#温和`

**核心**：事情过去了，人没事，但身体比脑子先知道"刚才多危险"。是延迟反应，越想越怕。

**身体反应**：手心冒汗 → 腿软 / 想坐下来 → 呼吸不稳 → 后背发凉 → 胃里一阵翻搅。

**思维特征**：脑子反复回放刚才那一刻 → 想"如果再来一次"→ 一阵庆幸 → 一阵后怕。

**❌ AI 味**：他想起刚才那一幕，仍感到心有余悸。

**✅ 完整描写**：
电梯到了 28 层，门开，他走出来，腿有点软。刚才那个场景在他脑子里又过了一遍——电梯从 18 层猛地往下掉，安全钳刹住那一刻，他的手机正好拍下一张糊成一片的走廊。他扶住墙，没敢动，等呼吸慢下来，才一步一步往工位走。坐下来之后他发现，咖啡洒了一半在衬衫上，刚才一直没察觉。他抽了张纸巾擦，擦着擦着手抖起来。同事问"你脸色怎么这么白"，他说"没事"，把纸巾攥成团扔了。扔完才发现，攥得太紧，纸团被攥成了石头。他又拆开，重新叠好，慢慢叠，像要靠这个动作让自己稳下来。

**✅ 短句速写**：电梯到 28 层他走出来，腿有点软——咖啡洒了半边衬衫他一直没察觉。

**✅ 侧面反应**：同事问"你脸色怎么这么白"，他说"没事"，攥纸巾的手一直在抖。

### 8. 羞愧

**tag**：`#情绪` `#羞愧` `#负面` `#温和`

**核心**：被揭穿做错事的那一刻——不是被抓的慌，是知道"自己确实错了"的难堪。

**身体反应**：脸烫得发红 → 眼睛不敢直视 → 脖子僵硬 → 手不知道往哪儿放 → 想缩小存在感。

**思维特征**：疯狂想找借口 → 立刻意识到借口更难看 → 想"我怎么会这样"→ 决定承担。

**❌ AI 味**：他羞愧难当，无地自容，恨不得找个地缝钻进去。

**✅ 完整描写**：
数据摆出来的时候，他没敢看投影。他盯着自己桌面上一道浅浅的划痕，划痕看了三遍，投影上的数字听得很清楚——那是他改过的那个数。会议室里有人咳了一声，他这才抬头，对上老板的目光。他没解释，也没辩，只是说了一句："是我改的。"声音不大，但屋里都听见了。说完他没再抬头。散会之后他走得慢，路上有同事想跟他说话，他点了下头，没停。回到工位上他没坐下，靠着桌沿站着，看着窗外。手机里那条消息他删了，留着没意义；他改了那个数时图的那点小利，现在显得那么小，又那么丢人。

**✅ 短句速写**：数据一摆出来他没敢看投影——"是我改的"，声音不大，屋里都听见了。

**✅ 侧面反应**：散会之后他走得慢，同事想跟他说话，他点头，没停。

## 三、隐性 / 特殊状态维度

### 9. 冷冽

**tag**：`#情绪` `#冷冽` `#负面` `#隐性`

**核心**：不是"心情不好"——是某件事之后，那个人心里某扇门悄悄关了。从外人看，他还是那个他；从内里看，温度降到了底。

**身体反应**：眼睛比平时更静 → 笑的时候只动嘴角 → 说话慢半拍 → 动作比平时更稳 → 周围人下意识屏住呼吸。

**思维特征**：不再期待 → 一件件把人/事分类归档 → 决定了"接下来怎么做"→ 不再犹豫。

**❌ AI 味**：他周身散发出冰冷的寒意，让人不敢靠近。

**✅ 完整描写**：
她离开之后，他照常上班，照常开会，照常回邮件。同事说"你最近状态不错"，他笑了一下——是那种让同事觉得没什么的笑。下班他没直接回家，在公司楼下站了一会儿，看了一眼她以前常走的那条路，没动，转身走了。他没删她微信，也没拉黑，只是把她设成"免打扰"。他不恨她，也不怨她，只是从那天起，他把"再相信一个人"这件事，从清单上划掉了。回家路上他买了她爱吃的那种蛋糕——他知道那不是给自己买的，但还是买了。回家放到冰箱，关上门。第二天那块蛋糕还在那儿，第三天还在，第四天他拿出来，扔了。扔的时候他没犹豫。

**✅ 短句速写**：她走了之后他照常上班，照常开会——只是把"再相信一个人"从清单上划掉了。

**✅ 侧面反应**：同事说"你最近状态不错"，他笑了一下，是那种让人说不出什么的笑。

### 10. 得意

**tag**：`#情绪` `#得意` `#正面` `#隐性`

**核心**：高级的得意是不动声色的——他不需要别人看出来，他自己知道就够了。写在脸上的是张扬，写在眼里的是真得意。

**身体反应**：眉眼舒展 → 嘴角压不住的弧度 → 动作比平时松弛 → 看人的眼神带一点"居高临下"。

**思维特征**：脑子里反复回放刚才那一刻 → 想"看到没"→ 忍不住想跟亲近的人分享。

**❌ AI 味**：他嘴角勾起一抹得意的笑容。

**✅ 完整描写**：
他从会议室出来，没回头。电梯里他低头看手机，给老婆发了条消息："中午加个菜。"老婆回："怎么了？"他没解释，关了屏幕。嘴角动了一下，电梯门开，他快步往工位走。路上遇到几个同事，他打招呼时语气比平时松，有人夸他"今天看着心情好"，他只是"嗯"了一声，那点笑意压在眼底，没浮上来。他坐下，打开电脑，把刚才那份合同翻出来又看了一遍——甲方签字那栏，他盯着看了五秒，慢悠悠关掉。他靠在椅背上，看着窗外。窗外的光很好，他眯了眯眼，像只偷了腥的猫。

**✅ 短句速写**：他从会议室出来没回头，给老婆发了条消息"中午加个菜"——嘴角那点笑意压在眼底，没浮上来。

**✅ 侧面反应**：同事夸他"今天看着心情好"，他只是"嗯"了一声，那点得意藏在语气里。

### 11. 慌张

**tag**：`#情绪` `#慌张` `#负面` `#隐性`

**核心**：不是恐惧，是"这件事我接不住"的慌——明明很重要的事，自己却掉链子，时间又这么紧。

**身体反应**：呼吸变浅变快 → 手心出汗 → 动作开始乱 → 说话比平时快 → 眼睛乱飘找"谁能帮我"。

**思维特征**：脑子里闪过几个方案 → 都觉得不行 → 想"完了"→ 抓住一个救命稻草就上。

**❌ AI 味**：他慌得手足无措，急得像热锅上的蚂蚁。

**✅ 完整描写**：
九点整的会议，还有三十分钟，PPT 没做完。他啪地把窗口切过来，发现刚才那个数据算错了，再算一遍，更不对。他抬手抓了一下头发，脑子里已经过了三种补救方案——第一种要重做，第二种要拖人，第三种，他还没想好。同事路过，他张口就问："那个图你那儿有没有？"同事说"等下"，他"等下等下"，又改口："快一点。"话说完他自己也觉得语气不对，但顾不上。他把那个错数据先截个图存档，免得待会儿更乱。喘口气，又算一遍，还是错的。他啪地把键盘一推，靠在椅背上看着天花板，那三分钟里他什么都没想，就那么喘着。

**✅ 短句速写**：还有三十分钟，PPT 没做完——他抬手抓了一下头发，脑子已经过了三种补救方案。

**✅ 侧面反应**：同事路过，他张口就问——同事说"等下"，他"等下等下"，又改口"快一点"。

### 12. 期待

**tag**：`#情绪` `#期待` `#正面` `#隐性`

**核心**：等待一件还没发生的好事——不是热切的，是带着一点不确定、一点小心的，像怕太高兴了就会出事。

**身体反应**：动作比平时细致 → 不时看时间/手机 → 嘴角无意识上扬 → 反复整理仪表/环境。

**思维特征**：脑子里把这件事在几个版本间反复预演 → 想"万一不顺利"→ 又被自己打断 → 决定"总之要往好处想"。

**❌ AI 味**：他满心期待，心潮澎湃。

**✅ 完整描写**：
他把会议室的椅子又往前挪了半寸，离桌子正了一点。他坐回去，又觉得不对，把水杯挪到自己右手边——他待会儿要递给对方一杯水，不能卡手。瞄了一眼钟，还差八分钟。他又把准备好的那份资料翻了一下，纸张边缘有点卷，他压平了，重新放好。第三遍了。他靠回椅背，让自己看上去松一点。窗外有人走过去，他下意识看了那人一眼——不是。手机亮了一下，他立刻去拿，是快递通知，他失望得很快，又把手机扣回去。他抬手理了理头发，把衬衫领口整了整。门外的脚步声越来越近，他坐直了一点，让自己笑得不那么用力。

**✅ 短句速写**：他把椅子往前挪了半寸，又整了整衬衫领口——门外的脚步声越来越近，他坐直了一点。

**✅ 侧面反应**：手机亮了一下，他立刻去拿；是快递通知，他失望得很快，又把手机扣回去。

| AI 味 | 问题 | 替代思路 |
|------|------|---------|
| 报情绪名 | 「他很震惊」 | 写一个具体身体反应（咖啡端了一半放下） |
| 模板反应 | 「心如刀绞/瞳孔骤缩」 | 拆身体反应 3-4 个具体部分 |

| 替读者感 | 「他心里既震惊又愤怒」 | 写身体反应让读者自己读 |
| 静态描述 | 情绪只停在一个画面 | 写过程：三秒后他回神，五秒后他手开始抖 |
| 情绪堆砌 | 一章里 5-6 个重头情绪 | 一章最多 2-3 个重头情绪 |
| 直接写心理 | 「他在想她怎么还不回来」 | 写动作：看了五次手机，每看一次手指敲一下桌 |
