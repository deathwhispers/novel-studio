## 核心原则（美女描写专项去味）

### 八大 AI 味陷阱

| 陷阱 | 表现 | 例子 |
|------|------|------|
| 全景扫描式 | 眼睛→鼻子→嘴→身材机械罗列 | 「她有一双大眼睛，高鼻梁，樱桃小嘴，身材纤细」 |
| 成语堆砌 | 用成语代替画面 | 「倾国倾城、闭月羞花、沉鱼落雁」 |
| 陈旧意象 | 用烂了几千遍的比喻 | 「肌肤胜雪、眉目如画、杨柳细腰」 |
| 模板句式 | 万能句式套所有人 | 「她穿着一身 X 色连衣裙」「她微微一笑」 |
| 机械修辞 | 强行「X 而不失 Y」 | 「冷艳而不失温柔」「清纯中带着妩媚」 |
| 模糊偷懒 | 用模糊词逃避精确 | 「一种说不出的美」「美得让人窒息」 |
| 目光/眼神滥用 | 只会写「目光落在她身上」 | 「他的目光落在她身上，久久不愿移开」 |
| 无旁观者反应 | 只写「她美」，不写「别人怎么反应」 | 「她走进来，所有人都被她的美貌震惊了」 |

### 五条去味方法

1. **写「他注意到什么」，不写「她长什么样」** —— 从主角视角出发，写偏见、写反应，不写客观档案。
2. **写一个记忆点，不写十句堆砌** —— 一个有故事的特征，胜过十句漂亮但空洞的形容词。
3. **用动作神态写气质** —— 写她怎么坐、怎么笑、怎么说话，让气质自己浮出来。
4. **写反应链** —— 主角看到她 → 身体反应 → 心理 → 行为，一层层推进。
5. **感官轮换** —— 别只用视觉。她经过时带起的风、她的声音、她身上的味道，都比「漂亮」更有画面。

## 一、身份关系维度

### 1. 女主（官配）

**tag**：`#女主` `#核心女角` `#都市`

**核心**：故事的锚点，不需要最漂亮，但要有「就是她了」的唯一性。

**❌ AI 味**：她长得很美，是那种让人一眼就忘不掉的类型。

**✅ 完整描写**：
她不是那种第一眼就能在人群里被挑出来的长相。五官挑不出毛病，也挑不出惊艳，属于那种越看越耐看的类型。真正让他记住她的，是她笑起来的那个瞬间——眼睛先弯，然后嘴角才慢慢扬上去，像是一池水被风吹开。那天她穿一件洗得发白的蓝裙子，袖口磨出了毛边，可她抬手把头发别到耳后的时候，腕上那根红绳露出来，衬得手腕很细。他没由来地想起小时候老家屋檐下挂着的那串风铃，也是这样，安安静静的，风一过就响一下。

### 2. 白月光

**tag**：`#白月光` `#校园` `#都市` `#回忆`

**❌ AI 味**：她穿着一身白裙，气质清冷，像不食人间烟火的仙子。

**✅ 完整描写**：

## 二、气质类型维度

### 1. 御姐
