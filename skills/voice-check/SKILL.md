# 角色声音一致性

## 能力范围

- 检查角色声音是否前后一致
- 检测声音漂移（角色突然用不同方式表达）
- 维护 voice 样本的更新

## Voice 的构成

一个角色的「声音」不只是口头禅，包括：

| 维度 | 说明 | 例子 |
|------|------|------|
| 注意力偏好 | 角色习惯注意什么 | 军武者注意威胁和武器；商贩注意价格和机会 |
| 句法习惯 | 句子长短、结构、节奏 | 短句 vs 长句；先说结论 vs 先铺垫 |
| 回避方式 | 不想回答时怎么做 | 沉默/转移话题/说谎/反问 |
| 情绪表达 | 怎么表现愤怒/恐惧/喜悦 | 外在行为 vs 内心活动 vs 压抑 |
| 用词偏好 | 哪类词汇高频出现 | 身体词/颜色词/数字/抽象词 |
| 幽默方式 | 怎么搞笑 | 冷嘲/自黑/吐槽/烂梗/不搞笑 |

## 多人 Voice 区分 5 维度（W-NEW-VOICE-5D 修复）

**问题**：Writer 不知道怎么造出 N 个不同声音——只知道「不同角色要不同」但不知道「按哪 5 个维度设计差异」。

**5 维度清单**——Writer 在写每个角色的 voice 样本时，按这 5 维度差异化设计：

| 维度 | 定义 | 设计差异化的方法 |
|------|------|----------------|
| **句长偏好** | 角色说话平均用多长的句子 | 老兵 5-10 字 / 学者 25-40 字 / 商人 15-20 字 / 少年 5-15 字 |
| **口头禅** | 角色习惯挂嘴边的词或句式 | 每个角色 1-2 个口头禅；不要每个角色都有（否则同质化） |
| **用词阶层** | 角色用哪类词汇 | 文人用抽象词/成语；武人用身体词；商人用价格/数字；少年用俚语 |
| **句法完整度** | 角色说话是否说完/留半截 | 急躁者不说完 / 沉稳者说完整 / 暧昧者绕弯子 |
| **打断频率** | 角色是否会打断别人说话 | 急躁角色高频打断 / 沉稳角色不打断 / 反派故意不让人说完 |

**Writer 用法**：
- 写新角色前，在 `setting/characters/<角色>.yaml` 的 voice 段填这 5 维度的具体选择
- 写多角色对话 beat 时，每个角色开口前在脑子里过一遍这 5 维度——句长/口头禅/阶层/完整度/打断频率是否匹配该角色
- 2 个角色声音趋同时，立即用这 5 维度找到差异点（最常见的是句长趋同 → 拉大差距）

**5 维度差异化速查**（Writer 写完一段多角色对话后自检）：
- [ ] 主角和老二的句长差 ≥ 5 字/句？
- [ ] 每个角色有且仅有 1-2 个口头禅（不是每人都有，也不是零口头禅）？
- [ ] 不同角色的用词阶层有明显区分（文人 vs 武人 vs 商人）？
- [ ] 至少 1 个角色说话不完整 / 至少 1 个角色说话完整（避免全员都"说完"）？
- [ ] 至少 1 个角色会打断 / 至少 1 个角色不打断（避免全员都"让对方说完"）？

## 检测方法

### 步骤 1：提取本章中每个主要角色的所有对话

### 步骤 2：逐角色检查

对照该角色的 `voice 样本` 检查：

- [ ] 句子长度和结构是否一致？
- [ ] 用词偏好是否连贯？
- [ ] 情绪表达方式是否匹配？
- [ ] 回避方式是否一致？
- [ ] 是否有「突然变得很会说话/很不会说话」的段落？

### 步骤 3：声音漂移检测

| 漂移类型 | 表现 | 可能原因 |
|---------|------|---------|
| 突然变书面 | 口语角色开始用「然而」「因此」 | AI 的默认写作风格侵入 |
| 突然变啰嗦 | 简短角色开始解释自己的行为 | Writer 在借角色之口解释 |
| 突然变文艺 | 粗糙角色开始用比喻和抒情 | AI 味的「文学感」侵入 |
| 突然同质化 | 两个角色说话方式趋同 | Writer 忘记区分角色声音 |

## 输出格式

```yaml
voice_report:
  passed: true/false
  issues:
    - character: "主角"
      drift_type: "突然变啰嗦"
      location: "场景2对话"
      description: "主角从之前的简短直接（≤10字/句）变成解释自己的计划（30+字/句）"
      fix: "删掉解释部分——主角不需要向对方解释为什么选这个方案，只需要说'听我的'"
```

## Voice 样本管理

每个 POV 角色在 `snippets/` 或 `setting/characters/` 中应有至少一段 voice 样本：

```
Voice 样本格式：
- 角色：主角
- 样本来源：第3章对话
- 特征：短句（5-15字），先行动后解释（如果有解释的话），质问时用问句但不期待回答
- 样本片段：
  「你来晚了。」
  「跟你没关系。」
  他没回答。他看着窗外，直到她走。
```

Writer 在写前加载 voice 样本。State Manager 每 10 章检查是否需要更新样本（声音可能随人物成长自然演变）。
