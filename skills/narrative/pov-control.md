# 视角控制

## 能力范围

- 选择和管理 POV 视角
- 控制叙述距离（近/中/远）
- 维护信息边界（角色知道什么 VS 叙述透露什么）

## POV 类型

| 类型 | 读者能看到 | 适合 |
|------|-----------|------|
| 第一人称 | 叙述者的感知+内心 | 强代入感、声音驱动、悬疑 |
| 第三人称近 | POV角色的感知+内心 | 网文主流选择 |
| 第三人称中 | POV角色的行为，内心偶尔可见 | 动作驱动 |
| 第三人称远 | 只有可观察的行为和对话 | 多角色群像 |
| 全知（慎用） | 所有角色的感知和内心 | 大概率产生上帝视角问题 |

**网文建议**：默认第三人称近。每章 1 个 POV，章内不切换。

## 叙述距离

同一场景可以用不同距离写：

**近距**（角色内心可见）：
> 手心全是汗。他盯着那扇门，不敢眨眼。如果门开了，一切都完了。

**中距**（行为可见，内心不可见）：
> 他盯着那扇门，一动不动。

**远距**（概括叙述）：
> 那天下午他等了很久。

**切换原则**：
- 高潮/紧张 → 近距
- 过渡/时间推移 → 远距
- 对话/动作 → 中距
- 不要在同一个场景内频繁切换距离（会让读者头晕）

## 信息边界

**POV 角色能感知什么？**

- 能看到/听到/闻到/触摸到的
- 能回忆起的（但回忆必须由当前感知触发）
- 能推断的（但必须是该角色知识范围内的推断）

**POV 角色不能感知什么？**

- 别人的内心（「他不知道她在想什么」是允许的，「她在想XX」不是）
- 角色看不到的角落发生的事
- 超过角色认知范围的信息

上帝视角的检测与句式清单见 `skills/analysis/info-leak-check.md`（Critic 检测用）。本 skill 只负责写作时的 POV 边界控制。

## 多 POV 管理

如果作品需要多 POV：
- 一章一个 POV，不混用
- POV 切换要有明确标记（章节开头或分隔符）
- 不同 POV 角色有不同认知 → Writer 必须分别维护每个 POV 的 `knowledge` 边界
- 读者可以通过不同 POV 拼出全貌，但每个 POV 角色只能看到自己的拼图
