# 文风校准

## 能力范围

- 锁定叙述者声音（写前）
- 检测文风漂移（写后）
- 确保句子质感与写作模式匹配

## 写前锁定（Writer 调用）

在开始起草前，明确以下文风参数：

```yaml
voice_lock:
  narrator_type: "角色近距"     # 角色近距 | 旁观叙述 | 全知
  sentence_style:
    avg_length: "中短"          # 短(10-15字) | 中短(15-25) | 中(25-35) | 长(35+)
    variation: "高"             # 长短句交替频率
  paragraph_density: "中"       # 段落信息密度（高=每段推动剧情，低=允许呼吸段落）
  tone: "冷峻+偶尔幽默"         # 叙述语气标签
  humor_source: "角色吐槽"      # 幽默来源（角色吐槽/叙述者评论/情境荒诞/无）
  sensory_preference: "触觉+听觉" # 习惯用哪种感官（默认视觉会导致 AI 味）
```

## 写后验证（Critic 调用）

### 检查项

- [ ] 随机取 3 段正文与 voice_lock 对比：句长是否在设定范围内？
- [ ] 幽默是否来自设定的来源而非 AI 通用段子？
- [ ] 是否有文风漂移——前 500 字和后 500 字像两个人在写？
- [ ] 叙述者是否有「忽然变得很文艺」或「忽然变得很粗俗」的段落？

### 文风漂移常见表现

| 漂移类型 | 表现 | 修复 |
|---------|------|------|
| 严肃→搞笑 | 前文冷峻，突然一段吐槽 | 确认是否角色在吐槽——如果是叙述者在吐槽就是漂移 |
| 简洁→繁复 | 前文短句，突然一段长句环境描写 | 检查是否到了需要慢下来的场景——如果不是就精简 |
| 口语→书面 | 对话突然变成书面语 | 重置为角色声音 |
| 经济→冗余 | 开始用两个词形容一个动作 | 逐句精简 |

## 品类适配

不同品类有不同文风基线：

| 品类 | 默认句长 | 段落密度 | 幽默 |
|------|---------|---------|------|
| 番茄系统爽文 | 中短(15-25) | 高 | 角色吐槽+系统吐槽 |
| 玄幻 | 中(25-35) | 中 | 偶尔 |
| 都市 | 中短(15-25) | 高 | 叙述者幽默 |
| 言情 | 中(25-35) | 中 | 角色互动 |
| 悬疑 | 中短(15-25) | 高 | 无/暗黑幽默 |
