# 场景渲染

## 能力范围

- 用感官细节（视觉/听觉/触觉/嗅觉/味觉）让读者身临其境
- 用环境压力影响角色行为
- 通过场景变化反映叙事节奏

## 感官描写原则

**一次只选 1-2 个感官**，不要五感全开：

- 紧张场景 → 听觉（心跳、呼吸、远处的脚步声）
- 陌生环境 → 嗅觉（气味比视觉更快传递「不对劲」）
- 身体状态 → 触觉（冷/热/痛/麻/湿）
- 不要习惯性写视觉——「他看到了XX」是偷懒

**先人后景**：
- 不是「房间里有一张桌子和两把椅子」
- 而是「他进门先看到桌上那杯没喝完的茶——人刚走」
- 环境描写通过角色的感知过滤，不是客观清单

### 改写示范

**白房间 → 有特征的空间**：

```
❌ 他走进房间。房间不大，有一张床、一张桌子、一个衣柜。窗户关着。

✅ 他走进房间。脚下的地板吱呀响了一声——第二块木板是松的。床上的被子没叠，一角拖在地上。窗户关着，但窗帘在动，有风从缝里漏进来。
```

**客观清单 → 角色感知（先人后景）**：

```
❌ 房间里有三个人。靠窗的位置坐着一个男人，桌上放着两杯茶。

✅ 他先看到的是靠窗那个男人。桌上两杯茶，一杯还冒着热气——人刚坐下不久。
```

**五感全开 → 只选关键感官**：

```
❌ 他走进废弃仓库。空气中弥漫着铁锈和机油的气味，耳边是远处机器的轰鸣，脚下的地面有些潮湿，头顶的灯泡发出昏暗的光，嘴里有股灰尘味。

✅ 他走进废弃仓库。铁锈味冲进鼻子。头顶的灯泡在闪，脚下的水洼映着一晃一晃的光。
```

## 环境压力

环境不是背景板，是施加在角色身上的力：

| 压力类型 | 例子 |
|---------|------|
| 时间压力 | 天快黑了、系统倒计时、对方在等回复 |
| 空间压力 | 房间太小/太大、人群密集、无处可藏 |
| 规则压力 | 不能使用能力、不能暴露身份、必须在规则内获胜 |
| 身体压力 | 伤势恶化、饥饿、寒冷、中毒 |
| 社会压力 | 周围有人看着、身份被质疑、等级压制 |

每个场景至少有一种环境压力。没有压力就没有紧迫感。

## 场景变化反映节奏

- 快节奏：场景切换频繁，每场景只写关键信息，过渡省略
- 慢节奏：场景稳定，允许呼吸段落，细节展开
- 高潮场景：空间收敛到最小焦点（两个人对峙，读者只看到他们的眼神和手）
- 余震场景：空间重新打开（角色走出房间，看到天空，听到远处的声音）

## 常见问题

| 问题 | 修复 |
|------|------|
| 白房间综合症（角色在无特征空间行动） | 给一个具体细节——发霉的墙角、闪烁的灯管、一张旧照片 |
| 场景切换无过渡 | 用一个感知连接两端（声音/光线/温度的变化） |
| 同质化场景 | 给不同场景不同的感官标签（A场景=冷+B场景=嘈杂，C场景=消毒水味） |
