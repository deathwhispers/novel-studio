# 人物一致性检查

## 能力范围

- 检查角色行为是否可从其设定（欲望/恐惧/创伤/限制）追溯
- 检查角色是否有「突然变成另一个人」的时刻
- 检查配角是否只有功能性（工具人检测）

## 检测方法

### 步骤 1：行为可追溯检查

对本章中每个重要角色的每个选择：
- [ ] 这个选择可以从角色的 `want`/`fear`/`wound` 中理解吗？
- [ ] 角色的行为是否符合其 `constraints`（能力限制/信息限制/性格限制）？
- [ ] 如果有「出格」行为，是否有足够的铺垫？

### 步骤 2：角色一致性检查

- [ ] 一直谨慎的角色是否突然冒险？→ 有铺垫吗？
- [ ] 一直沉默的角色是否突然大段说话？→ 有触发吗？
- [ ] 角色对话的句子长度、用词、语气是否与前文一致？
- [ ] 角色的情绪反应是否符合该角色的表达方式？

### 步骤 3：工具人检测

检查每个配角的出场：

| 工具人表现 | 检测问题 |
|-----------|---------|
| 只为传递信息出场 | 信息是否可以用其他方式传达？ |
| 只为被打脸出场 | 打脸对象是否每个都是「刚出现的路人」？ |
| 只为救主角出场 | 救援是否有该角色的个人动机？ |
| 出场即消失 | 这个角色之后还会出现吗？如果不会，为什么需要是个「角色」而不是事件？ |

### 步骤 4：对话区分度检查

- 摘出本章所有对话，去掉「XX说」标签
- 能否仅凭内容分辨谁在说话？
- 如果不能 → 角色的对话方式区分度不够

## 输出格式

```yaml
character_report:
  passed: true/false
  issues:
    - severity: "软问题"
      character: "主角"
      location: "场景1"
      description: "一直谨慎的主角在没确认安全的情况下暴露了能力"
      root_cause: "缺少动机铺垫——读者不知道为什么这次他选择冒险"
      fix: "补充内心衡量（如系统时限只剩30秒），或改为被动暴露"
    - severity: "工具人"
      character: "路人甲"
      location: "场景3"
      description: "出现的目的只是为了被打脸，没有独立动机"
      fix: "换成已有配角，或者给这个路人一个具体的身份和立场"
```

## 边界判断

以下**不是**人物问题：

| 表现 | 为什么可以 |
|------|-----------|
| 角色做出冲动选择 | 压力下人是会冲动的——前提是铺垫了压力 |
| 角色说了违心的话 | 对话和内心矛盾是人物深度的表现 |
| 配角信息不全 | 非 POV 角色不需要完整心理描写 |
