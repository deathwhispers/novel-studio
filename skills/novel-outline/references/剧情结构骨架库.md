## 九种骨架

### 骨架 1：三幕式（经典通用）

- 结构：第一幕 25% 设定+触发事件；第二幕 50% 对抗+中点反转；第三幕 25% 高潮+不可逆解决。
- 检查：第一幕结束主角无法回头；第二幕中点有真相揭露或重大损失；第三幕高潮有终极代价；结局有不可逆变化。
- 适用：大多数网文，尤其玄幻、仙侠、都市升级文。

### 骨架 2：英雄之旅（Campbell 模型简化）

- 结构：平凡世界 → 冒险召唤 → 拒绝召唤 → 遇见导师 → 跨越门槛 → 试炼/盟友/敌人 → 深入洞穴 → 磨难 → 奖赏 → 归途 → 复活 → 携宝归乡。
- 网文适配：平凡世界=初始状态；召唤=触发事件；导师=功法/指引；门槛=离开安全区；磨难=重大失败；奖赏=关键能力；复活=重生/突破；归乡=新世界/新地位。
- 适用：玄幻、仙侠、奇幻、冒险类。

### 骨架 3：身份揭秘型

- 结构：表层身份 → 多次铺垫 → 逐层揭秘，常见三层：能力/身份（30-50 章）→ 更深使命（50-150 章）→ 全书最大反转（150-400 章）。
- 关键设计：铺垫密度随层级增加；第一层被事件逼出，第二层被敌人揭露，第三层由主角主动揭示或终极对决引出。
- 适用：凡人流、废材流、马甲流、赘婿流。

### 骨架 4：多线并进型

- 结构：主线 A 成长、B 感情、C 势力/世界、D 悬疑各自推进，在关键节点交汇形成复合高潮。
- 线间关系：互补（A 线突破推动 B 线）、冲突（力量追求牺牲感情）、并行（独立推进）、隐藏（暗线最后揭晓）。
- 适用：群像、权谋、复杂世界观文。

### 骨架 5：悬疑揭秘型

- 结构：核心谜团 → 每章 1-2 条线索 → 推理推进 → 中点反转推翻旧结论 → 更深谜团 → 终极揭秘+代价。
- 线索管理：真线索约 60%，假线索约 30%，红鲱鱼约 10%。
- 适用：悬疑、推理、惊悚、谍战。

### 骨架 6：关系递进型

- 结构：陌生人 → 初识 → 朋友 → 暧昧 → 表白 → 恋人 → 考验 → 归宿。
- 关键设计：每阶段必须有关系变化和阻力；不能“立刻好感、立刻信任、立刻表白、一帆风顺、轻易通过考验”。
- 适用：言情、耽美、感情流。

### 骨架 7：先知改命型

- 结构：获得先知信息 → 改变小事积累优势 → 蝴蝶效应引发意外 → 先知失效 → 无先知应对 → 超越先知。
- 关键设计：先知优势制造“我知道未来”的爽感，蝴蝶效应制造失控紧张，先知失效制造危机，超越先知制造成长满足。
- 适用：重生、穿越、系统文。

### 骨架 8：螺旋上升型

- 结构：发现问题 → 尝试解决 → 失败/代价 → 总结经验；循环规模逐级扩大，终极循环用全部经验支付终极代价。
- 循环升级：问题从个人到团队到势力到世界；解决方式从个人能力到协作到博弈到规则改变；代价随之不可逆。
- 适用：种田、基建、经营、末日求生。

### 骨架 9：复仇螺旋型

- 结构：仇恨起源 → 隐忍积蓄 → 第一次报复 → 发现更大阴谋 → 第二次报复 → 代价支付 → 复仇/放下 → 终局。
- 关键设计：隐忍有成长；首报有爽点但不一次解决；真相背后有更大阴谋；代价不可逆；终局主角与起点不同。
- 适用：复仇、黑暗流、虐主流。

## 骨架自检

- [ ] 骨架匹配故事核心，不是硬套。
- [ ] 每个阶段都有不可逆事件，不是“差点发生”。
- [ ] 主角状态每阶段都有具体变化，不是“变强了”这种空话。
- [ ] 升级、转折、复仇都有代价。
- [ ] 结局与起点形成反差。
- [ ] 允许局部偏离主线；偏离时记录到 `90-运行/决策记录.md`。

## 混合骨架方法

- 主骨架决定全书节奏和关键节点，副骨架决定局部结构或角色弧线。
- 最多混合 2 种骨架；副骨架节点必须与主骨架关键节点对齐。

| 组合 | 主骨架 | 副骨架 | 效果 |
|---|---|---|---|
| 升级+复仇 | 英雄之旅 | 复仇螺旋 | 主角变强的同时逐步复仇 |
| 揭秘+感情 | 身份揭秘 | 关系递进 | 真相揭露影响关系变化 |
| 悬疑+升级 | 悬疑揭秘 | 英雄之旅 | 破案过程中主角变强 |
| 种田+揭秘 | 螺旋上升 | 身份揭秘 | 发展势力同时揭开身世 |

对齐示例：英雄之旅的“冒险召唤”对应复仇的“仇恨起源”，“深渊/磨难”对应“第一次报复”，“终极考验”对应“代价支付”，“归来”对应“终局”。

## 类型适配

### 玄幻/仙侠

| 骨架 | 适配要点 |
|---|---|
| 英雄之旅 | 冒险召唤换成觉醒灵根，门槛=境界突破 |
| 螺旋上升 | 种田换成修炼，每次循环=一个小境界 |
| 复仇螺旋 | 隐忍积蓄换成闭关修炼，报复=击杀仇人手下 |

### 都市/职场

| 骨架 | 适配要点 |
|---|---|
| 三幕式 | 触发事件换成项目危机，高潮=交付或商业对决 |
| 身份揭秘 | 身份换成职场秘密，揭秘=发现公司阴谋 |
| 螺旋上升 | 种田换成业务拓展，每次循环=一个项目周期 |

### 悬疑/推理

| 骨架 | 适配要点 |
|---|---|
| 悬疑揭秘 | 保持原样，假真相=误导线索 |
| 身份揭秘 | 身世换成凶手身份，假身份=嫌疑人 |
| 先知改命 | 先知换成推理预判，改命=阻止犯罪 |

### 言情/感情

| 骨架 | 适配要点 |
|---|---|
| 关系递进 | 保持原样，表白=第一次确定关系 |
| 英雄之旅 | 冒险换成追求，门槛=误会/阻碍 |
| 身份揭秘 | 身世换成前任/秘密，揭秘=发现对方隐瞒的事 |

## 骨架快速检查

1. 用一句话说出故事最核心的是什么（升级/揭秘/感情/复仇/悬疑）。
2. 主角起点和终点的最大反差是什么。
3. 全书每个阶段至少有几个不可逆事件。

3 题都能清晰回答，骨架健康；说不清则回到 `./大纲阶梯.md` 补结构。
