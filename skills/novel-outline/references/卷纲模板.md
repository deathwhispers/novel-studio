## 卷信息头

```markdown
# 第 {{X}} 卷：{{卷名}}

- 卷号：第 X 卷（全书共 {{N}} 卷）
- 卷名：{{简明卷名，2-6 字}}
- 功能定位：{{起势 / 发展 / 转折 / 深化 / 收束}}
- 核心卖点：{{爽点 / 虐点 / 悬念 / 感情线}}（选 1-2 个）
```

## 卷级定位

1. 用 1-2 句话说清这卷在全书中独一无二的功能，句式：`这卷是 {{阶段}} 的 {{功能}}，负责 {{建立/升级/转折/深化/收束}} {{什么}}，为 {{下一卷}} 的 {{什么}} 做铺垫。`
2. 聚焦 1-2 种读者主感受：爽、虐、悬、甜、燃或自定义；不写“多种感受”。

## 开卷设计

开卷承诺：Ch1 结束后，读者知道主角当前状态、本卷核心悬念、追下去能看到什么。

开卷钩子选 1 种：新问题、不可逆决定、倒计时、权力反转、情绪余震、关系破口。

## 中段升级路径

每卷至少 2 个维度有变化，不能只有能力升级：

| 维度 | 卷初 | 卷末 | 升级方式 | 代价 |
|---|---|---|---|---|
| 能力 | | | | |
| 地位 | | | | |
| 心理 | | | | |
| 关系 | | | | |

节奏型选 1 种（详见 `卷级节奏型模板.md`）：

- 标准型：起 → 承 → 小高潮 → 承 → 大高潮 → 收束
- 加速型：起 → 承 → 高潮 → 更高潮 → 终极大高潮
- 波浪型：起 → 小高潮 → 回落 → 中高潮 → 回落 → 大高潮
- 慢热型：长铺垫 → 一次大爆发 → 余震

再按章节范围标出节奏强度（1=极慢，3=正常，5=极快）。

## 核心转折

用 1 句话写清最不可逆的事件：

```text
在 {{Ch X}}，{{发生了什么}}，导致 {{主角/世界/关系}} 发生 {{不可逆变化}}，
这个变化让 {{下一卷核心矛盾}} 成为必然。
```

铺垫要散，不要集中在 1-2 章；记录铺垫章节、内容和形式。

## 卷末设计

卷末钩子必须和开卷钩子不同，选 1 种：新问题、不可逆决定、倒计时、权力反转、情绪余震、关系破口。最后 1-2 段写“读者读完会想什么”。

与下一卷衔接：主角状态、未解决问题、下一卷必须接住什么；下一卷开卷的第一件事和读者最关心的问题。

## 字数预算

- 计划章节数：{{X}}，浮动 ±{{N}}
- 最短章：800-1500 字；最长章：3000-5000 字
- 计划字数：{{X}} 万字；每章平均：{{X}} 字
- 按铺垫/推进/高潮/收束分配字数占比

## 自检清单

- [ ] 功能定位一句话说清
- [ ] 核心卖点不超过 2 种
- [ ] 开卷承诺具体
- [ ] 卷末钩子强，不是平静收束
- [ ] 核心转折不可逆
- [ ] 铺垫分布散
- [ ] 升级有代价
- [ ] 字数预算合理
- [ ] 跨卷衔接顺
- [ ] 角色弧线有变化

10 项中若有 3 项说不清，回到对应阶梯重审。

## 填写示例

第 3 卷《血火试炼》：功能定位是“发展期的能力质变+信任危机”，核心卖点是爽+悬。主角从新人升级为能独当一面的战士，同时因导师隐瞒真相而失去信任。卷末主角在任务现场发现“已死”的亲人还活着，但被组织控制。字数 8 万、35 章、波浪型节奏。

## 常见错误

| 错误 | 修复 |
|---|---|
| 功能定位太泛 | 用“负责……为……做铺垫”句式 |
| 卖点太多 | 聚焦 1-2 种 |
| 开卷承诺模糊 | 具体写读者会期待什么 |
| 升级无代价 | 加生命/信任/自由/道德代价 |
| 高潮可逆 | 写成“已经知道，无法回头” |
| 卷末钩子弱 | 用 `追读钩子设计.md` 检查强度 |
| 角色无弧线 | 配角也要有欲望和变化 |
| 伏笔无计划 | 写清计划回收卷和方式 |
| 字数不现实 | 按字数反推再分配节奏 |
| 跨卷断连 | 下卷首 3 章内回应本卷末 |

## 快速检查

1. 这卷在全书中独一无二的功能是什么？
2. 读者读完最强烈的感受是什么？
3. 卷末什么事让读者必须看下一卷？
4. 主角这卷失去了什么/得到了什么？
5. 如果跳过这卷，全书哪里会断掉？

能答 5 题：卷纲健康；3-4 题：补强对应部分；少于 3 题：回“大纲阶梯”重审。
