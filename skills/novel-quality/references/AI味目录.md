# AI 味目录

“AI 味”不是禁用词表，而是语言选择与人物、场景和叙事目的脱节。先用本文定位风险，再用 `去味手法.md` 判断是否修改。

## 常见模式与示例

### 解释腔

AI 倾向把角色的行为和动机解释得太清楚。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他握紧拳头，心中充满了愤怒，因为他意识到自己被背叛了。 | 他握紧拳头，指节发白。 |
| 她感到一阵恐惧，她知道接下来会发生什么可怕的事情。 | 她的脸色刷地白了。 |
| 他明白这是唯一的办法，只能硬着头皮上了。 | 他深吸一口气，推开了门。 |

### 均匀感

AI 倾向让段落长度、节奏和信息密度均匀分布。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 这是一个普通的早晨。阳光透过窗户洒进来。他起床洗漱，然后吃了早餐。 | 阳光刺眼。他翻了个身，把被子蒙在头上。 |
| 他们相视一笑，然后转身离开了房间。走廊里很安静，只有脚步声回荡。 | 她笑了笑。他没笑。 |

### 模板化句式

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他深吸一口气，缓缓说道…… | 「好，我去。」 |
| 她抬起头，眼中闪过一丝复杂的情绪。 | 她看着他，没说话。 |
| 空气中弥漫着一种诡异的寂静。 | 安静得不正常。 |
| 不是害怕，不是后悔，而是一种说不清的悸动。 | 他心跳很快。不知道为什么。 |
| 没有表情。没有「哦」。没有「管得真宽」。就是一句陈述。 | 他听完，把烟掐了。 |

### 过度总结

AI 倾向在叙事中插入评论式总结句。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 这就是命运的安排，谁也无法改变。 | 他没再说什么。 |
| 也许这就是成长的代价吧。 | 她揉了揉眼睛，继续往前走。 |

### 角色同声腔

AI 倾向让所有角色用相似的方式说话。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 「我认为这样做可能不太妥当。」 | 「不行。」 |
| 「我对此感到非常抱歉。」 | 「怪我。」 |
| 「根据我的分析，情况不容乐观。」 | 「完了。」 |

### 安全表达

AI 倾向避免强烈、有风险的表达。

| 原文（AI 味） | 改后（去味） |
|---|---|
| 他似乎对她有些好感。 | 他喜欢她。 |
| 这件事可能带来一些不好的影响。 | 这事要命。 |
| 他感到一种难以言说的情绪。 | 他笑不出来。 |

## 句式风险索引

| AI 腔 | 自然替代 |
|---|---|
| 由于……所以…… | 直接写原因或结果，不用连词 |
| 他/她感到/觉得/认为 | 删掉，换成动作或对话 |
| 随着…… | 拆成两句，不要用「随着」开头 |
| 不禁/不由地/忍不住 | 换成具体动作 |
| 说明/意味着/代表 | 留给读者判断，不要说穿 |
| 在……的带领下/帮助下 | 换成具体互动 |
| 只见/就看到 | 删掉，直接写画面 |
| 不是……不是……而是…… | 删掉否定铺垫，直接写「而是」后面的东西；如果不是真的需要澄清误解，不要用这个结构 |
| 没有……没有……就是…… | 否定清单不创造画面——写有什么，不写没有什么 |

## 结构风险索引

| AI 腔 | 自然替代 |
|---|---|
| 每个段落 3-5 句均衡 | 长短段交替，关键段落可只有一句 |
| 先景后人 | 先人后景，或人和景同时出现 |
| 对话后紧跟解释 | 删掉解释，信任读者能看懂 |
| 叙事后紧跟心理 | 把心理化成行动或对话潜台词 |
| 每章开头重述前文 | 直接推进，不要回顾 |

## 词汇风险索引

| AI 腔 | 自然替代 |
|---|---|
| 点了点头 | 点了下头 / 没说话 |
| 与此同时 | 删掉，或者用「这时」 |
| 然而/但是 | 一半的情况可以删掉，用短句转折 |
| 众所周知 | 不要用，直接写世界普遍认知 |
| 毫无疑问 | 删掉，用事实说话 |
| 某种/某种程度 | 换成具体描述或直接删 |

## 常见 AI 味组合

| 组合 | 表现 | 修复 |
|---|---|---|
| 解释 + 概括 | “他感到愤怒，因为对方背叛了他” | 删掉“感到”和“因为”，写动作 |
| 过渡 + 过渡 | “随着天色渐暗，与此同时……” | 拆成两句，删掉过渡词 |
| 安全 + 安全 | “某种程度上的某种变化” | 改成精确描述 |
| 均匀 + 均匀 | 连续 5 句都是“他做了什么，然后做了什么” | 长短交替，加中断 |
| 先景 + 解释 | “夕阳很美。这说明一天结束了。” | 删解释，让夕阳自己说话 |

## AI 味检测流程

1. **扫描标记**：搜索“感到/觉得/认为/意识到”“由于/随着/与此同时”“不禁/不由/忍不住”“可能/大概/似乎/某种”。
2. **分类处理**：解释腔和概括情绪优先删除；过渡词按 P1 处理；安全表达和均匀句式按 P2 处理，不机械替换。
3. **通读验证**：读改后的段落，确认仍像这个人物、这个叙述者、这本书；删了反而不通就回退。

## 快速检查（1 分钟）

随机抽 3 段：

1. 有“感到/觉得”吗？→ 有则检查是否解释或概括。
2. 有连续 3 句同样开头吗？→ 有则改写节奏。
3. 有“由于/随着”吗？→ 有则考虑删掉。

任一题“有”→ 进入 AI 味检测流程，并用 `去味手法.md` 判断受损效果。
