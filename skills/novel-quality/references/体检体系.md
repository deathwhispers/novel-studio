# 体检体系

> 用途：按不同粒度（章节/卷/中期/完本）执行结构化体检。
> 用法：根据当前写作阶段选择对应小节。

---

## 一、章节体检


**定位**：`novel-quality` 在质量检测阶段对单章、单场或卷前章节做证据型体检。它覆盖前后衔接、埋线回收、人物状态、章尾发动机和追读风险，不只是写后轻量自检。若刚完成 `novel-writing` 起稿且只需要守住硬门禁，用 `../../novel-writing/references/写后自检卡.md`。

## 五点五、章间推进密度

> 百万级长篇最容易在卷中段出现"章间空转"——多章虽然都有事件但读者感觉"没在推进"。本节专门排查这个问题。

### 章间推进密度矩阵

> 行=章节，列=四个推进维度，每格打分（0=无，1=弱，2=中，3=强）。
> 满格 12 分，< 6 分提示"空转"。

| 章节 | 信息推进 | 关系推进 | 局面推进 | 角色成长 | 累计 |
|------|---------|---------|---------|---------|------|
| Ch X | | | | | |
| Ch X+1 | | | | | |
| Ch X+2 | | | | | |
| ... | | | | | |

> **填表说明**：
> - **信息推进**：本章是否揭示了新的关键信息
> - **关系推进**：本章是否有关系变化（不是"角色见面"，是"关系有进展或破裂"）
> - **局面推进**：本章是否改变了主角的处境（位置/状态/能力）
> - **角色成长**：本章是否让主角/重要角色发生了认知或行为变化

### 推进密度曲线

> 累计得分 < 6 的章提示需要补强。

```
累计
  12 ┤                                          ╭─
  10 ┤      ╭─╮                                │
   8 ┤    ╭─╯ ╰─╮    ╭─╮                      │
   6 ┤───╯       ╰──╯  ╰──╮             ╭─────╯
   4 ┤                       ╰──╮   ╭───╯
   2 ┤                           ╰───╯
   0 └────────────────────────────────────
       Ch   Ch+5  Ch+10  Ch+15  Ch+20
```

### 章间空转的常见形态

| 形态 | 表现 | 风险 |
|------|------|------|
| 场景堆叠 | 连续 3 章写同一场景的不同角度 | 高（读者会跳过） |
| 信息无承接 | 章尾抛新信息，下章不接 | 中（读者会觉得"作者忘了"） |
| 关系无变化 | 连续 5 章关系状态不变 | 中（读者会弃） |
| 角色无成长 | 主角连续 10 章无认知/能力变化 | 高（核心推进力丧失） |
| 事件堆积 | 章章都在"发生事"，但都不重要 | 高（看起来在写其实在空转） |

### 章间空转自检

- [ ] 是否有连续 3 章累计 < 6 分（提示空转）
- [ ] 是否有连续 5 章"角色成长"维度为 0（提示主角"工具化"）
- [ ] 是否有连续 5 章"关系推进"维度为 0（提示感情线停滞）

- [ ] 累计均分最低的 3 章是否能合并或删除
- [ ] 中段（30-70%）的密度曲线是否塌陷

## 三、中期审视


当连载超过 50 章 / 字数突破 15 万 / 连续 5 章以上感觉到写不顺时，建议做一次中期审视。

## 审视时机信号

- 最近 5 章是否有 3 章以上是靠平推写出来的：是 / 否
- 是否已经超过 10 章没有新的关系推进：是 / 否
- 是否已经超过 10 章没有新的局面翻面：是 / 否
- 是否最近写之前越来越不想翻看前文和节拍卡：是 / 否
- 追读是否出现连续下滑：是 / 否
- 如有任意两项为「是」，建议立即做一次完整中期审视

## 四、完本检查


适用于一卷结束或全书收尾时使用。按顺序执行，不要跳跃。

## 第一步：线头收束检查

### 主线检查
- [ ] 主线最终目标是否已经达成或明确失败
- [ ] 主角的成长弧线是否完整（起点→终点有可感知的变化）
- [ ] 全书最大的悬念是否已经解答
- [ ] 所有中期提出的核心问题是否已有答案

### 副线检查
- [ ] 每条打开的副线是否都有收束（不一定完美收束，但不能凭空消失）
- [ ] 所有重要配角的故事线是否都有交代
- [ ] 被长时间搁置的线索是否最少有一次提醒或解释

### 关系线检查
- [ ] 每段核心关系的最终状态是否清晰
- [ ] 读者最在意的那段关系是否有足够篇幅的收束
- [ ] 有没有冗余关系线没有处理

## 第二步：伏笔回收清单

- [ ] pull 出 `20-大纲/回收/回收总账.md` 逐条检查每一条线
- [ ] 标记每条线的最终状态：已回收 / 有提醒 / 故意留白
- [ ] 未回收的线头中，哪些是续集伏笔，哪些是纯粹遗漏

## 第三步：情绪收束

- [ ] 结局的情绪基调是否符合全书的整体气质
- [ ] 读者读完最后的情绪是否和开书时的承诺一致
- [ ] 最后几章是否有足够的余韵空间（不是信息堆叠）
- [ ] 是否给读者留下了"这本书值得回味"的结尾力量

## 第四步：硬伤排查

- [ ] 检查 10-设定/硬设定.md 与正文是否冲突
- [ ] 检查 20-大纲/因果/场景因果图.md 是否所有因果链都已闭合
- [ ] 检查角色名称、地点名称、能力名称在全书中是否一致
- [ ] 检查时间线是否存在矛盾

## 第五步：完本后操作

- [ ] 最后通读一遍，修正错别字和语病
- [ ] 完成的分卷正文保留在 `30-正文/`，不另设归档目录
- [ ] 在 `90-运行/决策记录.md` 记录完本信息
- [ ] 更新 `00-书核/作品总表.md` 的状态为「已完本」
- [ ] 如果存在续集计划，在 `00-书核/作品总表.md` 的“长线承诺”分区记录衔接思路

## 第六步：续集/新书规划（可选）

- [ ] 留下的续集钩子是否足够让人期待
- [ ] 续集需要的设定变化是否已经记录
- [ ] 新书的构思是否已经独立记录，不被完本情绪带偏
