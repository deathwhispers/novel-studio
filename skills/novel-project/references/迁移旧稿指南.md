# 迁移旧稿指南

> 用途：把已有完整或半完整旧稿整理进小说工作区。
> 原则：不安装工具、不执行脚本；用文件管理器、文本编辑器和 Markdown 手写整理。

## 一、迁移前评估

| 维度 | 健康 | 亚健康 | 不健康 |
|---|---|---|---|
| 章节连续 | 无跳跃 | 少量跳跃 | 大量跳跃 |
| 设定一致 | 基本一致 | 少量矛盾 | 大量矛盾 |
| 文件格式 | 统一 Markdown/文本 | 2-3 种格式 | 多种格式混杂 |
| 目录结构 | 有 | 部分有 | 无 |
| 大纲 | 有 | 有部分 | 无 |

决策：

- 3 项以上健康：直接按最小结构迁移。
- 3 项亚健康：迁移时补建设定、大纲和进度。
- 2 项以上不健康：先整理旧稿，再进入项目初始化或按需重构。

## 二、准备最小工作区

按 `./工作区规范.md` 只创建当前需要的目录和文件，不默认一次铺满。用户提供的段落参考放在 `35-参考片段/`，用法见 `../../novel-writing/references/段落参考使用卡.md`。

旧稿先保留在来源目录；每章确认无误后再移入 `30-正文/`，整理完成前不要和当前正文混在一起。

## 三、整理正文

1. 用文本编辑器把 Word、网页或 PDF 中的旧稿粘贴为 Markdown；不要求安装转换工具。
2. 统一标题层级：章标题用 `#`，节标题用 `##`。
3. 统一对话符号，全文只保留一种：`「」` 或引号。
4. 删除页眉、页脚、页码、Word 样式残留和多余空行。
5. 建立章节映射表，记录旧文件名、旧章节号、新章节号、新文件名和状态。
6. 通过文件管理器或编辑器重命名、移动章节；有卷概念的按卷分目录，无卷概念先放在 `30-正文/未分类/`。

## 四、提取设定

从旧稿和旧设定文档中提取：

| 内容 | 去向 |
|---|---|
| 角色起点、目标、关系 | `10-设定/角色/姓名.md` |
| 硬规则、力量体系、世界规则 | `10-设定/硬设定.md` 等 |
| 地点与势力 | `10-设定/地点/`、`10-设定/势力/` |
| 时间线 | `10-设定/时间线.md` |

只提取正文中真正影响后续选择的信息。次要角色可先合并为配角群像，不要为迁移而复制整套模板。

## 五、补建大纲与进度

1. 从第 1 章、关键转折章和最后一章提取主角起点、当前状态与核心冲突，写入 `00-书核/作品总表.md`。
2. 已有卷结构时按 `../../novel-outline/references/卷纲模板.md` 的格式逐卷补建；没有卷结构时先标记 `[待重构]`。
3. 对已写章节按 `../../novel-outline/references/节拍卡模板.md` 的写法，只补视角人物、核心戏剧任务、因果锚点、章尾钩子这些最小支点，不要求每项都填。
4. 更新 `90-运行/当前进度.md`，记录当前章节、未闭合因果、待确认设定和下一章任务。

## 六、迁移完成检查

- [ ] 每章标题和正文格式统一
- [ ] 旧稿不再和当前正文混在一起
- [ ] 关键 hard canon 已进入设定文件
- [ ] 用户认可的参考片段已放入 `35-参考片段/`
- [ ] 当前进度能回答"写到哪、接下来是什么"
- [ ] 明显断章、缺失章节和待重构位置已在进度中标注

迁移不要求一次完成全部资产。先让当前正文可续写、可检索，后续按写作需要逐步补建。
