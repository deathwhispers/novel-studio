# 核心冲突设计

> 用途：定义并追踪故事核心矛盾，确保所有剧情都是该冲突的展开。

## 冲突三要素

| 要素 | 问题 | 示例 |
|---|---|---|
| 对立双方 | 谁 vs 谁？ | 主角 vs 帝国 |
| 争夺对象 | 争什么？ | 自由、真相、王位 |
| 不可调和性 | 为什么不能双赢？ | 零和博弈、价值观对立 |

## 升级阶梯

| 阶段 | 主角行动 | 对手行动 | 结果 |
|---|---|---|---|
| 潜伏期 | 未察觉 | 暗中布局 | 平衡 |
| 触发期 | 被动应对 | 试探攻击 | 受挫 |
| 对抗期 | 主动反击 | 全面压制 | 僵持 |
| 转折期 | 找到关键 | 暴露弱点 | 逆转 |
| 高潮期 | 孤注一掷 | 全力一搏 | 决胜负 |
| 余震期 | 面对代价 | 遗产/余党 | 重建 |

每次升级必须有新信息、更大选择困境、冲突性质变化，且对手同步升级。

## 主线追踪

| 卷数 | 核心事件 | 主角变化 | 世界变化 | 冲突升级 |
|---|---|---|---|---|
| | | | | |

支线最终都要回到主线，或揭示主线新信息。

## 多维度展开

- 个人：欲望 vs 恐惧、责任 vs 自由
- 关系：主角与反派、伙伴、世界
- 社会：传统 vs 革新、秩序 vs 自由

## 微观表现

宏大冲突要在日常场景中可感：盘查、师徒分歧、犹豫下手、团队决策都是冲突的显影。

伪解决：外部介入、回避不提、绝对碾压、巧合化解。正确做法是让主角做选择，暂时搁置也要留伏笔，力量优势有代价。

## 多线交织

主线、个人线、关系线可以同时推进；高潮让多条线共振。每个主要场景至少有 2 条线在场，三条线各有节奏。

## 代价与结局

- 累积表记录每卷失去、获得和净状态。
- 结局必须回应三要素、让主角成长、让世界变化、让读者满足。
