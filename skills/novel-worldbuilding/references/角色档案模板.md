> 用途：为每个重要角色建立动态档案。新增角色时复制本模板，命名为 `角色名.md`，随剧情持续更新。

## 基本信息

姓名、别名/代号、年龄、性别、身份/职业、社会层级、所属势力、首次出场、角色状态（活跃/死亡/失踪/退场）。

## 核心驱动力

必须填写以下四项：

| 项 | 字段 | 检查 |
|---|---|---|
| 欲望 | 表面欲望 / 真实欲望 | 能否在剧情中被满足或毁灭？ |
| 恐惧 | 表面恐惧 / 核心恐惧 | 是否会被剧情触发？ |
| 矛盾 | A 面 / B 面 / 冲突点 | 是否制造关键剧情时刻？ |
| 秘密 | 内容 / 揭露后果 / 谁最接近知道 | 是否在高潮时揭露？ |

## 功能定位

勾选角色功能：主角、导师、伙伴、反派、反派盟友、爱情线对象、喜剧调剂、信息提供者、牺牲者或其他。

记录：帮助主角成长的方式、制造阻碍的方式、与主角的关系弧线。

## 性格画像

- 外在：3 个标志性动作、口头禅/说话风格、情绪爆发特征、穿衣外貌风格
- 内在：决策风格（冲动/权衡/直觉/理性）、3 个核心价值观、压力反应（战斗/逃跑/僵硬/讨好）
- 缺陷：致命缺陷、可爱缺陷、与主角的冲突点

## 读者投入点

勾选读者关心原因：共情、好奇、期待、恐惧、喜爱、恨意。

高光时刻：最让人心疼/敬佩/意外/重新认识角色的时刻。

## 原型参考

| 原型 | 核心驱动力 | 常见变体 |
|---|---|---|
| 孤儿 | 归属 / 怕被抛弃 | 流浪儿、遗孤、被逐者 |
| 战士 | 证明自己 / 怕软弱 | 复仇者、守护者 |
| 智者 | 真理 / 怕无知 | 导师、学者、先知 |
| Trickster | 自由 / 怕约束 | 盗贼、间谍、小丑 |
| 照顾者 | 保护 / 怕无力 | 医师、领袖、父母 |
| 叛逆者 | 改变世界 / 怕平庸 | 革命家、异端 |
| 恋人 | 联结 / 怕孤独 | 痴情者、失恋者 |
| 统治者 | 控制 / 怕混乱 | 暴君、明君、幕后黑手 |

有魅力的角色常用两个原型组合：战士+照顾者、智者+Trickster、孤儿+统治者、叛逆者+恋人。原型是起点，不是牢笼。

## 声音设计

三要素：词汇选择、句式节奏、语气态度。

| 角色类型 | 特征 |
|---|---|
| 老江湖 | 行话、短句、反问、世故 |
| 书呆子 | 术语、长句、爱解释 |
| 热血少年 | 感叹、短句、冲动 |
| 阴谋家 | 双关、暗示、试探 |
| 苦大仇深 | 否定词、省略主语、压抑 |

一致性检查：不突然改变词汇层级；情绪高涨时特征放大而非消失；核心特征跨场景稳定；不依赖对话标签也能辨认。
