# 力量体系设计

> 用途：设计自洽、有代价、可升级的力量体系。项目中的详细字段按需填入 `10-设定/力量体系.md`。

## 力量三要素

来源 → 表现 → 代价

- 来源：力量从哪里来？
- 表现：力量如何显现？
- 代价：使用要付出什么？

缺少任一要素，体系都会崩坏。

## 等级原则

1. 等级越高人数越少，形成金字塔。
2. 每个等级有质变，不只是数值上升。
3. 晋升需要标志事件或仪式。
4. 每次晋升都会失去一些东西。

## 代价系统

| 类型 | 示例 |
|---|---|
| 身体代价 | 减寿、残疾、变异 |
| 精神代价 | 疯狂、失忆、人格分裂 |
| 关系代价 | 亲友受伤、被孤立 |
| 道德代价 | 杀人、背叛、牺牲无辜 |
| 资源代价 | 灵石、生命力、时间 |

代价要和选择绑定：用力量救人会伤自己；不用会看人死；找第三种方法要冒险。

## 力量与社会

- 力量可遗传 → 血统贵族、阶层固化
- 力量需修炼 → 师徒制度、宗门体系
- 力量稀缺 → 垄断、黑市、战争
- 力量可交易 → 商品化、阶级分化
- 力量有副作用 → 歧视、隔离、隐藏

## 平衡检查

- [ ] 顶级战力有明确上限
- [ ] 低级在特定条件可胜高级
- [ ] 战力差距不是绝对
- [ ] 升级速度与剧情匹配
- [ ] 每次使用代价都被记录
- [ ] 累积代价有显现并驱动选择

## 附录：战斗规则


> 用途：设计有策略深度、有代价的战斗规则。战斗比的是信息、策略、意志和代价，不是数值。

## 基础规则

| 判定方式 | 适用场景 | 风险 |
|---|---|---|
| 击倒/击杀 | 生死战 | 角色可能死亡 |
| 认输/投降 | 切磋、压制 | 失去尊严/资源 |
| 达成目标 | 潜入、护送 | 目标失败即输 |
| 时间限制 | 突围、拖延 | 时间耗尽 |
| 第三方介入 | 混战 | 局势不可控 |

战场要素：地形、天气、时间、人数、信息，各自写影响与利用方式。

## 战斗流程

1. 战前：信息、目标、策略、代价评估
2. 战中：试探 → 升级 → 转折 → 决胜
3. 战后：代价结算、信息更新、关系变化

## 策略库

以弱胜强：信息差、环境利用、牺牲战术、规则利用、心理战。
以强凌弱：碾压、资源消耗、信息封锁、人质威胁、心理压迫。

每种策略都写清前提、风险和道德代价。

## 代价

- 即时代价：轻伤、重伤、致命伤、精神创伤、装备损毁
- 累积代价：身体旧伤、精神创伤、关系破裂、资源耗尽

## 特殊场景

- 群战：2v2 看配合，小队看阵型，大规模看士气与补给
- 非对称：人 vs 怪物/环境/组织，悬念来自智斗和限制
- 围城：围困、试探、总攻、巷战四阶段
- 海陆空地下：记录特殊限制、优势和战术

## 叙事检查

- [ ] 战斗展示能力、推进剧情、揭示性格、改变关系或制造代价
- [ ] 节奏有铺垫、爆发、转折、决胜、余波
- [ ] 战后状态真实更新
