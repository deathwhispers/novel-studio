# 力量体系设计

> 用途：设计自洽、有代价、可升级的力量体系。项目中的详细字段按需填入 `10-设定/力量体系.md`。

## 力量三要素

来源 → 表现 → 代价

- 来源：力量从哪里来？
- 表现：力量如何显现？
- 代价：使用要付出什么？

缺少任一要素，体系都会崩坏。

## 等级原则

1. 等级越高人数越少，形成金字塔。
2. 每个等级有质变，不只是数值上升。
3. 晋升需要标志事件或仪式。
4. 每次晋升都会失去一些东西。

## 代价系统

| 类型 | 示例 |
|---|---|
| 身体代价 | 减寿、残疾、变异 |
| 精神代价 | 疯狂、失忆、人格分裂 |
| 关系代价 | 亲友受伤、被孤立 |
| 道德代价 | 杀人、背叛、牺牲无辜 |
| 资源代价 | 灵石、生命力、时间 |

代价要和选择绑定：用力量救人会伤自己；不用会看人死；找第三种方法要冒险。

## 力量与社会

- 力量可遗传 → 血统贵族、阶层固化
- 力量需修炼 → 师徒制度、宗门体系
- 力量稀缺 → 垄断、黑市、战争
- 力量可交易 → 商品化、阶级分化
- 力量有副作用 → 歧视、隔离、隐藏

## 平衡检查

- [ ] 顶级战力有明确上限
- [ ] 低级在特定条件可胜高级
- [ ] 战力差距不是绝对
- [ ] 升级速度与剧情匹配
- [ ] 每次使用代价都被记录
- [ ] 累积代价有显现并驱动选择
