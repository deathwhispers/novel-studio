# 经济与资源

> 用途：设计世界的物质基础，让战争、政治和势力冲突有经济逻辑。

## 生产与货币

| 环节 | 方式 | 控制者 | 问题 |

货币记录类型、价值锚定、流通范围、伪造难度和稳定性。

## 贸易与黑市

- 贸易路线：起点、终点、货物、利润、风险
- 控制者、关税、走私活跃度
- 黑市商品和地下势力的控制领域、与官方关系、生存方式

## 贫富与债务

| 阶层 | 人口占比 | 财富占比 | 生活方式 |
|---|---|---|---|
| | | | |

贫困的代价：底层为生存做什么、有无出路、如何制造犯罪或反抗。债务关系写清债权人权力和债务人处境。

## 资源替代

主资源枯竭 → 第一替代（昂贵）→ 第二替代（副作用）→ 终极替代（变革）。记录各阶段社会反应和受益/受损方。

## 剧情绑定

- 资源枯竭 → 战争、迁徙
- 垄断 → 反抗、黑市
- 货币崩溃 → 社会动荡
- 贸易封锁 → 走私、外交
- 债务 → 卖身、犯罪
- 主角和反派的经济层级、收入来源、经济压力
