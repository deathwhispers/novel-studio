# 一致性检查清单

> 用途：按类别检查设定是否自洽，发现疑似矛盾时逐项核实。

## 角色

- [ ] 行为符合核心驱动力
- [ ] 决策风格和压力反应稳定
- [ ] 能力、代价、限制与 hard canon 一致
- [ ] 关系状态与最新记录一致，变化有事件触发

## 设定

- [ ] 已写内容未违反 hard canon
- [ ] 新规则与已有规则不冲突
- [ ] 地理移动符合距离和通行时间
- [ ] 地点、势力状态在相关文件中同步

## 剧情

- [ ] 伏笔有回收计划，废弃伏笔有标记
- [ ] 角色信息与读者信息合理对齐
- [ ] 行动产生后果，重要决策有长期影响

## 风格

- [ ] 叙述距离稳定
- [ ] 禁用语未出现
- [ ] 角色对话和标志性动作可辨认

## 检查流程

- 每卷：通读本卷 → 对照设定核实 → 修复或记录例外。
- 完本前：全文通读 → 系统检查 → 整理优先级 → 更新最终版本。

## 常见矛盾

| 矛盾 | 检测 | 修复 |
|---|---|---|
| 角色瞬移 | 行程表 | 补路途或解释 |
| 季节错乱 | 时间轴 | 调整描述或时间 |
| 越级秒杀 | 等级表 | 加智斗、限制或代价 |
| 能力遗忘 | 能力清单 | 补限制触发 |
| 态度突变 | 关系日志 | 补转折事件 |
| Hard Canon 违反 | 硬设定清单 | 修改正文或变更设定 |
| 规则双标 | 规则适用性 | 统一规则或解释例外 |

## 处理决策树

发现矛盾 → 硬设定矛盾？是则必须修复；否 → flavor text 矛盾？可忽略或轻微修正；否 → 伏笔矛盾？决定回收或废弃；否 → 记录并评估影响。
