# 势力系统设计

> 用途：设计有欲望、有裂痕、会变化的势力。项目字段按需填入 `10-设定/势力/势力名.md`。

## 核心驱动力

- 公开目标 vs 真实目标
- 外部威胁 vs 内部威胁
- 对外价值观 vs 实际运作逻辑

## 组织架构

```
领袖 → 核心层 → 执行层 → 底层
```

关键人物至少记录领袖、二号人物、反对派。每个势力至少 1 个内部派系；没有内部矛盾的势力不存在。

## 资源与能力

| 资源 | 具体描述 | 稀缺度 | 获取方式 | 弱点 |
|---|---|---|---|---|
| 武力/经济/知识/政治/情报 | | | | |

## 关系网

| 对象 | 关系 | 亲密度 | 利益交集 | 潜在冲突 |
|---|---|---|---|---|
| | | | | |

与主角的关系记录立场、利益、信任的初始/当前/演变方向。

## 历史与演化

- 起源、誓言/信条、关键历史事件
- 当前危机：最大挑战、不解决后果、谁最想让它倒台
- 每卷更新状态、实力、关键事件、对主角影响

## 多势力检查

- [ ] 每个势力有欲望和恐惧
- [ ] 每个势力有内部矛盾
- [ ] 势力间有结构性冲突，不是善恶对立
- [ ] 势力实力有差距
- [ ] 主角有选择空间
- [ ] 势力随剧情变化
