> 用途：从零搭建小说世界顶层框架。时机：立项后、写第 1 章前。耗时：2-4 小时，只搭骨架，细节随写随补。

## 核心原则

先冲突后设定：设定只有让角色选择变难时才有价值。

| 原则 | 说明 | 反例 |
|---|---|---|
| 先冲突后设定 | 先确定核心矛盾，再设计支撑规则 | 先写 5000 字历史，发现用不上 |
| 先 hard canon 后 flavor | 不可违反规则优先，细节后补 | 设计货币体系，主角不用钱 |
| 人物优先于世界 | 读者通过角色感知世界 | 开篇 3 章纯设定，主角未出场 |
| 渐进式丰富 | 开书只建骨架，写到哪补到哪 | 第一天填满所有设定 |

## 六维度框架

### 1. 物理世界（Where）

| 层级 | 名称 | 特征 | 剧情影响 |
|---|---|---|---|
| 世界/大陆 | | | |
| 国家/区域 | | | |
| 城市/聚落 | | | |
| 核心场景（3-5 个） | | | |

物理法则差异：`法则 → 影响`。环境氛围：整体色调、时间叙事意义（如白天=安全、黑夜=危险）。

### 2. 社会世界（Who）

权力金字塔至少 3 层：顶层/中层/底层，并定义层间流动通道与层内矛盾。至少 2 种组织，记录权力来源、运作逻辑、弱点、代表势力。社会禁忌至少 2 条，每条写违反代价。

### 3. 历史世界（When）

| 层级 | 跨度 | 内容 | 当前影响 |
|---|---|---|---|
| 远古史 | 模糊 | 起源、神话 | |
| 近代史 | 50-100 年 | 塑造当前格局的事件 | |
| 当代史 | 主角出生至今 | 直接影响主角人生 | |

每个历史事件都应回答：留下什么伤疤？谁崛起/衰落？主角父辈的位置？未解决的仇恨或承诺？

### 4. 规则世界（How）

Hard canon 3-10 条：编号、规则、违反后果、首次验证章节。代价系统至少覆盖身体/精神/关系/道德之一。

### 5. 价值世界（Why）

核心母题 1-3 个，写清对立价值、主角初始立场、最终立场。道德困境 2-3 个，每个必须“无论怎么选都有代价”。

### 6. 神秘世界（What if）

未解之谜保留悬念：谜题 → 部分揭示时机。写清已知边界、越界代价。

## 五步流程

| 步骤 | 耗时 | 交付 |
|---|---|---|
| 确定世界类型 | 30 分钟 | 规模、基调、核心差异 |
| 画权力地图 | 1 小时 | 至少 3 个势力的欲望/恐惧/资源/弱点 + 关系网 + 结构性矛盾 |
| 锁死 Hard Canon | 30 分钟 | 5-10 条规则，约束物理上限/社会禁忌/资源限制/绝对代价 |
| 设计主角初始位置 | 30 分钟 | 社会层级、资源、信息、行动空间 |
| 建立最小可运转集 | 1 小时 | `硬设定.md`、`主角.md`、`核心冲突.md`、`开场地点.md`、`初始势力.md` |

红线：5 个最小文件不完成，不开写第 1 章。

## 常见陷阱

| 陷阱 | 症状 | 修复 |
|---|---|---|
| 百科全书 | 设定很多，剧情没开始 | 问：这个设定让谁的选择变难？ |
| 铁板一块 | 势力内部无矛盾 | 每势力至少 1 个内部裂痕 |
| 免费超能力 | 力量无代价 | 每次突破有身体/精神/关系/道德代价 |
| 时间混乱 | 不同地点事件对不上 | 建立统一时间轴 |
| 文化真空 | 只有政治战斗，没有日常 | 设计 3 个日常细节 |
| 设定孤岛 | 各设定无关联 | 新设定链接到已有 2 个设定 |

## 动态演化

世界随剧情改变：主角造成的、独立发生的、被揭示的。每个变化写入对应追踪文件，避免硬 canon 被悄悄突破。

## 交叉影响矩阵

| 方向 | 示例 | 剧情机会 |
|---|---|---|
| 物理→社会 | 资源稀缺→垄断/黑市/固化 | 底层革命 |
| 社会→物理 | 战争不断→焦土/难民 | 流民起义 |
| 历史→规则 | 大灾变→禁忌/封锁 | 禁忌诱惑 |
| 规则→价值 | 力量可遗传→血统至上 | 平民觉醒 |
| 价值→神秘 | 极度信仰→未知不可探究 | 科学觉醒 |
| 神秘→物理 | 异界可通往→边界不稳 | 入侵/殖民 |

## 世界类型速查

| 类型 | 核心差异 | 构建重点 | 常见陷阱 |
|---|---|---|---|
| 修仙 | 个体修炼突破生命极限 | 等级、寿命、资源、传承 | 战力膨胀、寿命失衡 |
| 奇幻 | 超自然力量非人人可用 | 魔法来源、社会结构、政治、神话 | 魔法万能、设定表面化 |
| 科幻 | 技术驱动，法则可理解 | 技术水平、社会形态、资源、伦理 | 技术万能、问题无探索 |
| 武侠 | 人体极限仍物理范围 | 武学、江湖规则、朝堂江湖 | 武功万能、规则不可执行 |

## 设定压测

| 测试 | 检查 | 通过标准 |
|---|---|---|
| 极端场景 | 弱胜强、顶级战力、消耗战、大战 | 有明确路径，不超 hard canon，升级可控 |
| 多角色 | 不同角色同场景对决 | 无角色在任何场景都无解强/弱 |
| 时间跨度 | 设想 1000 章 | 升级曲线、世界变化、势力兴衰、硬规则均可维持 |
| 读者质疑 | 主角/反派为何不直接做 X | 用限制、信息差或代价回答 |

## 自检清单

- [ ] 核心冲突能让主角至少做 10 次重大选择
- [ ] 硬设定不超过 10 条
- [ ] 主角有明确欲望和恐惧
- [ ] 至少 1 个势力与主角立场对立
- [ ] 世界有 3 个可感知日常细节
- [ ] 力量代价已定义

## 使用提示

1. 不要一次性填满；最小可运转集完成后即可开写。
2. 写到哪补到哪：新角色建角色卡，新势力建势力卡。
3. 每卷结束检查 hard canon 是否被违反。
4. 硬设定修改必须记录原因。
5. 底层设定不必全部揭示给读者。
