# 对话写作

## 能力范围

- 让对话承载关系变化、信息交换或角色选择
- 区分不同角色的说话方式
- 用潜台词和沉默替代直白解释

## 对话功能分流（W-NEW-DIAL-FUNC 修复）

按对话功能分 3 类——决定对话密度、打断比例、废话密度：

| 功能类型 | 触发场景 | 对话密度 | 打断比例 | 废话密度 | 写作要点 |
|---------|---------|---------|---------|---------|---------|
| **信息交换型** | 主角问情报/反派透露计划/盟友交接任务 | 高密度（每句含信息） | 中（可打断但要补完） | **极低**（不闲聊） | 短句直接、信息可追溯；不解释；收尾靠动作 |
| **关系变化型** | 朋友变恋人/敌人变盟友/陌生人破冰 | 中密度（情绪密度高） | **高**（打断=关系变化的载体） | **高**（闲聊铺垫） | 用沉默/回避承载情绪；用闲笔铺垫气氛；少解释 |
| **情绪释放型** | 角色崩溃/愤怒宣泄/暴露脆弱 | 低密度（短句 + 长停顿） | 极低（不打断） | 极低 | 短句 + 动作锚定 + 留白；不用长独白 |

**Writer 自检**：
- 写完一段对话，问：「这段对话属于哪种功能？」
- 信息交换型 → 出现闲聊 → 删
- 关系变化型 → 出现纯信息传递 → 加 1-2 句关系铺垫
- 情绪释放型 → 出现长解释 → 删，留给动作承载

## 对话前的动作锚定（W-NEW-DIAL-ANCHOR 修复）

**原则**：对话前必须有 1-2 句动作锚定——读者要知道「谁在做什么/看向哪里」再开口。

按场景决定加哪种动作：

| 场景 | 加什么动作 | 示例 |
|------|-----------|------|
| **情绪转换时** | 角色停下当前动作 + 一个新动作 | "他停下手里的活，抬眼看她。" |
| **沉默前** | 角色收起某个物品 / 转身 | "他收起照片，转过身。" |
| **挑衅前** | 角色逼近 / 抬高下巴 / 冷笑 | "她往前一步，嘴角翘起来。" |
| **关系缓和时** | 角色放松姿态 / 主动倒水 | "他倒了杯水推过去。" |
| **回答敏感问题前** | 角色犹豫 / 看别处 | "他没看她。看着窗外。" |

**禁止**：
- ❌ 纯对话段落（无任何动作）超过 5 句
- ❌ 动作只用「他看着她」一类无信息动作（视觉锚定 → 改成触觉/听觉）
- ❌ 多人对话每句之间没动作（读者无法判断说话者）

## 沉默/回避动作库（W-NEW-SILENCE 修复）

**问题**：`de-flavor-techniques.md` 只说「把正面回答改成沉默或岔开话题」，但"什么样的动作算回避"没示范库。

**修复**：12 个常见沉默/回避动作，Writer 按角色性格 + 场景选用：

| 动作 | 适用角色 | 承载情绪 |
|------|---------|---------|
| **低头** | 各种角色通用 | 愧疚/沉默/接受 |
| **转身**（背对对方） | 不愿面对/抗议 | 拒绝/逃避 |
| **收起物品**（照片/信件/小物件） | 情感细腻角色 | 收回情感/准备离开 |
| **整理衣物**（扣扣子/拉袖子） | 老兵/严肃角色 | 紧张/掩饰 |
| **抽烟 / 摸烟** | 中年男性角色 | 思考/拖延 |
| **看窗外 / 看天花板** | 各种角色通用 | 回避眼神/沉思 |
| **摸伤口**（旧伤 / 疤痕） | 受伤过的角色 | 回忆/自我安抚 |
| **倒水 / 推饮料** | 礼貌型角色 | 拖延/缓和气氛 |
| **收拾东西**（碗筷/工具/文件） | 务实型角色 | 结束对话的暗示 |
| **擦桌子 / 整理桌面** | 紧张型角色 | 手部焦虑 |
| **把手插进口袋** | 男性/务实角色 | 克制/避免触碰 |
| **装作看手机** | 现代角色 | 拒绝沟通 |

**Writer 用法**：
- 写角色回避回答时，从本表选 1 个动作（不要连用超过 2 个——避免动作堆砌）
- 角色在不同场景下的回避动作应该**有偏好**（主角总看窗外 → 配角总摸烟 → 各自一致）
- 动作 + 一句短对话 = 完整的"沉默拒绝"（如：「他没说话。摸了摸旧伤。」）

## 对话功能检查

写完一段对话后，检查是否至少满足一项：

- [ ] 对话改变了角色之间的关系（靠近/疏远/暴露/隐藏）
- [ ] 对话传递了角色之前不知道的信息
- [ ] 对话迫使角色做出选择或改变计划
- [ ] 对话揭示了角色的某一方面（欲望/恐惧/伪装）

如果四项都不满足 → 这段对话可能需要删减或重写。

## 角色声音区分

不同角色的对话必须有可感知的差异：

| 维度 | 示例 |
|------|------|
| 句子长度 | 急躁者：短句。分析者：长句。沉默者：不说完。 |
| 用词习惯 | 军武者用身体词。商人用交易词。学者用抽象词。 |
| 口头禅 | 一个就够了，不用每句都带 |
| 对同一事物的称呼 | 老板/头儿/那个人/他——反映关系 |
| 回避话题 | 什么话题角色会沉默/转移话题/说谎 |

**自检**：去掉所有「XX说」标签，只读引号内的内容，能否分辨是谁在说话？

## 对话中的潜台词

**不要写的**：
- 「我生气了」→ 让角色沉默，或突然用敬语，或开始收拾东西
- 「我不相信你」→ 让角色重复对方的话但加一个「是吗」
- 「我很担心」→ 让角色反复问同一个问题，或用不同方式问

**可以写的**：
- 角色嘴上说 A，行为在做 B（说「没事」同时把杯子捏碎了）
- 两个角色在谈 C，但读者知道他们实际在谈 D
- 角色回避一个问题 → 每次被问到就换话题

## 对话后的处理

- 不要紧跟在对话后解释对话的意思（「他说这句话是因为…」）——信任读者
- 如果对话改变了局面 → 用一个动作或感知来落点
- 如果对话没有改变局面 → 考虑删掉

## 品类适配（番茄系统爽文）

- 主角对话：简短、直接、不解释。打脸时用事实回击而非长篇大论
- 反派对话：可以啰嗦但不能蠢。给反派合理的逻辑
- 系统通知：风格统一（机械/调侃/高冷），每次出场保持一致的语气
