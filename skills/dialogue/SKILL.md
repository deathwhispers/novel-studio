# 对话写作

## 能力范围

- 让对话承载关系变化、信息交换或角色选择
- 区分不同角色的说话方式
- 用潜台词和沉默替代直白解释

## 对话功能检查

写完一段对话后，检查是否至少满足一项：

- [ ] 对话改变了角色之间的关系（靠近/疏远/暴露/隐藏）
- [ ] 对话传递了角色之前不知道的信息
- [ ] 对话迫使角色做出选择或改变计划
- [ ] 对话揭示了角色的某一方面（欲望/恐惧/伪装）

如果四项都不满足 → 这段对话可能需要删减或重写。

## 角色声音区分

不同角色的对话必须有可感知的差异：

| 维度 | 示例 |
|------|------|
| 句子长度 | 急躁者：短句。分析者：长句。沉默者：不说完。 |
| 用词习惯 | 军武者用身体词。商人用交易词。学者用抽象词。 |
| 口头禅 | 一个就够了，不用每句都带 |
| 对同一事物的称呼 | 老板/头儿/那个人/他——反映关系 |
| 回避话题 | 什么话题角色会沉默/转移话题/说谎 |

**自检**：去掉所有「XX说」标签，只读引号内的内容，能否分辨是谁在说话？

## 对话中的潜台词

**不要写的**：
- 「我生气了」→ 让角色沉默，或突然用敬语，或开始收拾东西
- 「我不相信你」→ 让角色重复对方的话但加一个「是吗」
- 「我很担心」→ 让角色反复问同一个问题，或用不同方式问

**可以写的**：
- 角色嘴上说 A，行为在做 B（说「没事」同时把杯子捏碎了）
- 两个角色在谈 C，但读者知道他们实际在谈 D
- 角色回避一个问题 → 每次被问到就换话题

## 对话后的处理

- 不要紧跟在对话后解释对话的意思（「他说这句话是因为…」）——信任读者
- 如果对话改变了局面 → 用一个动作或感知来落点
- 如果对话没有改变局面 → 考虑删掉

## 品类适配（番茄系统爽文）

- 主角对话：简短、直接、不解释。打脸时用事实回击而非长篇大论
- 反派对话：可以啰嗦但不能蠢。给反派合理的逻辑
- 系统通知：风格统一（机械/调侃/高冷），每次出场保持一致的语气
