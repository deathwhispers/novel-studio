# 商业化检查清单

> 用途：逐项检查书名、简介、开篇、追读和平台适配，不达标就改。

## 书名（25 分）

| 维度 | 标准 | 分数 |
|---|---|---|
| 题材信号 | 一眼知道类型 | 0-5 |
| 辨识度 | 与同类书有差异 | 0-5 |
| 卖点暗示 | 能猜到卖点 | 0-5 |
| 记忆度 | 可缩写成 2-4 字 | 0-5 |
| 平台适配 | 符合平台偏好 | 0-5 |

20+ 优秀；15-19 可用；<15 重写。

## 简介（25 分）

| 维度 | 标准 | 分数 |
|---|---|---|
| 前 2 句钩子 | 反常/悬念/冲突 | 0-5 |
| 冲突明确 | 追求 + 阻力 | 0-5 |
| 升级暗示 | 期待主角变化 | 0-5 |
| 悬念/承诺 | 有必须追的理由 | 0-5 |
| 字数控制 | 100-200 字 | 0-5 |

20+ 优秀；15-19 优化钩子；<15 重写。

## 黄金三章（48 分）

- Ch1（16 分）：前 200 字反常、主角在行动、核心压力、章尾钩子
- Ch2（16 分）：压力延续、展示性格、引入 1-2 个关键元素、压力升级
- Ch3（16 分）：有后果的选择、展示能力/特质、世界观扩展、中期悬念

40+ 优秀；30-39 可用；<30 重写。

## 追读布局

| 章节 | 必须有点 |
|---|---|
| Ch1 | 悬念钩子 |
| Ch3 | 小爽点/小转折 |
| Ch5-7 | 信息释放 |
| Ch10 | 小高潮 |
| Ch15 | 关系推进/代价 |
| Ch20 | 中高潮 |
| Ch25-30 | 卷末钩子 |

## 平台适配

- 起点：书名有信息量、简介 150-250 字、Ch3 内爽点、可复杂
- 番茄：反差/悬念强、简介 100 字内钩子、Ch1 有爽点、每 3 章强钩子
- 晋江：情绪/CP 暗示、简介突出感情线、Ch1-2 CP 出场、感情线清晰

## 总分

书名 20% + 简介 20% + 黄金三章 40% + 追读 10% + 平台 10%。85+ 可发布；70-84 合格但需优化；<70 重写。

## 快速检查

1. 3 个陌生人能猜到书名题材和卖点吗？
2. 30 秒内能说出简介讲什么吗？
3. 读前 200 字想继续吗？
4. 前 30 章每个检查点有明确追读点吗？
5. 平台适配有 3 处以上不匹配吗？
