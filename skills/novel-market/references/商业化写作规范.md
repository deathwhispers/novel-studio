> 用途：把作品包装成读者愿意点击、追读和付费的形态。适用于 novel-market 第三步：商业化包装。

## 商业化四件套

书名 → 简介 → 开篇 → 平台适配，分别完成：点击、期待、追读、付费。

## 书名优化

结构：`[核心信号/题材] + [卖点暗示/反差、悬念、情绪、功能]`。

| 类型 | 结构 | 示例 |
|---|---|---|
| 反差型 | 弱→强 | 《废材逆袭：我是龙族太子》 |
| 悬念型 | 身份/秘密+暗示 | 《我有一座冒险屋》 |
| 功能型 | 金手指+效果 | 《开局签到荒古圣体》 |
| 情绪型 | 情绪词+场景 | 《万古神帝》 |
| 直白型 | 主角+做什么 | 《大奉打更人》 |

自检：能猜题材；有反差或悬念；榜单中有辨识度；能缩写成 2-4 字记忆；无过时感。至少准备 3 个备选，发给 3-5 个目标读者测试。

## 简介优化

让读者 30 秒内决定是否值得追。

结构：`钩子 → 主角状态 → 核心冲突 → 升级暗示 → 悬念/承诺`。

- 前 2 句必须用反常、悬念或冲突开场，不用“主角叫 XXX，是……”
- 主角状态写处境，不写履历
- 核心冲突写“要做什么 + 被什么阻止”
- 字数 100-200；不剧透关键反转；不用“本书讲述了……”

示例：林尘被宗门追杀的那天，才发现自己体内沉睡着上古龙魂。从人人可欺的杂役，到被全宗追杀的“叛徒”，林尘只用了一天。

## 开篇优化

前 3 章完成：立主角、立冲突、立期待、立风格。

| 章 | 必须做到 |
|---|---|
| Ch1 | 2000-2500 字；主角有动作；前 200 字有反常；核心压力出现；章尾钩子 |
| Ch2 | 延续 Ch1 压力；展示主角反应方式；引入 1-2 个配角/关键设定；压力升级 |
| Ch3 | 主角做有后果的选择；展示能力/特质；引入更大世界观；章尾抛中期悬念 |

开篇错误：慢热、平铺、无冲突、介绍腔、万能主角。

## 平台适配

| 平台 | 读者特点 | 书名/简介/开篇偏好 | 节奏 |
|---|---|---|---|
| 起点 | 深度读者 | 直白有信息量，简介可含设定 | 可稍慢，Ch3 内必须有爽点 |
| 番茄 | 快节奏碎片化 | 反差/悬念，简介 100 字内有钩子 | Ch1 有爽点，每 3 章 1 个强钩子 |
| 晋江 | 感情向、CP 导向 | 文艺/情绪，突出感情线 | Ch1-2 CP 出场 |
| 飞卢 | 脑洞向、猎奇 | 功能/反差，直白有卖点 | 快，脑洞密集 |

多平台发布：选通用书名，准备 2-3 个简介版本，按主平台优化开篇后微调。

## 追读优化

| 位置 | 追读点 |
|---|---|
| Ch1 | 悬念钩子 |
| Ch3 | 小爽点/小转折 |
| Ch5-7 | 信息释放 |
| Ch10 | 第一次大满足 |
| Ch15 | 关系推进/代价支付 |
| Ch20 | 中高潮 |
| Ch25-30 | 卷末钩子 |

写明读者追书的 3-4 个承诺（悬念解答、主角成长、CP 结果、反派结局），每 10 章检查是否还在推进。

## 自检总结

| 项 | 标准 |
|---|---|
| 书名 | 有辨识度、有卖点暗示 |
| 简介 | 30 秒内建立期待 |
| Ch1 | 2000 字内有反常+压力+钩子 |
| Ch2 | 压力升级、展示性格 |
| Ch3 | 有后果的选择、中期悬念 |
| 平台适配 | 符合目标平台读者偏好 |
| 追读布局 | 前 30 章有明确追读点 |

## 常见错误

| 错误 | 修复 |
|---|---|
| 书名太泛 | 生成 3+ 备选并测试辨识度 |
| 简介剧透 | 只建立期待，不写关键反转 |
| 简介太长 | 压缩到 100-200 字，前 2 句有钩子 |
| 开篇无钩 | 从反常事件开始 |
| 平台错配 | 按目标平台调整 |
| 追读无规划 | 前 30 章有明确追读点 |
| 不测试 | 发给目标读者测试点击意愿 |

## 快速检查

1. 给 3 个陌生人看书名，能猜到题材吗？
2. 30 秒后能说出简介里的故事吗？
3. 读前 200 字想继续吗？
4. 平台适配有 3 处以上不匹配吗？

任一题“否”，回到对应章节修改。
