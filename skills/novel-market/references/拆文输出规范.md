> 用途：拆解爆款时提取可迁移技法和结构，不是复述剧情。适用于 novel-market 第二步。

## 拆解原则

每章问 3 个问题：

1. 这一章让读者追下去的东西是什么？
2. 这一章的“戏”是怎么立的？
3. 这一章的写法我能学到什么？

复述是“主角被追杀，然后遇到女主”；拆解是“开篇用追杀建立即时压力，同时暗示主角身份不凡”。

## 拆解维度

### 1. 钩子设计

分别记录书名、简介、前 200 字、章尾、卷尾的钩子类型、具体写法与效果。

钩子类型：悬念、反差、身份、情绪、倒计时、权力反转、关系破口、不可逆决定。

### 2. 人设塑造

为每个重要角色记录：出场章节、第一印象、核心矛盾、辨识点、弧线方向。

再提炼技法：用了什么技法、具体例子、可迁移性（高/中/低）。

### 3. 节奏控制

按章节区间标节奏强度（1-5）、事件和作用，分析铺垫密度、信息释放、对话与叙述比例、视角切换频率。

### 4. 爽点/虐点设计

| 位置 | 类型 | 具体设计 | 铺垫长度 | 读者反应 |
|---|---|---|---|---|
| Ch {{X}} | 爽点-{{类型}} | | | |
| Ch {{X}} | 虐点-{{类型}} | | | |

记录技法、来源、用法、可迁移性和风险。

### 5. 结构设计

分析全书、卷级、章级三层骨架，并回答：

- 这本书结构上的独特之处是什么？
- 效果是什么？
- 能否迁移到我的项目（能/不能/需变形）？

## 输出格式

输出文件：`05-市场/拆解/《书名》-拆解.md`

```markdown
# 《书名》拆解报告

## 基本信息
- 书名 / 作者 / 平台 / 题材 / 字数 / 状态 / 数据 / 拆解日期 / 拆解人

## 选择理由
为什么选这本书拆解。

## 核心卖点
最成功的 1-3 个点。

## 钩子设计
按钩子表格填写。

## 人设塑造
按人设表格填写。

## 节奏控制
按节奏表格填写。

## 爽点/虐点设计
按爽虐表格填写。

## 结构设计
按三层结构分析。

## 可迁移技法清单
| 技法 | 来源位置 | 我的项目怎么用 | 优先级 |

## 需规避的陷阱
| 陷阱 | 表现 | 我的项目是否已有类似问题 |

## 拆解结论
最值得学的 3 点；最需规避的 1 点；对本项目的直接影响。
```

## 拆解对象

| 类型 | 选择标准 | 目的 |
|---|---|---|
| 直接对标 | 同题材、同风格、同平台 | 学具体技法 |
| 跨题材标杆 | 结构好 | 学结构设计 |
| 新书爆款 | 上架 3 个月内爆红 | 学当前读者偏好 |
| 长青作品 | 完结多年仍有影响力 | 学经典结构 |

不拆：顶级大神自带流量的作品、完全无关题材、数据好但硬伤明显且不可复制的作品。

## 拆解深度

| 深度 | 时间 | 范围 | 产出 |
|---|---|---|---|
| 浅拆 | 30 分钟 | 书名+简介+前 3 章+章尾 | 1 页记录 |
| 中拆 | 2 小时 | 前 10 章+关键章+卷末 | 完整报告 |
| 深拆 | 1-2 天 | 全书逐章分析 | 报告+技法库 |

建议：立项前深拆 1-2 本直接对标；每卷开写前中拆 1 本热门；卡文时浅拆 1 本找灵感。

## 拆文学科纪律

1. 学技法，不抄内容。
2. 拆完必须变形，直接复制会套路化。
3. 结论必须可执行：“节奏好”不是结论，“每 3 章一个小高潮”才是。
4. 拆文不是一次性，写作推进中反复拆。
5. 拆文和写作交替：拆 1 本 → 写 3 章 → 再拆 1 本。

## 常见错误

| 错误 | 修复 |
|---|---|
| 复述代替拆解 | 回答：追读原因、戏怎么立、能学什么 |
| 只拆不记 | 用可迁移技法清单强制记录 |
| 盲目崇拜 | 剥离作者光环，只看技法 |
| 不筛选对象 | 按拆解对象表筛选 |
| 结论太泛 | 换成具体指标 |
| 不验证迁移 | 问：能否用？需要变形吗？ |

## 快速检查

1. 这本书最成功的 1 个点是什么？
2. 这个点我能迁移吗？
3. 用了这个技法，读者会有什么反应？

第 2 题“不能”就放弃；第 3 题答不上来就重新拆。
