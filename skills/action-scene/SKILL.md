# 动作与打斗戏

## 能力范围

- 动作描写的节奏控制（短句、动词优先）
- 打斗的空间感（位置、距离、方位）
- 打斗的因果链（出招 → 反应 → 结果）
- 打斗中的感官体验（不是解说，是身体感受）
- 打斗后的余波（疼痛、代价、心理）

## 动作节奏

打斗的核心是节奏——短句制造速度，长句制造喘气。

```
❌ 他挥出一拳，拳头带着风声砸向对方的胸口，对方侧身躲开，然后反手一刀劈向他的脖子，他向后一仰堪堪避开。

✅ 他出拳。
   对方侧身。
   刀光贴着他的下巴过去。凉。
```

### 节奏规则

- 打斗中：2-5 字短句，动词开头，删副词
- 关键一击前：停一下（一个无用细节、一次呼吸）
- 打斗后：至少一句中长句，让读者喘气

## 空间感

读者要能在脑子里「看见」打斗，前提是知道谁在哪、离多远、朝哪动。

```
❌ 两人打了起来，你来我往，打得难解难分。

✅ 他在门边，对方在窗下。中间隔着一张桌子。
   对方先动。桌子掀翻。茶杯摔碎。
   他退到墙角——没路了。
```

### 空间锚点

- 开打前写一句位置关系（谁在哪、中间有什么）
- 用方位词（左/右/上/下/身后）建立坐标系
- 环境是武器也是障碍（桌子、门框、台阶）

## 因果链

每个动作必须有反应，不能「你一招我一招」地报菜名。

```
❌ 他打出一拳。对方踢出一脚。他又打出一拳。对方躲开。

✅ 他一拳砸在对方肩上。对方趔趄一步，反手抓住他的手腕。
   他想抽。抽不动。
   对方膝盖顶上来。
```

### 因果规则

- A 出招 → B 的身体反应 → A 的下一步选择
- 每回合 2-3 个动作，不堆叠
- 打斗的胜负由「谁先犯错」决定，不由「谁的招式华丽」决定

## 感官体验

打斗不是解说，是身体感受。读者要「疼」，不要「懂」。

| 角度 | ❌ 解说 | ✅ 体验 |
|------|--------|--------|
| 疼痛 | 他感到肩膀一阵剧痛 | 肩膀像被火燎了一下，整条手臂发麻 |
| 疲惫 | 他渐渐体力不支 | 呼吸像拉风箱，腿越来越重 |
| 恐惧 | 他感到恐惧 | 手在抖，刀差点脱手 |

## 打斗后的余波

打完不是结束——疼痛、代价、心理才是打斗的意义。

- **身体**：伤势在哪、疼到什么程度、能撑多久
- **心理**：赢了有没有快感、输了有没有不甘、打斗暴露了什么
- **代价**：用了什么不该用的、惊动了谁、留下了什么痕迹
