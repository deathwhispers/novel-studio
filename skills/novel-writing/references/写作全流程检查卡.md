# 写作全流程检查卡

> 用途：从写前准备到写后交付的全程质量护栏。按阶段定位对应小节。

---

## 一、写前检查


目标是先锁定会改变正文的关键选择，不是把所有问题提前填满。章节和重大连续场景先按 `章节共创确认协议.md` 分轮询问；本表用于整理每轮结论。已有上下文能回答时直接判断，不重复询问用户。

## 所有模式都确认

- 写作单位：片段 / 场景 / 章节 / 短篇
- 写作模式：商业连载 / 类型长篇 / 文学叙事 / 短篇 / 探索起草
- 当前视角人物及其此刻的注意焦点
- 人物想靠近、逃避、理解或维持什么
- 当前最相关的压力、关系或未知
- 不可违反的 canon 与不可擅自补全的空白
- 要延续的 voice 样本或语言选择

### 信息边界锁定（所有模式必做）

> AI 拥有大纲和设定的完整知识，天然倾向上帝视角。不锁定信息边界 = 提前泄漏隐藏线、铺直叙述破坏悬念。写前对照节拍卡的「本章信息边界」，明确四层信息。

**视角角色已知**（本章 POV 人物此刻知道什么）：

**视角角色不知**（POV 人物不知道什么——正文中他的判断、推测不能越界）：

**读者已知**（前文章节已向读者释放的信息）：

**读者不知**（前文未释放的信息，读者当前处于什么认知状态）：

**禁止触碰清单**（AI 从大纲/设定中知道，但本章绝不能以任何形式出现）：
- 隐藏身份：尚未揭露的角色真实身份、关系或阵营
- 未公开伏笔真意：埋线的真正含义和后续走向
- 后续反转：后续章节的剧情反转、揭示
- 尚未揭露的规则：世界观中尚未向读者展示的规则、限制或力量体系

**边界自检**：
- 叙述者的语调和判断，是否超过了视角人物的认知范围？
- 本章释放的信息，是否会让读者提前猜出后续大反转？
- 视角人物没有理由知道的事，正文中是否以「他觉得」「他注意到」等形式泄漏了？
- 环境描写、配角对话、内心活动是否无意间成为了作者传声筒？

**例外**：仅当本章的功能本身就是「揭示」或「反转」时，对应信息从禁止触碰清单移入可释放层，但仍需在节拍卡中标注释放方式。

### AI味预防（所有模式必做）

> AI味不是词汇问题，是语言选择与人物、场景脱节。写前读一遍 `../../novel-quality/references/AI味目录.md` 的当前高风险类别，写中保持警觉，写后用「快速检查」扫描。

**写前自问三条**：

- 本章的叙述者声音是「有人在讲故事」还是「范文生成器」？前者有脾气、有偏好、会闭嘴；后者每句都像精修过的例句。
- 我的角色说话时，能不能遮住名字仍能分辨谁在说？不能 → 角色同声腔风险。
- 我有没有哪一段在读的时候感觉「写得挺好但不像是这个角色/这个故事会说的话」？有 → 标记，写后重点查。

## 按模式追加

### 商业连载

- 本章承诺什么、兑现什么？
- 哪个变化或问题推动继续阅读？
- 本章触碰哪条旧线？

### 类型长篇

- 本场景提供什么类型体验？
- 因果、悬念或人物弧线推进哪一项？
- 哪条规则或信息差在施压？

### 文学叙事

- 这段通过谁的观察建立意义？
- 哪种情绪或关系不能被直接简化？
- 语言、意象或叙述距离承担什么作用？

### 短篇

- 哪些信息必须压缩或延迟？
- 当前场景如何与题眼、意象或结尾形成回声？
- 哪一处绝不能解释过满？

### 探索起草

- 当前最想发现的是人物声音、关系、场景还是情节可能性？
- 哪些内容允许暂时矛盾或未定？
- 这次起草结束后用什么判断“值得继续”？

## 何时才停下来询问

章节和重大连续场景在剧情路径、人物关键选择或本章结尾后果未确认前暂停；场景执行层在主视角、信息边界或不可违反的表现要求会改变成文时暂停。其他小空白使用最保守写法并标记“待作者确认”。

若用户已明确说“直接写”、已给出等价的章节方案，或任务只是短片段/探索起草，则不强行追问；先复述采用的方向，再起稿。

## 二、写中即时检查


> 默认在完成一个场景或显著节拍后检查，不按段落或固定字数强制打断。目标是尽早发现会污染后文的硬伤，同时保留连续起草产生的节奏和直觉。

## 默认模式：场景级检查

1. 连续写完当前场景，不在句子层面来回润色。
2. 在视角、地点、时间或主要行动目标切换时停下检查。
3. 只立即修复硬门禁问题；语言和比例问题先标记。
4. 全章完成后统一处理节奏、voice、字数和句子。

## 硬门禁

任一项失败都应先处理，再继续写下一场景：

- [ ] 视角没有无意跳转；有意切换具备清楚边界
- [ ] 人物选择符合当前动机、已知信息和能力边界
- [ ] 没有违反 hard canon、时间线、伤势、位置或资源约束
- [ ] 关键结果能从行动、阻力和规则中推出，不靠作者强行安排
- [ ] 本场景没有让上一场景的直接后果凭空消失
- [ ] 正文未触碰「禁止触碰」清单中的任何信息（对照写前信息边界锁定）

## 场景功能

用一句话回答每项；说不清时回看节拍卡：

- 视角人物此刻在做什么：争取、维持、回避、拖延，还是观察？
- 具体的人、规则、环境或内在矛盾如何阻止他？
- 场景结束时，信息、关系、位置、资源或风险改变了什么？
- 哪个后果推动下一场景，而不是只靠“然后”？
- 本场景最值得保留的动作、画面或潜台词是什么？

场景可以承担呼吸、铺垫或余震功能，不强制每场都出现高潮或反转；但它必须改变读者理解、人物压力或后续选择中的至少一项。

## 软观察

这些信号不自动判失败。先判断偏离是否服务当前场景：

- 叙述距离、句子节奏或描写密度和项目样本不同
- 本场景明显长于或短于计划
- 对话、心理、动作或说明的比例发生变化
- 角色暂时没有使用惯常动作、句式或口头禅
- 出现疑似解释腔、抽象情绪词、常见套语或 AI 味高频句式（见 AI 味目录）
- 连续使用「仿佛/似乎」「在这一刻」「xxx而xxx」「xxx地说」等机械修辞
- 比喻或意象与角色的认知世界不匹配（角色是外卖员但比喻来自文学期刊）

如果偏离有明确目的，例如高潮处压短句、创伤场景拉远叙述距离、审讯场景提高对话比例，记录意图后保留。不要为了指标统一而抹平变化。

## 三种工作模式

### 默认模式

- 每个场景检查一次硬门禁和场景功能。
- 软观察留到全章完成后处理。

### 高频护栏模式

适用于新手、复杂战斗、多人对话或批量 AI 起草：

- 在关键节拍或约 600-1000 字处快速检查硬门禁。
- 连续两次无硬伤后恢复默认模式。
- 不因字数偏差单独停笔。

### 自由起草模式

适用于作者主动探索、实验性章节或已稳定掌握项目 voice：

- 全场景完成后再检查。
- 写作中只标记疑点，不立即修改。
- 结束后仍必须通过硬门禁。

## 决策顺序

```text
发现问题
  ├─ 硬门禁失败 → 局部修复；骨架失效才回节拍卡
  ├─ 场景功能说不清 → 明确目标/阻力/变化，必要时合并或删除场景
  ├─ soft signal 有创作理由 → 记录理由并保留
  ├─ soft signal 无创作理由 → 标记，完成场景后统一修
  ├─ soft signal 无创作理由 → 标记，完成场景后统一修
  ├─ AI味信号（解释腔/机械修辞/陈旧意象/修饰过度）→ 标记，写后扫描
  └─ 卡文 → 使用《写中急救指南》，仍无效再补上下文
```

核心规则：先保护因果、人物和设定，再保护场景功能，最后处理语言表面。不要让检查本身切碎作品的呼吸。

## 三、写中急救


> 急救的目标是恢复人物与文字的运动，不是给正文添加规定动作。一次只试一个最小动作；如果问题来自方向错误，退回写作意图，而不是继续堆技巧。

## 一、先判断卡在哪里

| 表面症状 | 先检查 | 不要默认做什么 |
|---|---|---|
| 篇幅偏短 | 是否漏写必要的选择、过程或后果 | 加对话、景物或新事件凑字 |
| 篇幅偏长 | 是否重复信息、解释已显出的情绪、承担多个任务 | 为满足统一字数硬砍有效段落 |
| 场景不动 | 人物此刻想维持什么，什么迫使他回应 | 强塞第三方、冲突或反转 |
| voice 漂移 | 人物注意什么、回避什么、如何组织语言 | 加口头禅或标志动作冒充声音 |
| 不知道下一句 | 当前视角刚感知到什么，最不愿面对什么 | 随机制造意外 |
| 结尾不成立 | 当前场景造成了什么后果或余韵 | 每章强造悬念 |

## 二、五分钟动作

### 1. 篇幅失衡

- 用一句话写出本段必须完成的作用。
- 标出每一段提供的新信息、体验或变化。
- 偏短：只展开被跳过、且读者必须经历的过程。
- 偏长：优先删同义解释与重复反应；保留人物特征、节奏和潜台词。
- 若自然完成得更短或更长，记录理由后放行。

### 2. 场景没有运动

依次回答：

1. 人物进入场景时想得到、避免或维持什么？
2. 对方、环境或人物自身的矛盾怎样施压？
3. 人物必须做出什么选择、拒绝或重新理解？

缺哪一项就只补哪一项。安静场景的“运动”也可以是关系、认知或注意力变化，不要求外部冲突。

### 3. voice 漂移

- 回读同一人物 200-500 字可靠样本。
- 对比注意力对象、回避方式、信息策略、句法节奏和叙述距离。
- 只改最明显的一类偏差，再通读是否自然。
- 不用固定口头禅、身体动作或句长比例代替人物声音。

### 4. 卡在下一句

任选一个动作：

- 跳写你最清楚的瞬间，之后补桥。
- 把叙述距离拉近或推远，重新看同一时刻。
- 写下人物最不愿说出口的一句话，再决定它是否进入正文。
- 暂写一个可撤销版本，不在句子层面追求定稿。

### 5. 结尾失效

先判断当前模式需要什么：

- 商业连载：后果、未完成行动或新的压力。
- 类型长篇：阶段变化、选择代价或下一步动力。
- 文学叙事：回响、意象变化、认知裂缝或有意义的停顿。
- 短篇：封闭、翻面、余韵或精确留白。
- 探索起草：停在人物或文本刚显出新可能的位置。

## 三、回退路径

- 撞 hard canon、因果断裂、人物重大选择无依据：停笔，回上下文或写作支持。
- 连续两个场景 voice 漂移：回声音样本与文风指南。
- 所有补救都像“加料”：暂停，重写当前场景的一句话意图。
- 连续出现 AI 味信号：回 `../../novel-quality/references/AI味目录.md` 确认模式，标记待写后处理，不中断起草。
- 只是软目标不理想：先完成草稿，在写后阶段集中处理。

## 四、写后自检


**定位**：`novel-writing` 起稿后的 3-5 分钟轻量检查，只守硬门禁、模式目标和明显 voice 风险；不替代 `novel-quality` 的深度章节体检。用户要求精修、发布前检查，或出现需要跨章证据的问题时，转 `../../novel-quality/references/章节体检模板.md`。

先完整读一遍正文，再检查。不要边读边按词表修改。

## 1. 硬门禁

- 视角、时间、地点、伤势、物件和人物已知信息是否连续？
- 正文是否触碰了写前锁定的「禁止触碰」信息？如有，立即移除并复查上下文。
- 重要选择能否从欲望、压力、认知或关系中理解？
- 是否无意违反 hard canon？
- 是否擅自把未知设定写成事实？

硬门禁失败时做最小修复；骨架失效才回到节拍卡或重写。

## 2. 模式目标

- 商业连载：承诺、兑现与继续阅读动力是否清楚？
- 类型长篇：类型体验、因果、悬念或弧线是否推进？
- 文学叙事：观察、情绪真实、语言选择或主题回响是否成立？
- 短篇：压缩、结构回声、意象和结尾是否互相支持？
- 探索起草：是否发现了值得保留的人物声音、关系或故事方向？

## 3. 章尾动力

> 本章最后一句话之后，读者脑中必须浮现一个清晰的问题——这个问题就是翻页的理由。

- [ ] 读者读完本章，脑中自然浮现的第一个问题是什么？
- [ ] 这个问题的答案在下章开头 500 字内有没有得到初步回应（哪怕只是推进）？
- [ ] 章尾是否避免了：总结腔（「就这样，他完成了今天的修炼」）、预告腔（「他不知道，更大的风暴即将来临」）、情绪空转、自然结束？
- [ ] 如果本章是过渡章/低压章，章尾是否至少留下了一个关系变化、一个角色选择或一个信息异常？

章尾不成立时，不要从头重写。先确定「读者现在最想知道什么」，再把那个问题在最后两段里变成可见的——一个选择悬置、一个异常现象、一句改变位置的话，或一个正在逼近的威胁。

## 4. 人物与语言

- 人物注意什么、回避什么、如何组织语言，是否仍属于这个人？
- 叙述距离和句法节奏的变化是否有作用？
- 解释、概括、动作和细节有没有重复表达同一信息？
- 最准确的一处语言是什么？最空泛的一处是什么？

不要求每章出现口头禅、标志动作、固定数量细节、冲突、反转或强钩子。

### AI味强制扫描（写后必做）

> 正文完成后、交付前，用 `../../novel-quality/references/AI味目录.md#快速检查` 扫描全章。这是质量底线——AI 味是读者弃书的最快理由之一。

**扫描步骤**：

1. 全文搜索「仿佛/似乎/好像」「在这一刻/在那一瞬间」「而/却」「不知过了多久」「(副词)地说」「目光/眼神/视线」。
2. 每处判断：这个词在这里是真的需要，还是 AI 的惯性填充？不需要 → 删掉或改写。
3. 抽查三段对话：遮住角色名能分辨谁在说吗？不能 → 角色同声腔，重写差异。
4. 抽查三段叙述：有没有「不是……而是……」「没有……就是……」句式？有 → 删否定铺垫。
5. 快速扫一遍比喻和意象：「空气凝固」「心被揪了一下」「一股暖流」「断了线的风筝」→ 出现了就换。

**判定**：
- 扫描命中 3 处以上 → 逐项修复后重新通读
- 同一类模式出现 2 次以上 → 该模式列入本章训练目标
- 仅 1-2 处且模式不重复 → 修复后放行

扫描完成后进入 ## 5. 决策。

## 5. 决策

- 有硬伤：局部修复并复查。
- 模式目标未完成：修最影响阅读效果的一处。
- 只有软风险：正文后标记，不自动改写。
- 已成立：交付正文，记录状态增量。

## 边界

- 本卡在正文交付前使用，答案来自当前章本身。
- `章节体检模板` 在转交 `novel-quality` 后使用，会补查前后照应、埋线、追读风险和修订结论。

## 五、全流程检查


检查深度服从任务，不要求每次写作完整走完全部流程。

## 快速起草

适用：试写、探索、续写片段、寻找人物声音。

1. 判断写作模式和视角。
2. 读取最近正文与必要 canon。
3. 直接输出正文。
4. 只标记硬伤和待确认项。

## 标准写章

适用：类型长篇、常规连载章节。

1. 读取节拍卡、最近正文、相关人物与 voice。
2. 连续完成场景，在场景边界检查硬门禁。
3. 先交付正文，再做轻量自检（含 AI 味强制扫描）。
4. 写章节状态增量；不逐章重写全部总账。

## 发布前精修

适用：用户明确要求精修、投稿、发布或定稿。

1. 检查硬门禁。
2. AI 味全章扫描并逐项修复。
3. 根据写作模式选择 2-3 个质量目标。
4. 先修结构和人物，再修信息与语言。
4. 每个问题引用原文并说明受损效果。
5. 对比修改前后，确认没有损害 voice、潜台词和节奏。

## 周期复盘

适用：每 5 章或卷末。

1. 合并章节状态增量。
2. 扫描连续性、伏笔和人物状态。
3. 汇总重复写作问题。
4. 只选一个下一周期训练目标。

## 停笔条件

仅在以下情况暂停并请求作者决定：

- 两种选择会改变核心人物立场或主线方向。
- 必要 hard canon 缺失或互相冲突。
- 用户要求与已有正文存在无法保守处理的冲突。

状态文件缺失、软目标不足、字数偏离或表层风险不阻止正文交付。
