# 连载状态追踪

> 用途：跨章持久化的三态追踪文件。Director 生成约束前必读，Writer 写完后必更新，Critic 验收时对照检查。这是防信息泄漏和上帝视角的中央数据库，不是临时备忘。

---

## 文件位置

`10-状态/连载状态.md`（项目根目录下，与 `20-大纲/` 同级）

每章写完后增量更新，每 5 章或卷末合并冗余。

| 章节 | 线索内容 | 指向秘密 ID | 释放方式 | 是否已回收 |
|------|---------|------------|---------|----------|
| Ch5 | 半张照片，背景有标志性建筑 | S1 | 环境细节，主角未注意 | 否 |
| Ch8 | X 的不在场证明与监控对不上 | S2 | 对话潜台词，读者能察觉 | 否 |

**释放方式取值**：环境细节 / 对话潜台词 / 角色内心反应 / 叙述者暗示 / 动作后果

## 六、状态更新协议（由 State Manager 执行）

Critic 验收通过后，State Manager 读取 Review Report + Writer 状态增量标记，执行以下更新：

1. **作者状态**：检查是否有新秘密需要加入；已揭示的秘密改为「已揭示」并归档到下方「已揭示档案」
2. **角色状态**：更新本章 POV 角色的已知/未知/误判/目标/压力
3. **读者状态**：更新读者已知（本章释放了什么）、读者未知、读者最可能的猜测
4. **线索追踪**：本章新释放的线索逐条记录；有回收的标为「已回收」
5. **Director 约束**：本章的约束存档到 `10-状态/导演约束存档/ChXXX-约束.md`（仅当约束内容与节拍卡有本质差异时才存档）

## 七、长期记忆压缩（State Manager 每 5 章或卷末执行）

### 触发条件
当前章节号 % 5 == 0，或卷末

### 压缩操作
1. **线索追踪表压缩**：已回收的线索保留一行摘要（章/内容/回收方式），删除详细描述
2. **角色状态压缩**：非活跃 POV 角色合并为一段摘要；活跃 POV 角色保留完整状态
3. **读者状态压缩**：已揭示超过 3 章的信息移入「读者已知摘要」
4. **卷记忆生成**：写入 `10-状态/卷记忆/第X卷-摘要.md`，包含：
   - 本卷关键事件（最多 10 条，每条一行）
   - 本卷揭示的秘密
   - 本卷新增的活跃伏笔
   - 卷末各 POV 角色状态快照
5. **状态文件瘦身**：删除已被卷摘要覆盖的逐章细节，保留当前章和上一章的完整状态

### 压缩后
- 状态文件控制在 500 行以内
- 已归档内容通过卷摘要文件可追溯
