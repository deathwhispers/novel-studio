# 写后状态与训练

> 用途：章节完成后的状态增量记录与作者阶段性训练目标管理。

---

## 一、章节状态增量


正文完成后只记录本章真实发生的变化。没有变化的总账不更新。

```markdown
#### chapter-XXX 状态增量

- 新增 hard canon：无 / …
- 人物状态变化：无 / …
- 关系变化：无 / …
- 新增或推进的伏笔：无 / …
- 已回收事项：无 / …
- 新增未决问题：无 / …
- 下一章必须继承的直接后果：…
- 待作者确认：无 / …
```

保存到 `90-运行/章节增量/chapter-XXX.md`。续写上下文在合并前必须读取最近相关增量；每 5 章或卷末再把增量合并进人物状态、因果图、回收总账和前文索引。只有新 hard canon 需要立即写入 `硬设定.md`；不确定内容放入“待作者确认”，不得擅自固化。

---

## 二、作者训练闭环


目标是让检查逐渐减少，而不是让作者永久依赖更多检查表。

## 每 5 章复盘一次

1. 汇总最近章节重复出现的问题，只统计有原文证据的问题。
2. 选一个最影响阅读效果、同时可在下一章练习的目标。
3. 保存一组修改前后片段，说明改动为什么更有效。
4. 下一轮写作只主动提醒这个训练目标，其他软问题写后再看。
5. 连续 3 次稳定通过后移出高频提醒。

## 训练记录

```markdown
## 周期：chapter-XXX 至 chapter-XXX

- 当前唯一训练目标：
- 反复出现的原文证据：
- 它损害的阅读效果：
- 修改前：
- 修改后：
- 下一章可执行练习：
- 连续通过次数：0/3
```

训练目标应写成可观察行为，例如“关键对话中减少直接回答，让回避来自人物关系”，不要写成“文笔更好”“更有张力”。保存到 `90-运行/写作训练日志.md`。
