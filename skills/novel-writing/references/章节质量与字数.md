# 章节质量与字数

> 用途：章节级质量标准与字数控制——写前预算分配、写后校验。

---

## 一、字数控制


> 篇幅是生产与媒介约束，不是文学质量分数。只有平台、投稿或用户明确给出限制时才构成硬约束。

## 一、先确认约束来源

| 来源 | 处理方式 |
|---|---|
| 平台/投稿硬限制 | 在不破坏必要内容的前提下满足，超限时调整场景边界 |
| 商业连载更新预算 | 作为可持续区间，允许章节功能导致的合理波动 |
| 类型或作者习惯 | 作为节奏观察，不单独触发扩写或删改 |
| 文学、短篇、探索起草 | 以形式、压缩和阅读效果决定自然篇幅 |

## 二、写前预算

- 当前写作单位：场景 / 章节 / 片段 / 全篇
- 目标区间及来源：
- 这个单位必须让读者经历的过程：
- 可以省略、跳切或留白的部分：
- 若自然完成后偏离区间，允许怎样拆分或合并：

不按固定比例预分铺垫、推进、高潮和余震；只有明确选择商业连载四段式时才参考相应技法库。

## 三、写中观察

不要按固定字数中断连续起草。到场景边界再判断：

- 偏短是否因为跳过了必要选择、过程或后果？
- 偏长是否因为重复信息、解释已经显出的情绪，或同时承担多个写作单位？
- 当前长度是否服务叙述距离、人物体验和模式？

偏短不默认加对话、环境或新事件；偏长不默认砍人物特征、潜台词和有效节奏。

## 四、写后决定

1. 自然完成且无硬限制：放行并记录实际长度。
2. 有硬限制但内容成立：优先移动场景边界或压缩重复信息。
3. 内容未成立：修复人物、因果或场景功能，不把问题命名成“字数不足”。
4. 连续偏离预算：调整项目预算，不能要求正文长期迎合错误估算。

- 是否需要动作：无 / 拆分 / 合并 / 压缩重复 / 补必要过程

## 二、质量标准


质量不是命中特定技巧，而是形式、人物、语言与当前写作目的相互支持。

## 共同底线

1. **连续性可信**：视角、人物状态、规则和已知信息没有无意断裂。
2. **人物可信**：重要反应来自人物已有欲望、经验、压力和关系，而非作者强推。
3. **信息清楚到恰当程度**：读者知道当前需要知道的，也保留当前不该说透的。
4. **语言有效**：总结、解释、动作、对话、心理和环境各自在需要时出现，不重复证明同一件事。
5. **形式服务内容**：节奏、段落、句法、视角距离和结尾方式匹配当前场景。

## 模式目标

| 模式 | 判断重点 |
|---|---|
| 商业连载 | 承诺与兑现清楚，读者知道为何继续读 |
| 类型长篇 | 类型体验成立，因果、悬念或人物弧线有积累 |
| 文学叙事 | 观察有选择，情绪可信，语言与主题形成压力或回响 |
| 短篇 | 信息经济，局部与整体互相照亮，结尾改变或深化前文 |
| 探索起草 | 产生值得继续的人物声音、关系、场景或问题 |

## 不使用的机械判断

- 不用对话比例、句长、细节数量或字数直接判质量。
- 不把“感到、觉得、因为、似乎”等词单独判为问题。
- 不要求所有人物主动外部行动；观察、等待、拒绝和认知变化也可以构成有效场景。
- 不要求每章不可逆变化、强钩子、爽点、反转或旧线触碰。
- 不用“摔杯、攥拳、咬唇”等动作机械替代情绪命名。

## 快速判断

引用正文回答：

1. 这段最重要的阅读效果是什么？
2. 哪处原文真正产生了这个效果？
3. 哪处内容削弱、重复或解释了这个效果？
4. 最小的有效修改是什么？

无法引用原文时，不做确定性质量结论。
