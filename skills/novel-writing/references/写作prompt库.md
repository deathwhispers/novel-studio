# 写作 Prompt 库

> 用途：AI 协作写作的 prompt 模板，按阶段路由。

---

## 路由指南


不要整库加载。先按任务选择一个库，再只读取对应二级标题下的 Prompt。

| 当前任务 | 读取范围 |
|---|---|
| 节拍卡、章纲、设定核对、伏笔、关系、卷纲 | `写前-prompt.md` 对应小节 |
| 对话、战斗、感情、章尾、心理、环境、节奏、续写 | `写中-prompt.md` 对应小节 |
| 体检、连续性、修订、语言风险、voice | `写后-prompt.md` 对应小节 |
| 角色对戏、卡文、批量任务、灵感、平台实验 | `特殊场景-prompt.md` 对应小节 |

加载步骤：

1. 用目录或搜索定位任务标题，例如 `rg -n '^## .*对话|^### Prompt' <file>`。
2. 只读取目标标题到下一个同级标题之间的内容。
3. 替换项目变量，并补充当前写作支点、最近状态增量、必要上下文和不可破坏项。
4. 把 Prompt 中的字数、段数、比例和结构视为可配置参考；项目约束与章节功能优先。
5. AI 产出后先过硬门禁，再判断软目标；不要仅凭词表或比例机械改写。
6. Prompt 正文若与 `../写作模式契约.md` 冲突，以模式契约为准；不要因为只加载一个小节而丢失适用范围。

如果任务可直接用当前上下文完成，不为了“用 Prompt”而额外加载模板。

---

## 写前阶段


> 每次只使用一个 Prompt，并把“写作模式、当前单位、作者意图”一并交给模型。除 hard canon 外，所有结构、数量和篇幅都可被作者意图覆盖。

## 目录

通用输入头；最小写作支点；支点检查；场景或章节；设定与因果；类型兑现；伏笔与信息；关系；结构与反转；长线规划；上下文裁剪；最终判断。

## 通用输入头

```text
【写作模式】商业连载 / 类型长篇 / 文学叙事 / 短篇 / 探索起草
【当前单位】场景 / 章节 / 段落 / 片段 / 卷
【作者意图】这次最想完成、发现或试验什么
【可靠上下文】最近正文、人物状态、hard canon、voice 样本
【允许未知】哪些内容可以通过正文发现
```

## Prompt 1：生成最小写作支点

```text
基于通用输入头，为当前单位生成最小写作支点。

只保留会真正改变起稿选择的项目：当前视角如何注意世界、人物想靠近或逃避什么、压力来自哪里、已知因果与 canon、希望形成的阅读效果。缺失项标记为待探索，不补成事实。

商业连载可额外写本次承诺兑现与继续阅读动力；其他模式不强制钩子、升级或事件推进。
```

## Prompt 2：检查写作支点

```text
检查以下写作支点是否足以起稿。只指出会导致人物选择失真、因果断裂、视角不明或 hard canon 冲突的缺口。

不要因为没填满模板、没有高潮、没有新债或选择安静收束而阻止起稿。输出“可以起稿”或最多 3 个真正阻塞项。
```

## Prompt 3：设计场景或章节

```text
为当前单位设计一条可写的运动轨迹：开始时人物如何理解局面，什么细节或行动施加压力，人物怎样选择，结束时关系、理解、局面、声音或形式发生了什么。

按内容需要决定场景数和篇幅。文学叙事、短篇或探索起草允许停顿、歧义、回响和未完成感；商业连载可选择更明确的兑现与推动。
```

## Prompt 4：设定与因果预检

```text
对照给定正文计划与设定，分开列出：
1. 已证实冲突：引用双方证据并说明为什么不能同时成立；
2. 可解释差异：可能来自视角局限、传闻或时间变化；
3. 尚未确定：留给正文探索。

只把第一类作为写前硬阻塞，不把资料空白误判成冲突。
```

## Prompt 5：类型兑现或情绪高压（按需）

```text
【适用】商业连载、类型长篇，或作者明确要求爽感、恐惧、悬疑、虐感等类型体验。

设计体验成立所需的前因、人物投入、压力变化、兑现瞬间和真实后果。避免把人物降格为反应装置，也不要为了强度添加与主线无关的羞辱、秘密或反转。

输出“体验如何从人物和因果中长出来”，不套固定模式或强度等级。
```

## Prompt 6：伏笔与信息释放

```text
根据当前视角和读者已知信息，判断这次应显露、延迟、误读或保持空白的内容。

每条建议说明：谁能感知、读者会怎样理解、现在释放产生什么效果、延后有什么代价。伏笔只在服务人物、因果或主题时加入，不要求每个单位新埋线。
```

## Prompt 7：关系变化

```text
设计一段关系运动。先写双方各自想得到、隐藏或避免什么，再用行动、误读、交换、沉默或拒绝让距离发生变化。

变化可以是靠近、疏远、重新命名关系，也可以是表面不变但读者理解改变。不要用固定阶段表替代人物的具体历史。
```

## Prompt 8：结构或反转选择

```text
比较 2-3 种真正不同的组织方式，例如顺叙、缺口、并置、循环、视角限制或延迟揭示。说明每种方式会改变什么阅读效果和代价。

只有当反转能重写既有证据且人物需要承担后果时才建议反转；“不反转”必须是合法选项。
```

## Prompt 9：卷级或长线规划

```text
【适用】确有长线生产需要时。

围绕作品承诺、人物弧线、关系与因果建立阶段节点。只规划当前可见范围，把未知项和可变项明确标出。

商业连载可补充追读承诺与更新约束；文学长篇不自动加载留存、升级或章尾强度指标。
```

## Prompt 10：上下文包裁剪

```text
为当前写作任务裁剪上下文。优先保留写作模式、hard canon、当前人物状态、最近有效正文、当前任务和可靠 voice 证据；其次保留相关关系、地点、物件与状态增量。

列出被省略但可能需要回查的来源。不要把模板占位、无关世界观或旧总结塞进正文上下文。
```

## Prompt 11：写前最终判断

```text
判断现在是否可以下笔。硬阻塞只包括：关键人物选择无法判断、已知因果断裂、hard canon 冲突、非预期视角不明。

其余问题列为“可在正文中发现”或“写后复核”。不要用字数、模板完成率、钩子、伏笔数量或固定结构阻止起稿。
```

## 写中阶段


> 每次只加载当前 Prompt。先给写作模式、人物状态、当前场景和可靠 voice；所有篇幅、段数、强度与结尾方式服从实际写作效果。

## 目录

对话；潜台词与群像；行动；亲密关系；心理；环境；类型兑现；结尾；节奏；续写；视角；形式实验；卡文续段。

## Prompt 1：对话

```text
写一段发生在具体空间里的对话。让双方各自注意不同事物，并通过措辞、回避、动作、沉默和信息策略显出差异。

【人物与关系】{{}}
【表面话题与真实需要】{{}}
【当前压力】{{}}
【voice 证据】{{}}

不要为每个角色制造口头禅，也不强制最后一句成为钩子。对话结束在关系或理解发生有效变化的位置。
```

## Prompt 2：潜台词或群像

```text
【适用】双人潜台词或多人场景。

让每个人只在其立场、知识和风险允许的范围内说话。用注意力、插话、结盟、沉默和空间位置管理群像，不要求人人平均发言。

输出可直接进入正文的场景，不附人物功能说明。
```

## Prompt 3：行动、战斗或追逐

```text
从当前视角写行动场景。空间、能力限制、判断和身体反馈必须可追踪；每个动作来自人物的即时目标，而不是招式展示。

结果可以是胜负、逃脱、误判、关系改变或新认识。只有故事已建立相应 stakes 时才加入重大代价，不强制造成不可逆伤亡。
```

## Prompt 4：亲密、告白或诀别

```text
从双方既有关系与此刻风险出发写场景。让情感通过具体选择、迟疑、身体距离和没有说出口的东西出现。

不要套固定阶段，也不要自动用拥抱、眼泪、牺牲或误会证明强度。结尾服从人物当下能承受的真实程度。
```

## Prompt 5：心理变化

```text
写人物在行动或感知中的心理运动。让外部刺激、旧经验、身体反应和选择互相作用；保留矛盾与未命名感受。

避免连续解释“他意识到/这意味着”。若人物无法得出结论，就停在其能感知的边界。
```

## Prompt 6：环境与意象

```text
通过当前视角选择环境细节。只写人物此刻会注意且能改变氛围、行动、关系或主题回声的内容。

不要把环境写成独立说明书，也不要让所有景物机械对应情绪。允许环境与人物感受抵牾。
```

## Prompt 7：类型兑现（按需）

```text
【适用】商业连载、类型长篇，或作者明确要求某种类型体验。

写出前因、人物投入、压力积累、兑现与后果。爽感、恐惧、悬疑或痛感必须从人物和因果中产生；不按固定强度、段数或字数生成。
```

## Prompt 8：章尾或场景尾

```text
根据写作模式生成 3 个不同落点：推动型、余震/回响型、留白/暂时停顿型。每个版本说明它把读者注意力留在哪里。

商业连载可优先考虑继续阅读动力；文学叙事、短篇和探索起草允许封闭、安静或歧义。不要凭空添加陌生人、秘密、倒计时或反转。
```

## Prompt 9：节奏与场景切换

```text
检查当前片段的注意力和压力如何运动。只在重复、跳跃、必要过程缺失或读者无法定位时调整。

场景长短、切换数量和快慢没有固定比例。给出最小改动，并说明它改善的是清晰度、张力、沉浸、呼吸还是形式效果。
```

## Prompt 10：续写防漂

```text
基于最近有效正文、章节增量、人物状态、hard canon 和当前任务续写。

只接住现在仍活跃且与当前人物有关的后果；不要求一章处理所有悬念，也不强制新埋一条债。延续 voice 的注意力、回避方式和句法倾向，不复制标志句。
```

## Prompt 11：视角设计

```text
判断维持或切换视角哪一种更能控制体验和信息。若切换，明确新视角独有的欲望、盲区和行动，并给读者足够定位信号。

不使用固定章节间隔、戏份比例或“同章绝不切换”的通用禁令；只有非预期跳转和无法定位才是硬伤。
```

## Prompt 12：梦境、幻境或形式实验

```text
【写作模式与实验目的】{{}}
【人物当前状态】{{}}
【需要延续的现实证据】{{}}

写一段服务于人物、主题或感知变化的形式实验。边界是否清晰、篇幅多长、是否解释，由目标阅读效果决定。避免把梦境只当预言或信息投递工具。
```

## Prompt 13：卡文最小续段

```text
不要补新设定。给出 3 个不超过一个动作或一次感知变化的续段方向：人物选择、关系/信息变化、叙述距离变化。说明各自会打开什么可能，再按作者选择继续正文。
```

## 写后阶段


> 所有判断必须引用正文证据并说明受损或实现的阅读效果。P0 只用于连续性、人物动机、因果、hard canon 和非预期视角漂移等硬伤；不输出综合分。

## Prompt 1：完整章节体检

```text
【写作模式与作者意图】{{}}
【当前正文】{{}}
【必要上下文】{{最近正文、人物状态、hard canon、voice}}

先概括这段正文真正完成了什么，再检查：人物选择与代价、因果、视角和信息、关系或压力运动、语言与形式。

输出：最有效的 2 处原文；硬伤；最多 3 个最影响阅读效果的软问题；最小修改顺序。没有问题就不要凑数。
```

## Prompt 2：单点深读

```text
只检查 {{人物 / 因果 / 视角 / 信息 / 节奏 / voice / 形式}}。

每个结论按“原文证据 → 读者实际经历 → 为什么有效或失效 → 最小建议”输出。不要扩展到其他维度，不用词频代替阅读判断。
```

## Prompt 3：结尾效果

```text
判断结尾把注意力留在何处，以及它是否完成当前模式需要的推动、余震、回响、封闭、歧义或暂时停顿。

商业连载可额外检查承诺兑现和继续阅读动力；其他模式不因缺少钩子判失败。若建议改写，给出不添加新秘密或反转的最小版本。
```

## Prompt 4：跨章连续性

```text
对照最近有效正文、章节增量和当前章，检查人物位置、知识、关系、物件、时间和未完成行动。

只报告有双方证据的冲突；区分真实矛盾、视角差异、时间变化和资料空白。输出原文位置与最小修复，不要求当前章回收所有旧线。
```

## Prompt 5：逻辑、细节或回收修补

```text
先写必须保留的戏剧功能、人物选择、信息和 voice，再做最小修补。

修订顺序：人物与因果 → 场景和信息 → 句子与细节。不得为了“更刺激”自动添加误会、反派、秘密、伤亡或反转。输出修改片段及每处修改保护的效果。
```

## Prompt 6：语言与形式审读

```text
结合写作模式、人物和可靠 voice 样本审读正文。重点检查抽象解释是否替代体验、句法是否无意重复、意象是否失去具体性、叙述距离是否意外漂移。

引用证据并提出局部校准。不要统一句长、删除所有修饰语、制造口头禅或把偏离样本本身判为错误。
```

## Prompt 7：人物 voice 对比

```text
比较当前正文与可靠人物样本中的注意力对象、判断方式、回避策略、信息权限和句法节奏。

列出保持、合理变化和无依据漂移。只有最后一类需要修复；角色在压力、关系和成长后的声音变化可以成立。
```

## Prompt 8：卷级与长线复核

```text
【适用】完成一个阶段、卷或足够长的样本后。

检查作品承诺、人物弧线、关系、因果、信息与形式如何累积。指出真正停滞、重复或失联的线，并引用跨章证据。

商业连载可增加追读与承诺兑现维度；文学长篇不自动套章尾强度、升级速度或固定回收周期。
```

## Prompt 9：读者体验假设

```text
根据正文证据提出 2-3 个可证伪的读者体验假设，例如注意力落点、情感距离或理解负担。区分文本证据、推断和需要真实读者验证的部分。

不要虚构读者画像、平台偏好或弃读原因。
```

## Prompt 10：完成度判断

```text
判断当前单位是否已经实现作者意图并通过硬门禁。

硬门禁：已知连续性、人物动机、因果、hard canon、预期视角。软目标按写作模式与当前单位选择，不要求固定字数、模板完成率、推进、钩子、伏笔或统一强度。

输出“可以保留 / 需要最小修复 / 交由作者审美判断”，并给出证据。
```

## Prompt 11：生成续写状态增量

```text
从正文中提取下一次写作真正需要继承的变化：人物选择与状态、关系、位置与时间、物件、已公开信息、尚未完成的直接后果。

只记录正文已发生的事实；推测单列为待确认。不要把审美评价、摘要或新设定写进状态增量。
```
