# 情绪兑现

## 能力范围

- 设计爽点兑现（商业连载/类型小说）
- 章尾制造翻页动力
- 情绪节奏编排（避免连续同情绪）

## 爽点设计

### 核心原则

- 爽点 = 此前积累的期待得到明确回应
- 来自角色的能力/准备/联盟/价值选择，不来自临时特权
- 兑现后留下真实变化，不立刻撤销

### 5 种爽点路径的触发条件（NEW-W9 修复补充）

| 触发条件 | 选路径 | 怎么写 |
|---------|--------|--------|
| 主角首次在实战中使用某个能力 | 能力兑现 | 用在关键时机，能力效果+见证者反应同时呈现，不只是"用出来了" |
| 旁观者误解 + 真相揭晓（如反派以为主角要输/以为主角没实力） | 认知翻转 | 见证者的反应比主角的行为更重要——旁白一句话"全场安静了"比主角内心独白有效 |
| 系统/任务奖励（点数、物品、技能） | 资源获取 | 获得过程有代价，不白送——读者要看到"为这一刻主角付出了什么" |
| 第三方倒戈（盟友站队/敌人反水） | 关系支援 | 支援源于既有情感/利益铺垫，不突兀——不能突然某路人跳出来帮忙 |
| 主角用智慧/规则破局（不是靠能力/武力） | 规则利用 | 在规则边界内找到优势——读者要能跟着主角的思路推导出来（"我懂了，他利用了 X 规则中的 Y 条款"） |

### 章尾 5 种形态的触发场景（NEW-W10 修复补充）

| 形态 | 触发场景 | 怎么写 |
|------|---------|--------|
| 决定悬置 | 主角面对两个选择 | 停在选择前——给读者看选项，不揭示结果（"他看了眼左边，又看了眼右边"） |
| 信息缺口 | 揭示一个新异常 | 给一个读者没见过的细节（异常的声音/气味/数值），不解释 |
| 关系移位 | 一段对话/动作改变了距离 | 关系变化在对话/动作里体现，后果不展开（"她说完这句话，转身走了。他没追"） |
| 危险逼近 | 威胁可见但未碰撞 | 威胁**已可见**——读者知道有事要发生，但主角还没反应过来 |
| 后果已至 | 事件已发生，处理是下一章 | 事件已完成，但处理这件事需要时间/资源/计划——读者知道下一章要"善后" |

### 爽点前后

- **爽点前必须有垫**：读者不知道角色在等什么、怕什么，爽点就是空炮
- **爽点后必须有后果**：爽完立刻写代价或连锁反应，让爽点不是终点

## 章尾动力

### 五种有效形态

| 形态 | 读者心理 | 怎么写 |
|------|----------|--------|
| 决定悬置 | 「他选哪个？」 | 停在选择前，不揭示结果 |
| 信息缺口 | 「到底怎么回事？」 | 揭示一个新异常，但不解释 |
| 关系移位 | 「他们会怎样？」 | 一次对话/动作改变了距离，后果未展开 |
| 危险逼近 | 「快跑/快打！」 | 威胁已可见，但未正面碰撞 |
| 后果已至 | 「然后呢？」 | 事件产生明确后果，处理后果需要下一章 |

### 章尾禁忌

- 总结腔：「就这样，他完成了今天的修炼」
- 预告腔：「他不知道，更大的风暴即将来临」——空洞无信息
- 情绪空转：「他感到一阵复杂的情绪」——没有行动或变化
- 自然结束：吃饭、睡觉、收工——除非这些动作引发了不可逆变化

**自检**：如果你是读者，读完这一章后脑中浮现的第一个问题是什么？如果不存在——章尾不成立。

## 情绪节奏

### 核心规则

- **不要同色连续两章**：上一章以紧张结尾，这一章不要从头紧张到尾
- **一章内至少两种阅读感受**：紧张+趣味、爽感+好奇、心酸+温暖
- **低压章不等于废章**：日常/过渡章要积累关系变化或伏笔，让读者觉得「我更了解这个角色了」

### 爽点密度数字阈值（W-NEW-PACE-NUM 修复）

| 节奏维度 | 数字阈值 | 备注 |
|---------|---------|------|
| **微爽点**（小目标达成/小反转/小打脸） | **每章 ≥ 1 个** | 番茄系统爽文读者耐心有限 |
| **主爽点**（大能力兑现/大反转/大清算） | **每章 ≤ 1 个** | 多了读者疲劳 |
| **连续无爽点上限** | **≤ 3 章** | 第 4 章必出主爽点（番茄读者放弃阈值） |
| **同一爽点类型连续** | **≤ 2 章** | 都是打脸 → 读者腻；第 3 章换类型（爽点+温暖 / 爽点+好奇） |
| **章内爽点落位** | **章中 60%-70%** | 章首钩子 + 章尾钩子不要直接是爽点（铺垫不够） |
| **节拍级爽点密度** | **情绪 beat 必含 ≥ 1 个微爽点** | 情绪 beat 没爽点就空转 |

**节奏曲线建议**（7 节拍章节为例）：
- beat-1 钩子：铺垫 + 期待建立（不算爽点）
- beat-2 承接：铺第二个期待
- beat-3 转折：第一个微爽点（小反转）
- beat-4 推进：第二个期待铺垫
- beat-5 高潮：主爽点（大兑现）
- beat-6 余波：代价/连锁
- beat-7 收束：情绪落点 + 章尾钩子

### 钩子落位硬清单（W-NEW-HOOK-POS 修复）

| 位置 | 是否必出钩子 | 钩子类型 | 备注 |
|------|------------|---------|------|
| **章首 200 字** | **必出** | 5 种开局之一（异常/悬念/动作/声音/情绪） | 读者 200 字内还没钩就划走 |
| **章中转场** | 必出（每 1000 字） | 1 个子问题/钓胃口 | 详见 hook-design |
| **章中高潮前** | 必出（回拉点） | 1 个让读者「他要失败了吗？」的瞬间 | 在主爽点前制造短暂挫败 |
| **章尾 50-100 字** | **必出** | 5 种章尾形态之一 | 章尾不成立 = 整章失败 |
| **节拍末尾** | 选调（承上启下） | 1 句钩子（next_beat_starter 不算） | 见 hook-design |

**钩子落位自检**（每章写完后）：
- [ ] 章首 200 字内出现 1 个钩子？
- [ ] 章中每 1000 字有 1 个子问题？
- [ ] 高潮前有回拉点？
- [ ] 章尾 50-100 字有钩子？
- [ ] 章内钩子类型不超过 3 种（太多 → 读者注意力分散）？

### 情绪调色板

| 情绪 | 作用 | 放哪里 |
|------|------|--------|
| 好奇 | 信息缺口驱动翻页 | 章首钩子、揭示后 |
| 紧张 | 角色处于即刻压力 | 冲突升级处 |
| 爽感 | 积累的期待被回应 | 本章兑现点 |
| 趣味 | 角色或叙述的魅力 | 紧张释放后、互动间隙 |
| 心酸 | 珍视之物被触动 | 关系变化、代价显现 |
| 温暖 | 信任/照料/理解发生 | 高压后的呼吸 |
| 震撼 | 认知被颠覆 | 反转揭示点 |

## 低压章怎么设计（NEW-W3 修复补充）

「不要同色连续两章」的反面是「低压章」。网文读者一看到过渡章就想弃——但实际创作中必须有低压章（节奏需要喘息、关系需要沉淀）。低压章不能写成"什么都没发生"。

### 低压章的 4 种合法形态

| 形态 | 例子 | 怎么写 |
|------|------|--------|
| **关系沉淀** | 上一章打了一架，这章主角和搭档在路边摊吃东西 | 关系变化有具体细节——「他没说话，但她把自己碗里的肉夹给了他」 |
| **伏笔积累** | 上一章揭示了系统秘密，这章主角在实验室找证据 | 不推进主线，但埋下「看到某个细节觉得奇怪」的下章钩子 |
| **视角扩展** | 上一章主角视角，这章反派/配角的"日常生活" | 用反差让读者理解反派的逻辑（不能洗白，但要让读者看到动机） |
| **角色内部成长** | 上一章大事件，这章主角独处/反思 | 用动作带内心（不是独白，是「他关上窗户，开始写信」） |

### 低压章的 3 个禁忌

1. ❌ **「他睡了一觉」式空转**——吃饭、睡觉、收工本身不是低压章，必须有变化发生
2. ❌ **「他想了很久」式情绪独白**——读者已知主角在想什么，独白是浪费篇幅
3. ❌ **「又一天过去了」式时间跳跃**——除非这个时间跳跃本身揭示了什么

### 低压章的最低标准（自检表）

- [ ] 本章是否有至少一个**不可逆的微变化**？（关系/认知/状态任意一项）
- [ ] 变化是否由**具体动作**承载？（不是"他变了"，是"他没说话，但她注意到他的手在抖"）
- [ ] 章尾是否给了读者**下章期待的锚点**？（哪怕很小的钩子也行）
- [ ] 全章是否避免了「吃饭/睡觉/出门/到达」的日常动作作为收尾？

**自检失败**：本章需要重写或合并到上一章/下一章。

### 低压章与节拍字数的关系

- 一章 7 个 beat，低压章通常 2-3 个 beat 用于「低压段」（铺垫/关系/伏笔），其余 4-5 个 beat 用于「伏笔积累 + 章尾钩子」
- 不能 7 个 beat 全是低压——读者看不到推进
- Writer 在 LOOP_PREVIEW 阶段应识别本章是「高压章 / 低压章 / 中性章」并在 WriterBrief-Beat 的 `emotional_arc` 字段标注
