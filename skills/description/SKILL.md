# 通用描写技法

## 能力范围

- 人物外貌描写（先印象后细节、特征化、避免清单）
- 物品道具描写（功能 + 故事）
- 描写与素材库的配合（技法 + 素材 = 成品）

## 边界（O10 修复）

| 关注 | 在哪里 |
|------|--------|
| 怎么写（先印象后细节、特征化） | **本 skill** |
| 写得好不好看（说明式→展现式润色） | `stylist`（修订场景） |
| 声音统一不漂移（叙述者声音锁定） | `style-calibrate` |
| 场景/环境渲染（空间、感官、压力） | `scene-render`（另一 skill） |

**调用时机**：Writer 写 beat **起草阶段**，需要外貌/物品描写时调本 skill。修订阶段不调本 skill——修订走 `stylist` 整体润色。

场景/环境描写的完整技法见 `skills/scene-render/SKILL.md`，本 skill 不重复。

## 外貌描写

### 先印象后细节

外貌描写的顺序决定读者记住什么——先写「第一眼看到的最强印象」，再写支撑细节。

```
❌ 她身高一米六五，皮肤白皙，眼睛很大，鼻子挺，嘴唇薄，头发是黑色的，扎成马尾。

✅ 她走过来，第一个让人注意的是那双眼睛——太亮了，像能把人看穿。
   走近了才发现，她个子不高，马尾扎得紧紧的，后颈露出一点汗。
```

### 特征化

外貌不是体检报告，是「记住这个人的理由」。选 1-2 个特征写透，其余留白。

```
❌ 他长相普通，但气质不凡。

✅ 他左眉有道疤，断成两截。笑的时候，那半截眉毛不动。
```

### 动作中写外貌

外貌在动作/互动中带出来，不单独停下来描。

```
❌ 她是个漂亮的女人。

✅ 她把头发别到耳后。手腕上那串珠子跟着晃。他多看了两眼。
```

### 素材库配合

写具体类型（人物外貌气质身材/性格、穿搭、车/表/房/奢侈服饰/神豪消费、环境、美食、爽点桥段、强烈情绪，或需要含蓄性暗示词汇、要融入网络热梗）时，按 `references/material-index.md` 用 tag 命中素材，再用本 skill 的技法组织——素材给「内容」，技法给「结构」。热梗按该库条目的「网文用法」融入对白/叙事，不整段照搬示范；密度、人设、品类约束见 `lib/internet-meme-catalog.md`「使用原则」。

> **W-NEW-7 修复澄清**：本 skill **不是触发器**。检索决策由 `agents/writer.md`「第一步半：素材库强制检索」根据 10 类触发清单决定（外貌/性格/资产/美食/环境/爽点桥段/强烈情绪/性暗示/网络热梗等），按 `references/material-index.md` 走 A 或 B 流程拿素材。本 skill 的职责只在 Writer 拿到素材**之后**——按本 skill 的「功能 + 故事」「多感官通道」「三视角镜头」等技法组织语言、把素材编织进文本。description skill 不主动判断"何时检索"，仅在 Writer 命中触发条件后介入。

## 物品道具描写

### 功能 + 故事

物品描写两层：它是什么（功能）、它经历过什么（故事）。

```
❌ 他手里拿着一把刀。刀很锋利。

✅ 他手里那把刀，刃口崩了个缺口。不是砍崩的——是磨崩的。磨了很多年。
```

### 出现即有用

描写一个物品，要么后面用到，要么揭示角色。不写「只是摆着好看」的东西。
